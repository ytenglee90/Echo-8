# ADR 0151 · AI 意图分流、历史回查与画布工作流

状态为有效。补充 ADR 0142、0147、0149、0150。

## 分流与请求

AI 助手按本轮原话本地分流。聊天在需要画布资料时只提供查询和范围读取，操作路径允许提交计划，混合正文任务分别绑定读取来源和写入目标。原生工具、JSON 信封和模型直接返回的计划都经过本轮写入限制及画布所有者校验。普通聊天不载入画布目录。具名操作优先采用当前命中对象。明确的短指代才查询对话任务状态。

本轮对象目录在首次定位后复用。同一轮延续保留原用户消息、模型调用和每项匹配的工具结果，既有原生工具配对和 HTTP 422 兼容流程继续使用。识别到对象修订冲突时允许一次重新准备。旧工具范围和计划失效，新核对采用独立画布任务标识。相关用量仍计入原对话任务。

## 原文与接续

近期相对摆放按会话记录最近一次真实预览及执行前后标记。常规聊天和其他计划不会挤掉该记录。间距追问在重读目标、参照和修订后计算，撤销或手动移位使旧基准失效。预览与状态仅保留在当前打开的会话生命周期内。

历史回查分块读取原对话，记录轮次、说话者、字段、确认或建议、替代关系及原文偏移。会话内目录可按修订重建，最多按范围读取 2 MiB。命中后重读同修订原文。优先区分最早确认、当前有效决定和助手建议。多对象或竞争决定需要确认；无命中由现有记忆检索提供补查。明确回顾全部讨论复用分批全文流程和原有用户确认。日志只记录读取次数、命中数、来源类型和字符数。

## 画布所有权与兼容

批量补全和历史字段恢复在 AI 助手中确定字段偏移，由原有 v2 正文编辑和画布所有者形成计划。按原句跨卡同步复用内容搜索和替换所有者。关系追踪、重名检查和按群组分列属于画布控制。拆合卡保留原卡，只在明确请求时重接已核对的可见连线。所有持久修改通过既有事务和撤销流程。

新增 `canvasControl.context@3`，提供具名对象优先和相关范围，旧版调用保留原选区行为。新增 `canvasControl.applyItems@1`，索引从 1 开始，读取预览内的动作或已展示的替换匹配项。存在多份待应用计划时，对话操作需要先选定一份。依赖的创建项需要一并选中。独立节点操作仅核对选中目标。涉及连线或群组时继续核对相关快照。整份应用 `canvasControl.apply@1`、已有计划版本及文档格式继续使用原协议，无书籍迁移。

本地能力识别明确的中文命令和结构化字段。缺失字段按字段名加冒号识别。年龄检查定位同名对象的不同数字年龄，供用户结合时间线核对。排版以已有画布群组分列，保持原位的卡片或群组通过名称指定。超出预算的正文与难以唯一定位的历史值要求补充范围。

## 验收

合成相对摆放在第 1、15、100、300 轮均定位到同一目标并通过 35 画布单位的回读。每次为两次模拟模型请求，首轮 8,495–8,569 字节，工具续轮 9,545–9,619 字节。与 ADR 0150 使用的「填入人物卡」抓包属于不同任务。没有专用 DeepSeek 测试凭据，服务商 Token 和延迟尚待实测。

最终类型检查、ESLint、658 项单测、246 项 Chromium 托管回归、40 项 Chromium 便携回归、80 项 Firefox/WebKit 便携回归及两项最终按项预览布局复核通过。极限画布浏览器测试覆盖 2,000 节点、1,600 连线和两千万字符并通过。托管与单 HTML 构建通过，按项预览完成截图检查。单 HTML 为 2,014,578 字节，SHA256 为 `bf47e213379a9e4ce71d485712a9ff115b335e9b03f444796bb3e552b7eeeeef`。

Firefox 最初在创建空白页时无法启动内容子进程，导致首轮全量的 246 项环境失败。测试进程使用 `MOZ_DISABLE_CONTENT_SANDBOX=1` 后可启动并完成验证。现有固定浏览器运行时可用，重新安装命令因本地 `ms-playwright/__dirlock` 目录权限失败。

随后 Firefox/WebKit 托管全量为 476 通过、16 失败。16 项串行复核后 5 通过、11 项仍失败。剩余 Firefox 八项涉及中转点端口连接、缩放尺寸参考线、标题端口、40% 群组端口、拖出视口和三档中转点控件间距。WebKit 三项涉及云端实时保存、中转点反向拖线及拖动释放预览。WebKit 的自然连线场景复核通过。原全量与复核失败记录保留在 `local-data/complete-ai-cross-final.log` 和 `local-data/complete-ai-cross-recheck.log`。
