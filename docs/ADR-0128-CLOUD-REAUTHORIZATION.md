# ADR-0128：Cloudflare 授权失效的重新连接入口

2026-11-05，有效。补充 ADR-0067、0127。

站点登录会话有效不代表 Cloudflare OAuth 授权仍可使用。状态接口增加可选 `reauthorizationRequired` 布尔字段；已到期且没有刷新令牌，或授权数据无法解密时，只返回重新授权状态，不返回令牌。控制接口返回 401 时，cloud-sync 保留当前书籍和待上传队列，并展示其拥有的云同步面板及重新连接操作。

书库提示卡和云同步面板只在 `reauthorizationRequired` 表示授权失效时提供重新连接入口；正常登录时隐藏，重新授权成功后恢复隐藏。失效状态展示明确的“重新连接 Cloudflare”按钮。书库右上账户区不重复提供重连按钮。新公开指令 `cloudSync.prepareReconnect` 先创建当前书籍与撤销历史的本机检查点、保存云队列，再返回站内 OAuth 起始地址；视图收到成功结果后才导航。无法持久保存的内存模式拒绝直接跳转，提示先导出。普通登录、退出和原 OAuth 协议保持兼容，不变更书籍格式和数据库结构。

浏览器回归覆盖初始授权已过期、控制接口 401、入口可见性、跳转，以及返回后本机书籍和撤销历史的保留。
