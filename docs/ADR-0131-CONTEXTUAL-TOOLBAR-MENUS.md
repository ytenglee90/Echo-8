# ADR-0131：根据选择显示图标与工具栏悬停菜单

2026-11-06，有效。补充 ADR-0026、0089、0110；替代其工具栏入口交互，不改变原指令及快捷键语义。

菜单排列、群组下拉、自动排列主按钮和中转点筛选/批量行为由 ADR-0132 替代。其他 UI 资源、协议及事务边界继续适用。

连接、群组和自动排列使用统一 UI 组件 ToolbarDropdown，AI 多会话菜单也复用该组件。鼠标经过或键盘聚焦打开浏览器管理的原生 popover；移出延迟关闭，方向键移动焦点，Escape 关闭并恢复触发按钮焦点。组件拥有并清理延迟任务及动画帧，不注册全局监听、不自设浮层层级。悬停、菜单和焦点只在视图中存在，不进入文档或历史。新增操作只显示图标，以 title/aria-label 提供名称。

连接插件通过兼容扩展的版本化指令 `connection.toolbarToggle@1` 接收 body/title/junction/disconnect。正文和标题连接分别创建或取消；纯连线选择只取消选中的对应类型。中转点操作只接受选中的连线，沿用拥有者的端点、类型和修订校验，以实际曲线中点的平均位置拆分；新点随即成为选中项，主按钮切换为解除。选中中转点再次操作恢复原连线，创建和解除各为一次持久事务。选择节点或文本框不会添加中转点。旧连线指令及快捷键保持兼容。

群组插件通过 `group.membership.applySelected@1` 接收 add/remove。加入要求先选对象，最后追加选择唯一目标群组；保持单一群组所有权，拒绝跨群组直接转移。只选成员时主按钮显示踢出；对象和目标群组有效时显示加入；只选群组显示解组；至少两个无群组对象显示创建。加入和踢出只在群组按钮菜单中显示当前有效图标，不再常驻第二个成员按钮。批量踢出可涉及多个群组，拥有者组合成员补丁及解散群组的连线清理计划，一次提交、一次撤销，不移动对象位置。旧成员面板指令继续可用。

自动排列主按钮固定使用宫格，菜单提供宫格、横排、竖排图标；旧快捷键和命令面板的循环排列指令保持原行为。所有选择投影只读公开能力与元数据，执行时由功能拥有者再次校验，UI 不直接写入持久状态。

选择拥有者收到目录中缺失的 ID 时立即刷新公开实体投影，而非等待动画帧合并的失效信号，确保同一复合操作刚创建的中转点可以立即选中。它只更新可重建目录及工作区选择，不产生文档历史。

本次协议均为兼容扩展，不改变书籍、剪贴板、数据库或连接记录格式，无需数据迁移。定向测试覆盖类型独立取消、纯连线中转点操作、文件往返、插件停用后撤销、批量加入/踢出、单事务撤销、悬停与键盘焦点、图标随选择变化和固定排列。
