# ADR 0150 按画布任务组装模型请求

状态为有效。补充 0148、0149。

用户明确指定一张正文卡且没有提出额外画布操作时，发送目标的 ID、标题、正文长度和修订号，仍附允许读取的当期正文。模型使用单卡正文提示和原有工具。存在多目标、关联操作、显式历史检索或无法核对当前修订时，沿用原有通用上下文。

「填入人物卡」保留最近的助手原话及对应用户要求。对应的当前对话已可从近轮读取时，不自动再取其索引归档；用户指定其他记忆或明确要求回顾时保留原有检索路径。旧画布状态和对象不会随单卡请求重复发送。

工具读取仍经过所有者的实际范围与修订校验。返回范围若已逐字出现在本轮来源中，工具结果以原来源编号、修订和范围引用现有内容。短于这段描述的原样保留。若字段不同或正文只覆盖部分范围，发送工具原文。DeepSeek 等原生调用仍保留每一组 assistant/tool 消息和调用标识，JSON 兼容信封仍沿用现有路径。

生成、修订校验、执行确认及撤销仍由原有画布计划处理。书籍格式、持久化、公开画布能力和校验沿用原协议。

## 工具、对象和证据按任务选择

对已识别的画布任务，按正文、位置、颜色、连线、群组、显示形式和设置选择工具参数与对象字段。组合操作合并所需字段，同一对象只出现一次。未识别或依赖正文定位的请求保留通用工具和较完整的目录。此分类只决定请求组装，计划权限、审查和应用均由现有所有者判定。

同一轮工具结果以对象 ID、实际数据和修订为依据复用目录或前一工具结果。正文按源 ID、修订、偏移和逐字重叠比对，已提供部分使用引用，其余部分补发。仅在编码较小时采用引用；工具结果超限或失败时不会注册未发送的内容。原生模式保留调用与结果配对，兼容信封显式标出可供后续引用的工具调用标识。

明确要求沿用草稿时，在当前预算内保留最后一版完整答复，跳过旧操作提示。预算不够时标记缺少完整草稿。几何或结构追问若已核对最新计划状态并有对应对象资料，可省略对话原文。明确追问以前确定的事项时按现有记忆范围检索原文，沿用自动或仅显式引用模式。
