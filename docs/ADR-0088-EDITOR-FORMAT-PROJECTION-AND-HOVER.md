# ADR-0088：编辑器格式投影一致性与画布悬停反馈

## 状态

已采纳。补充 ADR-0004、ADR-0017、ADR-0063、ADR-0066、ADR-0086。

## 决定

1. 格式刷只在指针释放或键盘选区完成后，给最终非空选区应用来源格式。选区预览、焦点恢复、失焦和单个光标落点不执行格式写入。新的鼠标手势不恢复上一次失焦保存的选区锚点。
2. 双击格式刷通过 schemaVersion 1 的 `editor.clearFormat` 意图，顺序发布清除请求，再分发文本所有者的 `content.resetFormat`。它校验格式和正文修订，在一个不可与先前格式操作合并的事务中恢复当前节点的默认格式并删除所有局部格式标记；撤销同时恢复两者。单击请求和双击清除请求经过同一消息通道，防止双击后迟到的单击重新启用格式刷。
3. 字号提供 15/24/36 px，字重 400/600/900，行距 1.2/1.7/2.6，字距 0/2/4 px，首行缩进 0/2/4 字，段后间距 0/1/2 行。快捷键沿同一三个值步进。旧文档的其他数值保留，控件仅显示该当前值作为不可重新选择的隐藏项，不改写既有数据。
4. 文本所有者和编辑投影共用无状态的带偏置锚点变换。投影在每次输入、原生输入回退、中文组合提交、粘贴和辅助替换时立即移动格式标记。正文临时广播同时携带该正文对应的标记，保证可合并预览仍是完整一致的快照。继承格式是临时标记；队列排空后通过有范围和修订保护的格式快照替换。旧正文或旧格式加载结果不得回退较新的投影；待提交正文期间保留对应的本地标记。
5. 格式投影的视觉键只包含格式、范围和辅助装饰，不把持久标记 ID、锚点偏置或修订号当成像素变化。局部写入同步记录视觉键，避免提交确认再次重建相同 DOM。辅助装饰的投影在绘制前同步，继续保留正文格式。默认格式修改保留已有标记引用；仅显式清除操作删除标记。
6. 连接线普通描边继续为 1.5 px；悬停、键盘聚焦及选中统一为 3 px，并遵守原有低缩放平方根补偿。普通、单独定色和批量路径使用同一高亮宽度；单独定色继续保留用户的颜色。标签悬停同样高亮对应路径。
7. 节点和文本框的悬停复用选中描边层，包括圆角、外扩、颜色和远景宽度。悬停不更改选择、尺寸、文档、历史或持久化。节点已有的临时悬停广播继续负责概览中相关连线的显示。

## 兼容性

增加两个内置 schemaVersion 1 指令，复用现有命令信封、标准补丁、格式记录和格式能力。旧指令保持可用。`.echo8` 格式与插件数据版本不变，无需数据迁移；旧的任意合法排版值继续可读写。临时预览新增可选标记数组，不保存到文件或历史。

## 验证

- 锚点测试覆盖连续前插、跨段、Emoji、删除、边界偏置和原对象不可变性。
- 内核测试覆盖默认格式保留局部格式、清除的修订拒绝、原子历史、保存重开和插件停用后撤销重做。
- 浏览器测试覆盖真实拖选、前后目标、空选区、双击与单击顺序、三个可选级别、前方输入/换行/粘贴/IME、编辑器重开、纠错及补全替换、逐帧格式稳定，以及连接线、节点和文本框的悬停/选中反馈。
