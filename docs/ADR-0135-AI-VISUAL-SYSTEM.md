# ADR-0135：AI 助手统一视觉与紧凑账户信息

2026-11-06，有效；补充 ADR-0007 的统一 UI 主题边界。

聊天、记忆库、Prompt 模板和模型连接共用 UI 拥有的 ai-design-system.css，以 ai-floating-panel 为作用域，不修改功能插件的命令、数据或私有实现。该视觉层在既有 AI 样式之后明确加载，统一基础字号/行高、标题层级、字段标签、34px 表单控件、32px 图标操作、8px 控件圆角、10px 卡片圆角及 16px 内容边距。聊天正文使用独立的 13px 阅读层级；不把正文和表单标签压成同一层。

卡片、输入框和下拉框继续使用当前面板的语义前景色，降低背景填充和边框强度；统一下拉箭头、键盘焦点和禁用反馈。模型连接取消多余的整页外框，保留连接、迁移和检索模块的清晰分区；记忆文件操作按可用宽度换行，聊天顶部控件也在窄面板自然换行。控件不以固定内容宽度挤压文字。

书库账户区将容量和权限放入一个不换行的信息行，邮箱仍单独一行；容量保留原提示说明，已有窄屏策略不变。

无公共消息、权限、文件格式、数据库或持久数据迁移。验证比较四个 AI 页面的实际控件排版与标题层级，检查窄屏横向溢出，渲染四页截图；保留原有 AI、模板、记忆和连接工作流回归，并验证账户容量/权限在同一行。
