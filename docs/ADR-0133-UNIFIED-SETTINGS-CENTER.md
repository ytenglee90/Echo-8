# ADR-0133：统一设置中心与命令偏好管理

2026-11-06，有效；补充 ADR-0007、0025、0130。

设置中心是 shell 对受治理的 `right.primary` 插槽的布局：左侧为外观、命令与快捷键、云同步、书籍与恢复、插件、内核与诊断，右侧只渲染当前活动贡献。插件仍拥有自己的内容、公开打开/关闭指令和工作区状态，shell 不导入功能实现，不读写私有状态。入口按 ADR-0134 调整为命令面板最上方的“设置中心”，不在工具栏添加设置按钮；旧命令、快捷键和关闭按钮保持兼容。

新增可选的运行时 UI 元数据 `SettingsPageContributionV1`，显式携带 `version: 1`、分类名、图标、排序和无载荷的拥有者打开指令。只允许 right.primary 的 view 注册；PluginManager 验证指令属于贡献插件，UIRuntime 校验版本和字段并冻结副本。导航读取已注册的全部设置页，不受插槽当前独占渲染过滤影响；停用插件时，其导航、页面及活动表面一并释放。未声明设置元数据的既有贡献继续采用原布局。

分类点击通过目标拥有者的 ViewClient 路由公开指令，后续互斥关闭仍由 UISurfaceArbiter 处理。分类选择从活动表面推导，不另建选中状态，也不进入文档历史或恢复记录。分类键盘焦点保留，直接打开时焦点进入内容区，关闭时恢复到仍存在的入口；窄屏改用可横向滚动的分类栏。

六个页面共用标题、说明、操作区及语义颜色。命令与快捷键继续读取公开动作/快捷键目录，额外展示来源并支持按来源、命令标识、关键词搜索，以及已自定义/未绑定筛选；快捷键冲突继续由唯一 UI 注册表原子裁决。独立命令面板保留为执行浮层，动作目录不复制。内核详细信息默认折叠，插件增加搜索，外观和命令列表减少重复卡片边框。

云同步原先用空补丁事务携带打开事件，空事务会被跳过，因此旧面板无法让出。现在由 cloud-sync 声明并写入会话专用的 `cloudSyncUI` 工作区命名空间，使打开/关闭走实际事务、可靠发布原有事件。新增其自有状态读写权限，不增加跨插件访问；该状态被恢复过滤器排除，旧数据缺省为关闭，无需迁移。

此次只扩展非持久 UI 注册协议；无数据库、书籍格式、插件持久数据版本变更，无需数据迁移。验证包括旧贡献兼容、无效元数据拒绝、导航与独占表面并存、拥有者停用清理、六分类切换、旧快捷键直达、独立命令面板跳转、快捷键修改/恢复及窄屏可达性。继续执行项目完整本地验证与单 HTML 构建。
