# ADR 0153 · 本地理解画布指令

有效。取代 ADR 0152 的云端语义入口，保留其上下文去重与受限查询。

AI 助手在准备阶段分流。已能完整解析的命令走已有本地路径。其他简短自然语言在浏览器内使用现有 BGE Small 或 Base 量化模型和按模型训练的分类参数。本地分类只接收用户当前输入，已引用的正文和旧对话资料仍走原有检索流程。明确的否定、假设和咨询优先按讨论处理。首次使用模型需要获取固定版本的模型资源，指令文本留在设备上。已识别的聊天直接进入现有生成流程，取消云端意图判定工具。

分类参数来自 162 条人工标注示例。分类分数和候选间距用于筛选，不能视为概率。明确的数量、名称、颜色、方向等参数由受限解析提取。所有子项都能绑定后才允许整批提交。新建对象可在同一条指令内分组和连接。参数不足时请求澄清。现有正文生成、需要分析的画布任务和显式 AI 指令继续使用模型工作流。

新增 `language.embed@1`，复用本地语义提供者和 Worker 模型资源，独立于画布索引。新增 `canvasControl.localPlan@2`，对解析后的操作和明确的选区数量进行二次校验，保留最初用户输入。对象绑定、权限、确认方式、事务和撤销由画布控制及各对象所有者负责。直接模式可提交新建及本地解析的可逆结构修改，删除及正文覆盖保留审查。已应用、待确认或已撤销的同轮追问优先读取本地执行记录。旧版能力、画布计划格式和书籍格式继续兼容。

验证用浏览器加载固定资源并运行真实本地模型，统计云端请求和实际画布变化。重点覆盖两张近义标题的独立创建、批量改色、六节点建图、整批撤销重做和追问防重。分类参数由 `scripts/train-local-intent.mjs` 生成，训练样本位于 `scripts/local-intent-training.ts`。

本次检查通过类型检查、ESLint、661 项单测、42 项 Chromium 便携回归、Firefox 和 WebKit 的 4 项便携定向验证及极限画布压力测试。Chromium 托管全量 245 项通过，三项编辑器与拖线场景在串行复查中通过。WebKit 的便携入口使用数据 URL 加载固定 ONNX 模块，解决不透明来源下的嵌套 Blob 导入错误。重新生成的单 HTML 校验值记录在 `artifacts/SHA256SUMS.txt`。
