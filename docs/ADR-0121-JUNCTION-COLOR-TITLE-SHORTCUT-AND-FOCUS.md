# ADR-0121：中转点颜色、配套主题、标题快捷连线与全画布聚焦

## 状态与拥有者

已采纳，2026-11-04；与 0120 同次交付。连线插件拥有中转点全局颜色及标题连线约束，调色盘拥有颜色入口和配套主题，画布拥有聚焦。各插件通过既有外观、选择目录、指令及临时信号协议协作。

## 中转点全局颜色

外观种类新增 `connection-junction`。连接拥有者的 document 命名空间 `connectionAppearance` 新增可选 `junction` 记录，独立保存十六进制颜色和修订；缺失时自动按画布背景取色。既有 `connections.appearance@1` 快照增加可选 junctionColor/junctionRevision，外观 read/updatePlan/resetPlan/colors 能力统一处理此项。公开类型为增量扩展，连线数据 14 兼容此前全部记录，13→14 恒等迁移；剪贴板和书籍容器不变。

预览只广播，提交走拥有者修订及原色校验、标准补丁和一次历史；支持取消、撤销、保存重开和全局重置。渲染时只校正显示对比，不修改用户存储色；普通边框使用设置色，选中/悬停继续使用统一提示色。

## 三套配套主题

明调、暗调、护眼分别协调画布、编辑区、栏位、群组、注释、连线及中转点颜色。暗调节点正文改用暗底与可读灰字，消除白色节点表面与浅字的冲突；护眼使用低饱和草木色，明调使用暖灰。

`palette.applyPresetColors@1` 接收版本化的预设 ID，读取外观拥有者计划，将画布、连线、中转点三项 document 颜色作为一次事务提交。界面随后通过原有 `palette.setPreferences` 提交个人 workspace 配色，遵守文档与个人偏好必须分事务的边界。用户微调继续保留；只在点击配套主题时应用新的搭配。色板记录仅统计画布实际对象的用色，不记录未使用的主题样本。

## Shift+L

标题切换指令把中转点纳入选择目录。恰好一个标题对象（文字节点或文本框）与一个中转点时，按选择顺序创建标题虚线；再次执行删除该直接连线。通过现有 create 指令及 inline invoke 提交，保留修订、单事务、撤销和虚实线不共用中转网络的规则；普通 L 和已有标题到标题规则不变。

## 未选择时聚焦整张画布

`canvas.focusSelection` 在空选区时取各拥有者的全部可选实体边界，包括节点、文本框、群组、中转点、连接线及注释；空画布不操作。有选择时保持既有行为。FocusRequest 增加可选 `center-if-overflow` 模式：内容可放入视图时适配显示，超过可用视图时保留当前 zoom 并居中到全部边界中心。其他调用者默认 fit 行为不变。

## 验证

拥有者测试验证颜色修订、独立性、重置/历史、文件兼容、主题对比、标题连接正反顺序及共存实线。Chromium 检查颜色预览/提交/撤销和三套主题外观，Shift+L 连接节点/文本框标题与中转点，以及未选择时紧凑/大范围聚焦。单 HTML 从源码重新生成，发布后仅做两项关键抽查。
