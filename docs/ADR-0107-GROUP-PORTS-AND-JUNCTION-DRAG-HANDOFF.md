# ADR-0107：群组低缩放端口与中转点拖动交接

## 状态

已采纳，2026-11-04。补充 0087、0098、0099，替代群组低于 50% 时禁用端口的旧策略。

## 决定

群组左右边中点保留透明端口，命中区扩大为固定屏幕 48×64 像素，按当前缩放换算到世界尺寸。40% 等低缩放不再移除端口。节点输入适配器与共享群组/中转点拉线适配器使用同一 connectionGroupPortHit 纯几何判定；实际锚点仍在边中点，标题成员端口优先级与群组生命周期不变。

中转点松手时再次采样最终坐标，避免合并的 pointermove 漏掉最终位置。开始与结束仍立即使用唯一交互会话令牌进入队列；位置提交按适配器的完成链串行化。开始与提交通过公开 connections.graph@1 读取权威点状态，当前适配器此前提交的位移可以安全叠加，其他来源的修订仍交给拥有者校验拒绝。旧 capture 丢失事件不能取消新点或重新捕获的会话。取消、热拔插、书籍替换与历史操作继续清理临时状态。

提交成功后保留最后位置预览，直到拥有者的图投影更新，再由令牌所属预览交接；旧操作完成不能清除新操作的预览。临时乐观位置和本适配器的修订缓存按点 ID、修订和坐标匹配，换书和删除时清理。一个完成拖动对应一个现有 connection.moveJunctions 指令及一次撤销；不新增持久字段或消息形态，文件 dataVersion 9、剪贴板 schema 4、容器和权限不变，无需迁移。

## 验证

契约验证不同高度与 40%/100%/240% 下群组命中矩形的屏幕尺寸和边界。真实浏览器验证扩展区域拖出及节点接入群组、40% 低缩放、仅 pointerup 携带最终坐标、连续三次快速移动及逐次撤销、多点移动与取消、群组成员预览、中转点跟随节点，以及旧捕获/修订交接不产生回跳。
