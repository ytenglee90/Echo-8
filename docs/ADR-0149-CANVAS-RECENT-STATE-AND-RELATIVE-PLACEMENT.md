# ADR 0149 画布近期状态与相对摆放

状态为有效，补充 0147、0148。

用户提供的「武器卡排列杂人物卡上方，中间空20PX」首轮请求带有六张卡的元数据、两份旧计划、正文和重复历史。第二次请求再次附上已提供的对象。这些材料主要服务于其他任务。

相对摆放由本地解析产生两个名称、方向和边缘间距，允许常见口语和已报告的输入笔误。canvas-control 解析真实目标并以当前尺寸计算坐标，垂直摆放默认水平居中，水平摆放默认垂直居中。省略间距时为 60 画布单位。两张卡都纳入修订检查，计划只修改所需的节点，预览、核对及撤销沿用现有事务。多个候选仍需选择。「间距改成 35」沿用同一对话最近一次已经应用、回读标记仍匹配的相对摆放。无法核实时询问两张卡。

明确只操作位置且不要求参考正文或记忆时，助手跳过无关正文和已选记忆，只提供位置操作说明、查询和提交计划工具。按正文特征定位时保留正文读取工具。对具名的新位置任务也跳过历史原文。对于涉及位置的简短续接，允许从当前记录读取一千字符以内的近期上下文。普通画布任务最多发送最近四条不同的原话、共 1,200 字符，特意追溯历史时继续使用原有检索。普通对话最多保留近期六条、共 4,000 字符。最新单条超限时保留首尾并标注省略。早期原话优先保留用户明确约束及相关条目，共 1,800 字符。已保存原文和索引仍是历史来源。

模型首轮默认只查选区和本轮对象。需要接续或请求足够简短时，附带最近真实状态和一个相关的最新计划摘要，保留目标、状态及动作数量。状态需要对照当前画布判断是否仍已应用或已经撤销。若位置目录已提供某节点的几何数据，初始状态省略该节点的重复项。模型可以显式查询更多状态。重复工具响应使用先前调用的标识保留关联，原生工具消息仍成对传送。上述变化不增加任何为总结而发出的模型请求。

新增运行时能力 `canvasControl.agentPlan@2`，在原画布计划旁接受可选 `placements`。v1 保持原调用形状。两种输入在画布控制插件内编译为原有坐标操作。书籍、原始对话和数据库结构沿用现有格式。回归覆盖多轮后同一句原话离线执行、无关选区隔离、20 和 35 画布单位的边缘距离、撤销、过期参照卡、旧计划与正文裁剪，以及重复工具响应的原生消息关联。

运行 `node --experimental-strip-types scripts/evaluate-canvas-assistant.ts` 可复现 2 轮和 48 轮合成历史下的请求体大小、目标与回读结果。默认使用模拟模型返回。提供专用环境变量 `ECHO8_TEST_DEEPSEEK_API_KEY` 后可加 `--live`，用同样的合成输入测量真实 DeepSeek HTTP 状态、逐次用量和耗时。每个用例最多发送四次请求。可通过 `ECHO8_TEST_DEEPSEEK_MODEL` 指定测试模型。

模拟对照中，2 轮和 48 轮的首个请求体分别为 8,745 和 8,750 字节，工具续轮分别为 9,816 和 9,821 字节。两组都通过目标、35 画布单位间距和应用后的状态核对。此处测量的是序列化后的请求体，环境缺少测试凭据，尚无真实模型命中率、用量或延迟数据。
