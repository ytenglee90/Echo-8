# ADR 0155 · 助手指令限制、回执与按需对话

状态为有效。补充 0142、0151、0153 和 0154。

## 画布请求

本地分流在命令解析和语义分类前检查只读与预览限制，带引号的标题和正文引用作为数据。已完整识别的排列或移动通过既有本地计划生成预览，画布控制在提交入口再次核对限制。明确要求保留颜色的移动只规划位置。排列改口可以沿用当前计划的列数、间距和排除对象，更换为唯一匹配的群组。原预览在新范围完成校验后才取消。提交继续核对节点和群组修订并进入同一个画布事务。

新增只读能力 `canvasControl.receipt@1`。查询按同会话的准备标识、原始目标或最近收到的回执定位。回执最多保留 32 项，画布替换或插件停用时清理。待确认、已应用、撤销、后来修改、失败、取消和过期沿用画布控制核对。明确追问状态在本机回答，查询记录留在对话且不占用画布撤销步骤。同一发送重试先取回执，已有计划不重新提交。明确要求「再建一份」且最近完成的是独立单节点本地创建时，以新发送标识重新准备。范围含糊时请用户指定对象。既有命令和能力继续兼容，书籍格式无需迁移。

## 模型请求与历史

用户明确要求的字数、词数、条数或一句话参与输出额度计算。定长草稿计算额度时扣除由应用原样保留的首句。续写保留首轮输出额度，用户配置的提示词策略仍可覆盖默认值。请求测量复用服务商序列化代码，分别记录请求体字节数、估算输入 Token 和输出上限。各次真实调用继续由任务用量账本累加。

有明确近距离指代、没有显式资料或选定记忆的对话追问优先读取最后一个完整问答，跳过本地语义分类和画布检索。旧草稿按版本选择并复核原文修订。内部对话目录在收到连续提交的追加事件后只补扫新增范围。撤销、重做、换书和无法确认的修订重新按范围建立目录。可手工编辑的旧式外部对话来源按原方式重新扫描。

测试覆盖离线预览、应用、撤销与回执、同一发送重复提交、明确再建一份时由文本节点分配可用标题、带约束的更换群组、旧草稿原文与首句、按需输出额度及确认追加后读取范围。用量回放属于固定样本和本地估算。
