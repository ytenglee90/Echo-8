## 本次改动

助手保留完整本地语法作为常用操作入口。画布缩放、自动保存间隔、快捷键、完整主题、连线颜色、选中连线端点查询和编号标题的沉浸编辑可通过真实所有者执行。“连接线改为蓝色”不再误拆为连到“线改为蓝色”；不明确的插入和删除范围先澄清，不宣称已经修改。

无法完整编译的工作区操作，根据用户明确选择，使用助手当前所选且已配置的模型解析。目录取自实际可用的动作及参数结构，不把注册数量当成自然语言通过率。解析最多两次请求：需要时先筛选相关动作，再提供相关结构；所有用量与实际请求均计入记录。只提供有界对象元数据，不自动读取正文，并遵守检索隐私标记。名称、位置和关系会发送给所选服务。纯查询返回实际结果；模型提出的修改必须先核对步骤、目标和参数，然后交给原所有者执行。对象在解析或确认前改变时拒绝旧计划，子预览没有提交时保持待确认。

画布控制预览新增全选、取消全选、计数、逐项新建标题编辑和一键避开重名。生成时统一分配可用名称，群组和连线仍绑定本轮新对象。新建专用计划最多 400 个节点及 512 项相关动作，整份原子提交并整体撤销/重做；旧协议及已有对象范围限制保留。80 张不再是用户需要手动拆分的独立新建批次。

助手模型、Prompt 和记忆选择固定在输入框上方，移除重复的顶部控制范围/指令栏。全部指令改为紧凑列表，区分本地指令、模型解析、功能界面和不可用状态。我的用语允许同一动作多个说法及多行添加；默认偏好直接设置横排、竖排和网格间距。群组在画布上显示名称与成员数量，群组管理提供查看、创建、重命名和定位。暗调请求正文使用主题文字色。日志区分聊天、正文生成、查询及语义计划，显示实际规划动作及安全统计，不保留原始正文或密钥。

新增画布计划 v3、`canvasControl.localCreationPlan@1`、`nodesPlan@3`、`groupsPlan@2`、`connectionsPlan@2`、`applyItems@2`、标题编辑/避重名指令、`offerWorkspace@1`、只读 `workspace.plan.validate@1` 和 `group.rename@1`。旧版本继续兼容。书籍格式和数据库表不变，无迁移；不自动升级个人数据 Worker。账户配置仍为此前发布的 v2，匿名用户可浏览目录，保存个人配置仍需连接账户。

自动审批拒绝本次生产 D1 完整 SQL 本地导出，理由是未专门授权复制可能含账户数据的内容。没有绕过拒绝、读取或提交数据库内容。保留此前已有私有备份，并在部署前读取、记录 D1 Time Travel 恢复书签；书签和现有备份均留在忽略目录。此版本没有数据库结构变更。
