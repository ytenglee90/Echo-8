# ADR-0104：中转点线型隔离与群组复制过滤

## 状态

已采纳，2026-11-03；补充 0089、0102，部分替代 0091 中群组复制中转图的规则。

## 决定

同一中转点及由中转点相连的组件只能包含一种线型。连接所有者在添加中转点、创建、重接、快捷连接和路由标题转换前，对修改后的组件校验；虚线与实线混合时拒绝整个操作，文档和历史不变。选择不同线型共享节点也不能合并为一个点。单一路由的完整组件仍可整体转换线型。剪贴板实例化拒绝新建混合线型组件。旧文件中不相关的既有混合组件仍可读取和删除，校验不触发批量改写或删除用户数据。

群组复制不包含中转点或任一端为中转点的线段；内部不经过中转点的普通连线继续复制。连接拥有者使用现有 connections.targets@1 公开群组投影，识别复制选区内的群组 ID，不读取群组私有命名空间。快捷键、导航按钮及 Alt 拖拽都复用同一个 clipboard.serialize@1 入口；普通节点选区仍可复制完整且有效的中转图。

无新增公共请求形态、存储字段或权限；文件 dataVersion 8、容器和剪贴板 schema 3 保持兼容。群组数据、节点和直接内部连线仍一次粘贴事务、一次撤销。

## 验证

契约覆盖混合线型合并、创建和重接拒绝、跨点组件校验、单路线转换、无部分写入或历史条目、群组复制与 Alt 复制不携带中转图而保留直接内部线，以及原有普通节点中转图复制和旧文件往返。浏览器实际操作覆盖键盘、导航按钮和 Alt 拖拽三个入口，并验证点与原连线原位保留以及单次撤销。

快速 Alt 拖拽的提交方式在 pointerup 时以原生修饰键/统一快捷键状态锁定。尚未完成选择解析的已释放手势不再接受后续 keyup 覆盖，确保快速操作与慢速预览同样执行复制。浏览器覆盖释放鼠标后立即释放 Alt 的入口。
