# ADR-0095：Ctrl 拖拽批量加入和移出群组

## 状态

已采纳，2026-11-03；扩展已有群组拖拽规则，保留单节点兼容行为。

## 决定

`group.dropTarget@1` 请求、`group.membership.preview` 临时信号和 `group.membership.drop` 指令增加可选 `nodeIds`，明确本次拖动的完整节点/文本框集合。缺省仍只处理原有 `nodeId`。批量 ID 必须唯一、已存在且与本次移动位置集合一致，目标需在正式指令中重新验证。

Ctrl 拖动已选中的节点时保留整个选择，避免 Ctrl 的选择切换语义提前移除拖动起点。没有实际移动时仍完成普通 Ctrl 点击切换选择。松开修饰键后仅提交位置变化，不改变群组成员；修饰键仍由统一快捷键中心管理。

全部对象尚未分组时，按指针下的原有目标规则整批加入一个群组。已有成员继续采用 Ctrl 表示移出的规则，整批中的已分组对象从各自群组移出；未分组对象只随批次移动。预览同步投影每个受影响群组。全部位置、成员变化，以及不足两人群组解散和相连连接的清理，合并为一次拥有者标记的标准补丁事务，可一次撤销。

文档记录和容器版本不变，无需持久迁移；版本化公开接口以可选字段兼容旧单节点请求。插件实现仍只通过公开能力协作。

Alt 复制预览的原成员仍属于原群组，群组边界投影忽略 `duplicateOriginIds` 对应的位置预览，沿用权威原位置；未加入群组的复制体不影响外框和群组端口。中途松开 Alt 时恢复普通移动预览，再次按住后恢复原边界。复制优先时不显示 Ctrl 成员变更预览。

## 验证

契约覆盖节点与文本框批量加入、跨群组移出及解散、连线与位置的一次撤销、旧请求、无效批次及过期目标零写入。真实浏览器验证混合选择、Ctrl 点击、整批加入/移出、修饰键释放取消成员变更及撤销重做。

浏览器分别复制群组内节点与文本框，持续检查提交前外框及相连路径不变、中途 Alt 释放/恢复、提交后复制体仍未加入群组，并验证撤销。
