# ADR 0162 · 模型辅助解析与可核对的工作区操作

有效。用户明确选择使用助手当前模型兜底解析并接受 Token 用量。本决策替代 0157 的“配置云端模型后仍禁止操作解析兜底”，补充 0159–0161；本地确定性入口、所有者校验、正文范围、事务、记忆证据与文件授权边界继续有效。

## 解析与执行

完整本地语法优先，明确的缩放、快捷键、自动保存、主题、连线颜色及选中连线查询不增加模型请求。无法编译的工作区操作使用发送时选择的已配置模型，而不是把整句话作为节点标题。缺少具体对象或有歧义时澄清；例如“删除所有内容”和“人物 2 插入人物 1 中”不猜测删除范围或插入方式。

AI 所有者通过 `workspace.actions@1` 取得实时可用动作、参数结构、类别和副作用类型。共享纯服务投影模型可用性，指令目录区分本地指令、模型解析、功能界面及不可用状态。没有参数结构、原始画布 JSON 计划、已停用、文件授权、远程账户写入、恢复覆盖与记忆管理不进入兜底目录。注册数量不是自然语言成功率或全覆盖保证。

解析只接收当前要求与有界对象元数据，不读取正文。最多 240 个节点、80 个完整群组、240 条端点均已提供的连线；选中及点名对象优先，尊重上下文目录的 `automaticRetrieval=false`。标题、名称及关系仍会发送给用户所选服务，不能将“没有正文”表述成没有外发。标题视为不可信数据，不能成为指令。目录截断会明确标记，模型不能猜测未提供对象。

按所选连接的上下文窗口估算预算。完整结构不适配时，先发精简动作索引，选择最多 12 项，再只发送相关参数结构；总计最多两次请求，均进入实际请求检查与 Token 统计。相关对象仍无法适配则停止，不用无限重试扩大费用。普通聊天、正文生成和操作解析有不同的日志任务类型。

模型只能返回有界 JSON 步骤或澄清，不能执行工具、脚本或自行写入。校验真实目录、输入结构、提供过的对象及唯一名称后，经新增只读 `workspace.plan.validate@1` 预检。纯查询由原工作区所有者执行并返回实际回执。修改计划经 `canvasControl.offerWorkspace@1` 显示动作、目标和参数，用户确认后才通过 `workspace.plan.run@1` 交回原所有者。

确认时重查发送选区及引用对象标记。助手记录自己的回复会推进文档修订，不能错误地把这类无关变化视为目标过期；同一正式指令内取得最新文档修订并交给工作区所有者。对象确实改变则拒绝。子计划等待文档预览、对象选择或文件授权时，父计划保持待处理，通过原 `workspace.plan.resume@1` 查询/续接实际结果，不提前宣称完成。关闭、切书、取消和停用沿用原生命周期清理。

## 大批量创建与重名

画布计划新增版本 3，最多 512 项且仅允许创建新节点、群组和内部连线，最多 400 个新节点。`canvasControl.localCreationPlan@1` 在所有者接纳前拒绝已有对象修改及外部依赖。节点、群组、连线所有者分别新增 `canvasControl.nodesPlan@3`、`groupsPlan@2`、`connectionsPlan@2`，保留旧协议的 80 对象/100 项限制。新计划完整预检后仍为一个原子事务，整份撤销重做。独立创建的旧 80 张分批方式及回执续接继续有效。已有对象的通用操作范围没有无条件扩宽。

新标题统一由内容所有者 `content.createPlan@1` 分配，包含当前画布及同计划保留名；本轮关系绑定稳定引用，不因避重名连到旧对象。预览新增全选、清空、选择计数、逐项新建标题编辑与“一键避开重名”。`canvasControl.updateTitle@1` / `resolveTitles@1` 只改临时预览；`applyItems@2` 接受最多 512 项，原 @1 上限保持不变。空选择不能隐式提交整份。

## 界面与个人配置

模型、Prompt 与记忆选择固定在输入框上方，移除重复的顶部控制范围/指令栏。指令目录使用紧凑行。默认偏好直接设置横排、竖排、网格间距；我的用语可一次添加多行，同一动作允许多个说法。仍复用账户配置 v2，不新增存储格式或自动升级个人 Data Worker。

群组所有者新增 `group.rename@1`，通过修订检查、标准补丁与一次全局撤销更新名称。群组画布标签和管理面板展示真实名称及成员数量，提供定位、创建、重命名及加入操作。请求检查对话框使用主题文字变量，暗调下正文保持可读。

日志 v2 新增可选任务类别、输出字符数、来源数量和受限动作 ID。日志面板通过公开动作目录显示已规划动作，不记录原始正文、标题、密钥或完整提示词；“查看发送内容”仍是仅当前打开期间保留的单独检查通道，不混入导出诊断。操作记录包括聊天、正文、查询、模型解析及原有保存/索引等核心任务。

## 兼容与验证

书籍格式、数据库、部署边界不变，无数据迁移。旧画布计划、按项应用与个人配置协议保留。协议测试覆盖 400 节点群组的原子撤销/重做、旧版本拒绝超限、外部依赖拒绝、实际 69 项重复创建避重名、连线颜色和端点查询、模型目录/元数据/预览及未知动作拒绝。浏览器验证实际缩放、快捷键、保存间隔、沉浸编辑、群组管理、全选/标题编辑、账户多说法与默认偏好、输入布局和暗调请求检查。发布记录单列完整检查结果及已有跨浏览器兼容问题。
