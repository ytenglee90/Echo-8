# ADR-0094：节点与文本框取消宽度上限

## 状态

已采纳，2026-11-03；替代节点及文本框的 1600 世界坐标宽度上限。

## 决定

内容拥有者的既有版本化摘要协议中，`resizeLimits.maxWidth` 变为可选，缺省表示无宽度上限；原有提供者声明的有限上限仍被画布尊重。节点和文本框均省略该值，画布拖动预览、智能吸附后尺寸、正式创建/调整尺寸、显示方式记忆和旧数据迁移不再截断宽度。最小宽度与高度规则保持原约束，指令继续拒绝非有限数值。

宽度仍为现有有限数值字段，不新增文档字段或容器版本。保存、导入和撤销继续使用原补丁与尺寸记忆，旧文件无需变更。空间索引对超宽对象已有独立集合，避免按宽度分配无限网格桶；正文预览继续受既有文本长度预算限制。

## 验证

两种显示方式分别验证创建和调整超过旧上限、撤销重做、显示方式切换记忆、文件重开、最小宽度及无穷大拒绝。浏览器实际拖动两种对象超过 2000 宽度，并验证撤销重做；继续执行密集画布压力测试。
