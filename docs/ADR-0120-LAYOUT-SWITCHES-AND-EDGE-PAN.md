# ADR-0120：智能布局开关、拖动边缘平移与移除中转点旋转

## 状态

已采纳，2026-11-04。补充 0119；取消 0111 和 0117 中仍保留的手动公共方向旋转。

## 智能布局

`smart-layout` 独立拥有 workspace 命名空间 `smartLayout` 的 `guides`、`snap` 两个布尔偏好，默认均开启，退出重启后保留，不进入书籍内容或撤销历史。公开无参指令 `layout.toggleGuides@1`、`layout.toggleSnap@1` 返回 `SmartLayoutSettings`。它们分别注册统一动作与快捷键，不预占默认组合键；用户在快捷键中心分配按键，输入法、编辑器及冲突规则由既有全局管理器处理。

`layout.snap@1` 与 `layout.resizeSnap@1` 保持原接口，由同一拥有者按偏好决定偏移/尺寸和参考线结果。关闭吸附仍可显示临近参考线，关闭参考线仍可吸附；两者关闭时自由拖动和缩放。提交设置后清除旧参考线。停用插件后删除动作、指令和快捷键，重新启用保留偏好。

## 边缘平移

UI 输入基础层 `use-drag-edge-pan.ts` 由各插件的拖动适配器复用，只维护临时指针、视图和补偿量，不读取或修改业务数据。节点（含文本框）、群组、中转点仍各自拥有拖动预览及最终事务；框选沿用画布拥有的世界坐标锚点和平移生命周期。画布可见区域边缘约 52 屏幕像素内渐进平移，时间步长受限；指针不动时持续更新，离开边缘即停止。每帧只广播 camera preview，并按累计视图位移补偿对象位置；松开后提交一次 camera workspace 状态及原有的一次移动事务。取消或停用时释放 RAF 和临时会话。中转点、群组声明 camera commit 消费权限，不导入画布插件实现。

## 旋转移除与兼容

删除双击中转点旋转指令、按压计数、提示、方向字段的公开类型和手动投影分支。双击被中转点消费且不改变曲线，也不触发画布背景创建。公共切线由当前物理邻接关系自动求解。连线数据升级到 14，13→14 恒等迁移；旧 `handleAngle` 和 `curveBend` 作为不透明数据保留并忽略，旧书和剪贴板继续可读，既有未知数据不丢失。书籍容器及数据库边界不变。

## 验证

拥有者测试覆盖两个开关的独立效果、缩放尺寸、无文档历史、快捷键贡献和热停用；兼容测试覆盖旧方向数据保存重开及自动路由。Chromium 检查五类边缘拖动、停留持续平移、松开停止、普通选择和双击无旋转；类型、静态检查及单 HTML 生成/启动按交付流程完成。发布后只抽查两项核心操作。
