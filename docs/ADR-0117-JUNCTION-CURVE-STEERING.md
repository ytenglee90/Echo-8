# ADR-0117：拖动中转点附近曲线调整共享方向

## 状态

已采纳，2026-11-04。补充 ADR-0111、0116 的方向输入和绘制规则，不改变节点移动、中转点位置或箭头归属规则。

## 输入与拥有者

连接插件拥有此操作。先选中中转点，再拖动与它关联、距点心 48 屏幕像素以内的曲线；点本身和加号保留原用途。Shift、Ctrl、Meta、Alt 保留原有选区等输入含义。远处曲线和普通节点间的曲线保留原操作。

独立的 `use-junction-curve-drag.ts` 负责手势、捕获、取消及提交交接。拖动围绕中转点计算相对于按下时指针的转角，按已有的 15° 偏好量化；不会移动点或节点。关联分支共用同一过渡轴。自动模式仍用原物理邻域算法；手动偏好允许相向端口的混合扇形最多倾斜 45°，控制多边形保持横向单调。反向端口及窄回绕通道保留水平安全限制。样条内部 C2、接点 G2 及防自交约束继续有效。

## 版本化消息与历史

- `connection.junction.handle.preview@1`：只含中转点 id、源修订与临时角度，或清除标志；不进入文档或历史。
- `connection.setJunctionHandle@1`：id、expectedRevision、handleAngle；拥有者检查实体存在、修订一致及角度为 `[0,360)` 中的 15° 整数倍，返回 handleAngle/revision。相同值为无操作。

手势采用已有 `dragging-node` 交互会话，结束先入队 `interaction.end`，再提交一次有修订校验的正式指令、标准补丁和提交后事件。一次拖动只产生一条全局历史。Escape、失去捕获、停止插件或失败清除本会话预览；成功时待拥有者投影确认再清除，避免预览与提交跳变。焦点仍在中转点时由图层捕获阶段处理本手势的 Escape。

复用 dataVersion 11 的 handleAngle 和剪贴板 schema 6，文件容器、数据库及已有内容不变，无需数据迁移。新增消息显式使用版本 1，不覆盖旧双击旋转指令。

## 箭头与线条尺寸

箭头长宽只由统一画布细节缩放计算，不再取决于曲线或末端引导段长度。短引导段保留原曲线在不透明箭头下延伸，不反转短线段、不挪动样条控制点来腾出空间。连线粗细及虚线长度、间隔继续由统一主题变量与画布缩放控制，与连接距离无关；悬停和选中反馈保留。

## 验证

正式指令覆盖无操作、过期修订、无效角度、单次历史及插件停止后的撤销。几何验证涵盖端口边界、防自交、连续性和不同缩放、短引导段的固定箭头尺寸。Chromium 验证拖曲线实时调整所有分支、预览/提交一致、撤销重做、Escape 取消、点位置不变及虚实线的尺寸稳定。单 HTML 由源码生成，文件入口与正式发布只做定向验证。
