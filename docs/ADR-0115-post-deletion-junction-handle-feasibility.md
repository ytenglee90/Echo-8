# ADR-0115：删除重连后的中转手柄可行方向

> 几何实现已由 [ADR-0116](ADR-0116-physical-junction-network-splines.md) 替代；本文保留为历史记录。

## 状态与复现

已采纳，2026-11-04，细化 ADR-0112/0113 的共同方向约束。按照用户完整操作复现：连接多个节点、多选线右击合并中转点、删除主干、从加号连接其他节点。未旋转的 0° 中转点同样出现回折；节点全在同一侧时更加明显。

删除的线没有残留在曲线计算中。问题是合并保留的图关系、删除后保留的分支和新建手势可能具有相反的逻辑方向。仅用输入/输出均值计算公共前向导数，会掩盖某一条分支的方向冲突，把它的自动手柄指向跨度背面。逻辑图方向、几何切线所在直线和手柄应使用该直线的哪一半不能混为一个值。

## 决定

仍由连线插件按真实锚点计算可重建几何。O(E) 累计每点输入/输出均值时，同时记录所有相邻分段在 x/y 上的正向符号约束。先保留已有均值提议与鼓包抑制，再清除任意会令某条分段反向的轴分量。

存在非零可行轴时，继续使用同一个前向导数，包括此前认可的陡峭扇形垂直过渡。若约束矛盾、两个分量都不可行，不强行套用同一有向向量；回退为共同水平切线，各分段根据真实另一端所在半区和 source/target 角色选择方向，保持共线且面向端点。手动 handleAngle 仍是用户显式的 15° 旋转偏移，保留值和撤销语义。

三次曲线的前向控制长度同时受 x/y 距离的一半约束，避免纵向细小跨度被较长斜向手柄穿过。节点水平端口和输入箭头规则不变。重接的实际候选点对直接用于重接绘制、命中和标签，而不从点上任意另一条分段推断方向。

不反转或改写已有图关系，不修改 branchSide、角度、位置、标签，不用删除或重建中转点修补数据。旧文件重新投影即可使用新规则。无新增公开消息或持久字段，connections dataVersion 11、剪贴板 schema 6 和外部容器不变，无数据库迁移。

## 验证

Chromium 首先保存完整操作链的失败截图，确认反向手柄超过跨度；修复后逐张查看四种布局的预览与提交图：中转点居中、全部节点左侧、全部节点右侧，反向关系与镜像布局。验证同一操作的路径预览/提交一致、角度始终为 0°、撤销/重做。保留已认可陡峭布局、15° 双击、自由左右拖线、实虚线接入和箭头重接检查。

拥有者协议回归涵盖实线/虚线、共同输入/输出、三个中转点位置、删除主干/分支组合，检查各阶段的曲线控制顺序、40%/100%/240% 箭头、单事务新增、删除不改变点记录、撤销/重做、移动跨侧和保存重开等价。历史存在相反关系时断言共同切线共线与各自前向，不再错误要求所有分段的有向导数相等。仅使用 Chromium，单 HTML 重新构建，发布后仅做完整操作链的定向复查。
