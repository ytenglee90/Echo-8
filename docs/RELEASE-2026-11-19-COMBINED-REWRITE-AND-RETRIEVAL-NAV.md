# 2026-11-19 · 本地沉浸写作与组合改写

产品提交 `049b4ed`。边界说明见 [ADR 0166](ADR-0166-SETTINGS-NAVIGATION-AND-LOCAL-CONTROLS.md)。

## 行为

- “打开空白11的沉浸写作模式”由本地工作区语言服务识别，通过已有编辑器动作打开对应正文并进入沉浸模式，不发送模型请求。也支持“进入/切到/切换到……的沉浸写作模式”；数字标题沿用已有规范化定位。
- “用新的节点插入内容，标题为周明瑞，内容为改写后的未命名节点的内容，”按创建、标题、改写来源绑定。三个完整字段支持六种排列，引号中的逗号保留为标题数据；缺失、重复或附带未知字段不部分执行。只对指定来源调用一次正文生成，实际创建命名新节点、保留原节点，并可一次撤销。正文改写仍产生模型用量，目标绑定与建卡不增加模型规划调用。
- 移除 AI 模型连接页面底部重复的“打开检索设置”按钮，检索功能继续从设置中心的“检索”分类进入。清除对应声明和样式；修正窄屏迁移卡片受旧 flex 基值影响被拉高的问题。

所有者分别为工作区语言服务、AI 助手与 AI 模型连接插件。复用既有公开动作、事务、修订校验和历史，不改变公开协议、书籍格式、连接配置或数据库，无迁移，不升级个人数据 Worker。
