# ADR-0108：标题创建参照与对齐区外的自动选边

## 状态

已采纳，2026-11-04。修正 0105、0106 中对齐区外仍按原方向相对翻转的规则。

## 决定

标题连接的预览和刚完成连接保留实际拉线侧；水平对齐区内同样保留原操作方向。节点水平相对关系改变且超出对齐范围后，直接按当前水平中心位置自动选边：源在左则左/左，源在右则右/右，不再把原侧反向映射到错误方向。整体平移两个端点不改变相对关系，不触发换侧。文字节点、文本框和混合形态一致，群组/中转点相向规则与正文输入箭头不变。

现有 titleOrigin 增加成对的可选 sourceCenterX、targetCenterX，记录创建或显式重接时的权威水平中心参照。保持初始水平差值或落在对齐区时使用原侧，否则使用自动侧。预览每帧以临时当前参照保留指针起始侧；正式拥有者从实际几何记录参照。复制时两端参照随粘贴位移平移。缺少参照的旧记录在对齐区使用原侧，区外使用现行自动侧，原字段保留。

## 版本与兼容

连线 dataVersion 9→10，9→10 恒等迁移保留旧记录与未知字段。剪贴板 payload schema 4→5，继续接受无版本、2、3、4；新参照必须成对且为有限数。文件容器、命名空间、权限和部署边界不变，无数据库迁移。

## 验证

契约覆盖初建手动侧、整体平移、对齐区内微调、左右跨出范围后按绝对相对位置选边、文字节点/文本框转换、保存重开、9→10 迁移、未知字段保留及复制时参照同步偏移。浏览器覆盖左右标题端口的初建与移动、上下文本框先小幅微调再明显错开、撤销及三线中转和低缩放连线回归。

选择目录的几何修订包含最终水平端口侧，确保同坐标重接仅更新初始参照导致换侧时，绘制与命中/框选缓存同步刷新。
