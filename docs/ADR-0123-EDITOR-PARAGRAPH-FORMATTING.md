# ADR-0123：段落独立排版与光标格式回显

## 状态与归属

已采纳，2026-11-05。编辑器拥有格式目标、工具栏回显和 DOM 投影；文本节点拥有格式校验、正文范围扩展、持久标记和事务。补充 ADR-0004、ADR-0088。保留原有三个可选级别与旧文档的任意合法数值。

## 格式作用范围

- 光标位于正文段落、没有选中文字时，修改当前段落，而不是整篇默认值。
- 选中文字时，字号、字重、字距和颜色只作用于选区；行距、首行缩进和段后空行作用于选区涉及的完整段落。选区恰好结束于换行后时不包含下一段。
- 全选正文同样覆盖已有局部格式。空正文或尚未建立正文光标时保留默认格式设置；双击格式刷仍显式清除所有默认及局部格式。
- 包括开头空段、中间空段和末尾空段。末尾空段通过现有 paragraph 标记的等值起止锚点表达；输入后扩展为普通段落范围。段落首端吸收同段开头输入，末尾非空段吸收追加输入；已有选区标记仍排除外侧边界输入。

## 版本与兼容

新增独立 schemaVersion 1 指令 `content.applyFormatting`，复用现有请求字段及格式快照。旧 `content.setRangeFormat` 的非空范围和单标记契约继续可用。新指令由文本所有者将混合补丁拆分为选区文字部分和整段排版部分，在同一修订校验和原子事务中提交；不在编辑器内调用文本插件私有实现。跨编辑窗口的完整段落由所有者每次至多读取一个 64 KiB 分块寻找边界，不拼接整篇正文。

继续使用 textFormat storageVersion 2、TextFormatMark 的原有字段和段落作用域，没有新增文档命名空间、记录字段或单位；书籍容器和插件数据版本不变，无需重写既有书籍。旧标记按原顺序读取；旧 selection 标记中的段落字段在投影时解释为所在段落的布局，属于派生显示兼容处理，不改写原记录。已有锚点变换扩展为保留 paragraph 等值范围；selection 的空标记仍移除。兼容测试同时保留旧命令，验证新段落与空段标记的保存重开及撤销重做。

最新格式标记拥有最高优先级，返回预览与持久 markIds 使用同一顺序。只合并同范围的最新标记，避免为修改一个字段而重新提升旧标记的其他字段。整段格式与局部文字格式可以按操作顺序相互覆盖。

## 排版单位与回显

- 字号使用 px，字距继续使用 px，不重新解释旧数值。
- 行距使用无单位倍数，子文字随各自字号计算行高；不再把段落排版字段施加到局部 span。
- 首行缩进按段首文字的字号加字距计算一个字的步长，缩进字数乘以步长。
- 段后空行按该段基准字号 × 行距倍数 × 空行数计算；不往纯文本中插入换行。
- 工具栏在鼠标、键盘移动光标时读取实际当前位置格式，段落字段按当前段落解析，不从上一段末端继承回显。跨选区每个字段分别判定混合；混合项不假装显示默认值，选定一个级别后统一该属性。
- 混合判定使用有优先级的区间扫描，先为已挂载的至多 256 KiB 窗口建立换行索引，再按标记进行二分定位和 O(字段数 × 标记数 log 标记数) 区间扫描，不为每个标记重新扫描长段落，也不加载整篇正文；工具栏按文档和选区缓存结果。

## 验证

覆盖逐段独立设置、混合字号/行高、字距与缩进配合、段后空行计算、选区结束换行边界、全选覆盖、空段输入、跨窗口段落、旧命令兼容、格式标记顺序、陈旧修订拒绝、文件保存重开及撤销重做。Chromium 定向回归包含格式刷、前方输入/换行/粘贴/IME、纠错及补全、编辑器重开和逐帧格式稳定。便携 HTML 从源码重建并通过 file:// 检查。按用户偏好不执行 Firefox/WebKit，也不在发布后重复整套回归。
