# ADR-0065：连线文字、水平端点切线与自适应箭头

## 状态

已采纳。补充 ADR-0017，并替代 ADR-0064 中标题连线依靠纵向控制点扇出的局部决定。

## 问题

标题栏连线的首尾控制点带有纵向偏移，箭头虽然使用 SVG 自动定向，视觉上仍会以斜向进入目标，无法保持端点处的水平方向。原箭头尺寸也偏小。连线还缺少自己的关系文字；如果把文字仅放在视图状态中，它不能参与保存、复制和全局历史。

## 决定

1. 普通连线与标题栏连线都使用单段三次贝塞尔曲线，首控制点与起点同高，末控制点与终点同高。两端切线因此始终水平；普通端点控制柄的最小长度增至 160 世界单位，并同时参考横向间距与纵向跨度、上限为 420 世界单位。普通曲线按端口语义定向：右端口始终向右离开，左端口始终从左侧进入；即使两个节点横向重叠，也不再根据边缘端点的相对 X 坐标把曲线和箭头翻转。标题栏左侧外扩的最小幅度同样增至 160 世界单位、上限增至 320 世界单位，使起止段的曲率更清晰。
2. 目标端不再叠加 SVG marker。可见连线路径的曲线轴线终止于箭头底部中心，同一个 `d` 随后闭合出实心三角箭头；曲线和箭头仍由一个 SVG path 绘制，不存在 marker 尾段、重复箭头元素或接缝。箭头以 100% 画布缩放下约 14×14 px 为基准，并随末端切线自动定向；缩小画布时遵循第 8 条的柔和补偿。普通、悬停和选中状态同时继承同一路径的画布自适应填充色与描边色。
3. `ConnectionRecord` 增加可选的 `label`、必需的 `labelWidth`/`labelHeight` 和必需的 `revision`。标签最多 200 个字符，尺寸限制为 80–640×36–320 屏幕像素，缺省为 180×48。`connection.setLabel` 校验期望版本，在一个文档事务内更新标签和版本；空白标签删除该字段。`connection.resizeLabel` 同样校验期望版本并以一个事务提交最终尺寸。
4. 双击连线命中几何、已有文字本身，或聚焦后按 F2，在曲线的近似弧长中点打开多行临时文本域。输入状态不进入文档；普通 Enter、点击画布空白处或其他失焦操作提交，Ctrl/⌘+Enter 在光标处插入换行，Escape 取消。标签按持久尺寸自动换行并裁剪溢出，右下角提供与节点一致的缩放角标。拖动过程通过 `connection.label.resize.preview` 发布临时尺寸，松手后才发送一次 `connection.resizeLabel`，因此历史中只产生一个调整动作。显示标签以实际画布色作为底色，在 100% 基准下使用 12px 文字和 1px 边框；普通状态的文字与边框使用连线色，悬停、选中和编辑状态与对应连线同步使用自适应选择色，不使用阴影。标签在世界 SVG 组内应用第 8 条的补偿变换，因此位置跟随曲线，文字、边框和已调整尺寸按同一柔和比例变化。
5. 标签及其尺寸跟随保存、恢复、撤销、重做与内部剪贴板。粘贴产生的新连线保留标签和尺寸并把修订号重置为 1。连接插件数据版本先从 2 升到 3，为旧连接补 `revision: 1`；本次再从 4 升到 5，`4 -> 5` 迁移为旧连接补缺省标签尺寸并保留未知字段。项目容器和剪贴板 bundle 版本不变。
6. 密集模式仍把未标注连线合并为一个 SVG 路径，只为实际含标签的连线增加中点标签 DOM；双击命中继续使用空间索引候选和曲线距离。
7. 交互 SVG 模式按稳定顺序先绘制未选中连线、再绘制选中连线，因此选中的曲线及其命中区域自动位于其他曲线前方；密集模式继续使用位于批量路径之后的选中覆盖层。普通连线、箭头、标签文字和标签边框统一使用连接插件提供的 `--connection-line`；没有颜色覆盖时它等于原有的画布自适应线色，用户在全局颜色设置中选择颜色后则使用经过 3:1 背景对比校正的结果。选中或悬停时曲线与文字一起切换为 `--canvas-selection`，编辑输入也与已选曲线同色。悬停、键盘聚焦和选中只改变自适应颜色与绘制层级，曲线及一体式箭头始终保持与同一缩放级别普通状态相同的补偿描边，不再加粗。
8. 连接视觉采用统一的柔和屏幕尺寸补偿。100% 以下的实际屏幕比例取画布缩放比例的平方根，即只抵消一半的对数缩放：40% 时曲线描边、箭头、标签显示框、文字、边框和编辑框约为 100% 基准尺寸的 63%，而不是完全补偿后的 100%，也不是无补偿的 40%。100% 以上保持基准屏幕尺寸上限。可见曲线描边、箭头几何和完整标签框使用同一世界比例；透明命中区仍单独使用 `non-scaling-stroke`，保证缩小视图时容易选中但不产生额外视觉。补偿只属于渲染层，不进入连接记录、持久化或撤销历史。

## 兼容性

- 数据版本 1 依次经过既有 `1 -> 2`、`2 -> 3`、`3 -> 4` 和新增 `4 -> 5` 迁移。
- 旧连接获得修订号和缺省标签尺寸后可直接编辑、换行和缩放文字框，端点、文字和创建时间不变。
- 新版标签属于连接命名空间；停用连接插件时仍按不透明插件数据保留。

## 验证

- 纯函数测试核对标题曲线首末控制点的纵坐标和曲线中点。
- 插件合同测试覆盖标签与尺寸命令、版本冲突边界、换行保留、撤销重做、保存重开、迁移和复制粘贴。
- Chromium 工作流从真实曲线双击添加自动换行文字，再从已有文字重开并用 Ctrl+Enter 插入换行、点击空白提交；拖动右下角角标调整宽高，并核对标签在 40% 最小画布缩放下仍按柔和比例保留其调整结果，同时继续验证无 marker/尾段的同路径实心大箭头、水平端点切线、加大的曲率和悬停缩放。
- 同一浏览器流程比较 100% 与 40% 下的曲线描边、箭头长宽、标签字体、标签边框和标签外框，验证它们约缩至 63% 且使用同一补偿比例。
- 几何测试验证选中连线稳定后置绘制；浏览器测试同时比较普通和选中状态下标签文字与曲线的实际计算颜色，并核对普通、悬停和选中状态始终保持 1.5 px 描边。
- 完整类型、代码规范、单元、浏览器、便携构建和 `file://` 回归作为发布门禁。
