# ADR 0158 · 助手组合任务、账户用语与偏好

有效。补充 ADR 0127、0133、0155 和 0157。

## 本轮范围

用户自然语言决定每步读写和历史取材范围。画布只读、预览及本次禁用长期历史是本地限制。禁用历史时清空当前准备的长记忆索引和手工选择，保留明确引用和必要的近距离指代。公开操作仍执行现有权限、确认、修订与生命周期校验。

输入框保留编辑和发送控件。对话保留实际使用的来源和执行结果。问候、助手身份问题及与已选档案无关的独立问答走无资料路径，简短追问优先查阅当前对话的最近一轮。用户明确要求回忆时仍按所选范围查询经验证的原文。

画布正文意图识别兼容先说明写入位置、先说明要写什么，以及引用同一对话的上一段内容。生成新正文前在本地绑定目标。已有草稿的写入在本地使用完整原文，遇到指明主题的请求时核对原问题或草稿主题。

## 组合计划

助手按保留引用文字的规则拆分动作。规则覆盖的结构操作交给画布控制，通过 `canvasControl.prepareCompound@1` 捕获选区、解析端点、绑定已有及本轮新建对象，并预检各所有者生成的事务。计划可包含标题、正文、连接和删除，无法满足的步骤阻止整组。云端只接收创作子要求及必要原文，返回严格的 `texts` 数据，不参与拆解、对象定位和执行规划。

`canvasControl.completeCompound@1` 由画布所有者把文本合入此前的本地计划，仍通过既有 offer、review、apply、commit 和回执通道应用。删除使用原有审查并展示已知的关联连线。取消或移除待应用方案的删除项走 `canvasControl.revisePending@1`。无需改变既有画布计划、书籍和撤销格式。

## 账户配置

个人用语和横排间距进入统一设置中心。AI 助手管理交互、候选和内存中的登录会话快照。云同步提供 `account.assistantPreferenceScope@1` 和 `account.assistantPreferences@1`，通过既有账户身份访问个人数据 Worker 8 的 `GET/PUT /v2/assistant-preferences`。新增 D1 表 `account_assistant_preferences`，按签名身份隔离，本次更新带期望修订。升级 SQL 可重复执行，旧版设置和快捷键保持兼容。原始聊天、模型密钥和书籍正文不进入偏好资源或导出文件。

配置和 JSON 交换格式都为 v1。支持全局和当前云端书籍范围。用语只能映射到受支持的选区编组或横排、竖排动作。自动学习默认关闭，明确纠正与上一条用语匹配时提取候选，候选经确认才参与路由。识别及提取使用本地规则，规则关闭后保留数据。明确标准动作和本次参数优先于习惯。

开启学习后，连续三次明确指定同一个横排间距，且操作已经提交并完成回读核对时，程序会自动提出间距候选。计数留在当前账户与书籍的运行状态。候选以既有 v1 格式的停用反馈条目保存，确认后才启用。现有同范围默认值优先。账户只接收候选数字、来源和适用范围，不接收完整对话。
