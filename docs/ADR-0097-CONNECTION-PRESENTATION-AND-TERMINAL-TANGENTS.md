# ADR-0097：连接的形态投影与水平箭头接入

## 状态

已采纳，2026-11-03；补充 ADR-0093，替代 ADR-0091 中以截断弦线决定箭头方向的策略。

## 决定

箭头方向取最终贝塞尔控制柄的导数方向。在线身截断后，将末端及最后控制柄投影到箭头轴上，使线身到箭头基部的切线保持一致，消除中转点分支斜率较大时的折角。节点和文本框端口为水平，因此其箭头和线尾均水平；中转点仍无输入箭头，原有共享切线、缩放补偿、开放虚线与独立实心箭头不变。

公共连接几何增加可选 `presentation`，缺省仍表示文字节点。实线语义连接左右正文中点；虚线连接文字节点的左右标题中线，连接文本框时投影到其左右边中点。转换只改变几何投影，保留既有连接属性、ID、标签和历史；转换回节点后自动恢复标题或正文接入位置。`titleRoute` 也参与真实节点端点投影，兼容已有中转分支。

节点、文本框、群组和中转点的拉线适配器共用标题端口命中规则。文本框拖到节点左右标题端口时创建标题虚线；源端口语义在手势内独立保存，离开标题目标后可恢复原普通连接预览，不会意外锁定虚线。文本框本身没有标题栏命中区。

形态纳入内容几何缓存及选择几何修订，即使转换前后宽高相同也立即重算连接。所有拖动保持临时预览和一次正式连接指令；不存在转换后通过事件补写连接的额外事务。

这是既有版本化几何接口的可选元数据扩展，不新增持久字段；连线数据版本 8 与项目容器保持不变，无需迁移旧文件。

拖动线身复用正式线型规则，默认实线，源/目标为标题或中转点继承标题关系时才使用虚线；`ConnectionDraft.titleRoute` 是可选临时元数据。进入或移出标题目标立即切换，不等正式连接提交，也不影响实心箭头。

## 验证

单元覆盖陡峭分支的左右接入及各缩放、双标题端口命中和移出恢复、同尺寸形态转换、线型保留、一次撤销重做及文件重开。浏览器覆盖文本框拉入左右标题口、实虚线的同尺寸转换与撤销，以及中转点拉出的实线/虚线到节点或文本框的水平箭头和线尾，并检查实际截图。完整回归、密集画布、跨浏览器和真实 file:// 构建继续作为发布门禁。
