# ADR 0167 · 简单界面控制的本地覆盖

有效，补充 ADR 0159、0162、0166。用户要求系统检查打开、关闭、切换，能由本地功能执行时不请求大模型，不依赖用户逐条发现遗漏。

## 所有权与执行

`workspace-controls` 服务共享完整句式的界面名称和动作适配，工作区语言编译器和目录输入解析共同使用；不读取插件私有状态、不调用 DOM。设置、检索、插件、模型连接、群组管理、书库、查找、外观、日志、命令面板及保留的画布控制入口均指向原所有者。命令面板与画布控制的导航按钮不恢复，开发者工作区动作入口不恢复。

开/关/切换保留明确含义：智能参考线、吸附、纠错、补全、小地图开关由现有所有者执行并回读；画布工具明确绑定选择或手形。编辑器支持具名正文、发送时唯一选中节点、当前窗格、上下窗格及沉浸进入/退出/切换。当前窗格不存在时本地提示，不猜一个节点。

助手记忆/模板/对话视图、联网、自动记忆候选及自动取材绑定发送窗口 ID；“关闭当前助手”仅最小化该窗口，“关闭全部助手”保留原全部最小化命令。启用自动记忆是用户明确选择，之后普通模型回答产生候选的既有用量策略不变；本地操作本身不触发自动提炼。切换模型只从公开 provider 目录精确匹配已配置的唯一 ID、完整名称或模型名，同名或缺失在本地澄清，不调用模型选择。

自动保存开关沿用个人偏好所有者。关闭设为零；开启时保留已有非零间隔，已关闭则采用既有默认一分钟。无新增持久字段，不虚构未保留的关闭前间隔；本机恢复日志仍由原系统独立管理。

新增 `system.ui.closeSettings@1`，无参数，返回 `{ closed: boolean }`。UI 内核只从已注册设置页和当前 `right.primary` 表面核对拥有者，内联调用该表面已声明的关闭命令；无设置页时返回 false，不模拟 Esc、不关闭助手或任意非设置浮层。原 `openSettings@1` 及所有页面命令保持兼容。已有 editor 与 AI 命令补齐静态注册类型，不改变运行时载荷。

## 解析与费用

共享规则只接受完整指令；引号内节点名保持字面值，疑问/假设不执行，否定句在本地回应。缺少主题、工具、节点名称等必要参数时本地澄清，不付费猜测。仍保留对真正未覆盖语义的授权模型兜底，但已识别的本地动作停用、目标缺失、重名、选区不符或所有者失败不转成模型重试。

组合指令必须完整编译且通过现有计划预检；含未知步骤不部分执行。目的描述与单次打开设置的既有表达保留；带未知附加逗号子句的面板请求不做宽松子串执行。执行步骤、状态与 Token 元数据继续由原日志/回复路径记录为本地用量零。

## 验证与兼容

独立验收词汇覆盖 121 种面板动作/语序；动态核对当前所有无必填载荷的打开、关闭、切换动作均有本地路由，后续新增漏接会使测试失败。目录提供新增的已验证示例。测试同时验证真实所有者、设置关闭权限边界、窗口绑定、唯一模型匹配、否定/缺参/未知组合拒绝、浏览器实际状态与网络请求数。

公开新增命令版本为 1，目录沿用兼容扩展的 `workspace.actions@1`。书籍、账户配置、数据库、模型连接备份与部署边界不变，无迁移，不升级个人数据 Worker。单 HTML 仅从源码重新构建。发布验证及已知兼容问题在单独发布记录中如实列出。
