# ADR-0112：中转点共用流向切线与曲率过渡

## 状态

已采纳，2026-11-04。取代 ADR-0105、ADR-0111 中每条分段独立使用水平导数的几何策略。

## 问题

同侧节点在陡峭扇形布局中，经常出现主干向左进入中转点、分支向右离开的 180° 回折。缩短水平手柄或逐段旋转不能解决输入、输出导数相反的问题。须以用户截图的布局实际渲染验证，不能只验证节点端的水平接入。

## 决定

连线插件先投影普通端点的真实锚点，再以 O(E) 增量均值计算中转点的公共前向轴：输出锚点均值减去输入锚点均值。只有输入或输出时使用中转点位置补全；退化时依次尝试点到输出或输入到点，仍重合则回退向右。所有输入末端和输出起端使用同一个前向导数，消除点处的方向反转。handleAngle 继续表示顺时针 15° 倍数，改为对公共自动轴施加同一偏移；保存的角度、位置、左右端口元数据不重写。

每条涉及中转点的曲线用三个均匀参数的三次 Bézier 段，内部一、二阶导数连续，两端加速度为零。不同分支在中转点拥有相同单位切线及零曲率。手柄长度根据跨度与前向分量限幅；普通节点端附加水平直线引导段，保持箭头与端口水平衔接。重合端点生成零长度路径，不产生额外环。普通节点之间的原有曲线与标题同侧选边不变；实线输入口箭头、输出口无箭头和中转点无箭头规则不变。

绘制、边界、框选、命中、标签位置和批量 SVG 共用同一分段几何，不增加逐段 DOM。新建及重接预览把临时候选边纳入投影，重接时排除旧边；关联中转点的已有分支也随候选流向更新，并纳入临时可视区域检查。预览仍为临时状态，结束只走既有拥有者指令和事务。

## 兼容性与验证

没有新增公开消息或持久字段，容器、connections dataVersion 11、剪贴板 schema 6 保持不变；旧文件和未知字段原样往返。现有 handleAngle 使用值不变，渲染时采用新的公共自动轴。无需数据库迁移。

定向验证截图中的窄横向、长纵向布局以及镜像左右布局，实线/虚线、汇入/分出、24 个手动角度、曲线各段切向与曲率连续、水平箭头、40%/100%/240% 几何、拖拽预览、撤销和文件往返。Chromium 保存并人工查看修复前后复现图，补充单 HTML file:// 启动检查。遵循用户偏好，不运行 Firefox/WebKit；发布后只做定向轻量复查。
