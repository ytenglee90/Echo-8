# ADR-0118：单条曲线独立调整与共享接点平滑

## 状态

已由 ADR-0119 取代，2026-11-04；用户要求移除拖动曲线调向。以下保留历史设计记录。

## 拥有者与输入

连线插件独立拥有 `use-curve-bend-drag.ts`、正式指令、临时预览和几何求解。选中中转点或一条连线后，在中转点附近 48 屏幕像素内拖动该线，只修改命中的连接实体；其他连接记录、中转点坐标及公共 handleAngle 均不变。普通远处点击、修饰键选区、点移动和加号拉线保留原含义。

拖动改变单条样条的内部控制多边形，不改变接点公共切线、短主干或节点端口方向。首尾三个控制点仍共线，保持端部零曲率及 G2 接合；内部仍为 C2 B 样条。正常相向端口为内部控制点保留横向空间，以横向单调约束避免回折和自交；近距离反向端口调节已有绕行通道的净空。不可行的几何调整受限，不用旋转公共轴来代偿。

## 消息与文件版本

- `connection.setCurveBend@1`：`id, end, angle, expectedRevision`。end 为 from/to，必须是现存中转点端；angle 为 -75 至 75 的 15° 整数倍。拥有者验证连接修订、端点及参数，无操作不记历史。
- `connection.curve.bend.preview@1`：同一源修订及临时调整值，或清除标志。预览只覆盖该记录的临时投影，所有绘制、命中及标签仍使用同一 RoutePlan。
- 移除 ADR-0117 错误的 `connection.setJunctionHandle@1`、`connection.junction.handle.preview@1` 和旧拖动 hook；双击使用原 `connection.rotateJunctionHandle`，不会与单线拖动交叉。

连接数据升级到 **12**，新增可选 `curveBend: { from?: number; to?: number }`；无字段或零值保持原几何。11→12 为保留全部已有和未知数据的恒等迁移。剪贴板连接负载升级到 **7**，读取继续兼容旧 2–6。书籍容器及数据库边界不变，旧书可直接导入；不往中转点增加另一份连线状态。

重新接线、插入或删除中转点时按真实端点身份转移单线调整值，移除被替换端点的调整值，防止断开的手柄方向残留。复制只有被既有复制规则允许的连线才继承该字段。字段经过运行时验证，非法外部几何偏好不参与路由。

## 提交与验证

拖动保持临时状态，松开结束交互会话后提交一次修订检查指令和标准补丁；拥有者投影确认后清除预览。取消、停用和失败释放本会话资源。一次拖动对应一次全局撤销，支持重做和保存重开。

Chromium 定向验证 100%/40%、输入/输出端、预览/提交、取消/撤销，并逐条断言目标曲线改变、旁支路径完全不变、中转点不动。拥有者验证单事务、过期修订、文件 12、剪贴板 7、旧数据迁移和重接清理；几何边界检查共享切线、连续性及自交。单 HTML 从源码生成，发布后只检查两项关键操作。
