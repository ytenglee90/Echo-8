# ADR-0119：移除拖动曲线调向

## 状态

已采纳，2026-11-04。用户因调节受限、曲线难以命中而要求删除此功能。本决策取代 ADR-0118；ADR-0117 的固定箭头和线宽规则仍有效。

## 边界与行为

连线插件删除曲线拖动 hook、预览状态/信号、正式调向指令、专用类型、端点偏好转移助手和内部控制点偏移算法。点击曲线继续按统一选择规则处理，中转点移动、加号拉线、箭头重连及原有双击公共方向功能保持既有行为。普通连线和中转网络均使用自动路由，不再解释单线偏移。

## 兼容与验证

连线数据版本升至 13，12→13 为恒等迁移；旧的 `curveBend` 扩展数据作为不透明数据保留，既不参与路由，也不阻止文件、剪贴板或恢复日志加载。剪贴板 7 继续兼容此前版本；容器和数据库格式不变。移除 `connection.setCurveBend@1` 和 `connection.curve.bend.preview@1`，不提供另一套调向入口。

定向验证旧数据保存重开及自动路由、已移除的协议、普通曲线选择、中转点预览提交和箭头重连。检查仅用 Chromium；单 HTML 由源码重新生成，发布后只抽查两项关键操作。
