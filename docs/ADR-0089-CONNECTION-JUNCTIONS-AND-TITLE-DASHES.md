# ADR-0089：连接中转点与标题虚线

## 状态

已采纳。补充 ADR-0002、0017、0026、0060、0064、0065、0086、0087。

工具栏交互由 ADR-0131 补充：只根据选中的连线添加中转点，选中中转点时显示解除图标；正文和标题操作分开切换。原数据模型、指令和快捷键继续兼容。

## 所有权和模型

`connections` 继续拥有全部线段、文字框和新的 `connectionJunction` 文档命名空间。中转点有稳定 ID、世界坐标中心和修订号，不是文字节点，不进入正文、AI 内容目录或文字统计。端点 schema v2 新增可选 `kind: junction`；缺省仍是原来的文字节点端点。线段保留原有 ID、颜色、文字和文字框尺寸，新增主干标记 `junctionTrunk`；中转点的 `branchSide` 记录原分支方向，以便删除其他分支后仍能恢复正确身份。

`connections.graph@1` 提供版本为 1 的 `{connections, junctions}` 图快照。既有 `connections.list@1` 继续返回以真实节点为两端的逻辑连接及原分支 ID，避免旧消费者把中转点当作正文节点。公开创建、连接切换及标题切换指令识别已经经过中转点的关系，不重复创建直连或破坏共享路线。

## 操作语义

1. 选中连接线后，在画布或线条上右击，输入适配器分发 `connection.addJunctionFromContext`，由连接所有者读取当前选择，并通过内联指令调用 `connection.addJunction`。右键是逐次排队的正式意图，不使用会合并丢失操作的帧预览信号。没有选中连接线或正在文字输入时保留原生右键行为。
2. 单条连接在点击位置拆成两个独立线段。多条连接只有在共同输入同一端点或共同输出同一端点时，才合并成一个中转点和一条公共主干。整个拆分或合并只提交一个事务；无效方向、重复 ID 或过期修订不写入任何数据。
3. 原分支保留文字与外观，文字框仍放在该分支曲线的中间。主干默认不复制文字。再次拆分节点旁的分支时，文字留在靠真实节点的一侧。节点、点或相机移动时从同一组端点几何推导线条、箭头、文字框、命中和框选范围。
4. 删除线段只删除选中的线段，保留中转点和其他分支。删除中转点则把仍存在的入边和出边接回对应节点；原分支的 ID、文字和外观继续保留。显式一同删除的线段或节点不会被恢复。删除多个点、节点和线段通过拥有者的 `entity.deletePlan@1` 与其他插件一次原子提交。已经删掉主干的一侧不会因删除孤立点而凭空重建旧连接。
5. 拖动先取得带唯一令牌的 `dragging-node` 交互会话，移动时广播临时位置和参考线，释放时先结束该会话，再提交一次带修订校验的 `connection.moveJunction`。取消和停用释放捕获、参考线和预览，迟到的清理不能清除较新的手势。方向键通过逐次排队的相对移动指令避免快速输入使用旧修订。
6. 选择目录声明 `connection-junction` 实体。智能布局从公开目录把它作为中心点参考，因此节点与群组可向点对齐，点也可吸附节点、群组及其他点；拖动自身从候选中排除。连接提交后才刷新参考索引，帧预览不进入文档历史。
7. 快捷键中心与命令面板注册“在鼠标位置添加连接中转点”和“删除选中中转点并恢复节点连接”。默认不占用额外按键，用户可设置自己的绑定。添加使用画布公开指针位置，移除也可使用已有 Delete/Backspace 选择删除操作。

## 标题虚线

标题端点连接的线条和文字框边框均为虚线。`titleRoute` 在中转拆分后保留标题路线语义，使两个端点都是中转点的内部主干也保持虚线。选中、悬停、文字编辑和缩放不改变线型。密集 SVG 批量路径按颜色及线型分别合并，避免普通实线被一起改成虚线；显示、编辑中的文字框都保留虚线边框。普通连接线继续沿用原来的实线外观。

## 存储与兼容

连接插件 `dataVersion` 从 6 升为 7，`6 -> 7` 迁移仅增加空中转点命名空间，旧连接、标题端点、颜色、文字和尺寸不变。`.echo8` 容器仍为 version 2；较旧应用按既有数据版本门禁拒绝新版连接数据，避免丢弃中转点。内部剪贴板容器保留 version 1，连接拥有者载荷使用显式 `schemaVersion: 2` 并仍接受旧载荷。复制节点集合时携带它们之间必要的点与线段，统一重映射 ID、偏移点坐标，并在同一粘贴事务中提交；只复制单个节点不携带指向未选节点的半条路线。

## 性能与验证

中转点 DOM 按视口裁剪；连接继续使用原有视口空间索引和大规模批量路径。通用空间索引对超过 4096 网格单元或不安全整数网格坐标的对象改用稀疏溢出集合，大范围查询回退到记录过滤，避免任意拖远的曲线申请数百万网格或导致循环无法前进。正常小范围索引和查询规则不变。

定向测试覆盖两个合并方向、无效／过期请求原子拒绝、移动和吸附、线段删除、中转点绕接、一次撤销重做、共享主干保留、复制粘贴、旧格式迁移、保存重开、插件停用后的历史、旧版逻辑端点、快速右键与键盘意图、极远空间范围，以及实际 Chromium/WebKit 中的右键、拖动、快捷键绑定和标题虚线。完整合同、托管浏览器、2,000 节点／2,000 万字符压力门禁与 `file://` 单文件验证继续执行。
