# ADR 0142：任务累计用量、按需上下文与确定性操作

状态：有效；补充 0138–0141。所有权为 ai-assistant、ai-provider、canvas-control 和正文拥有者 text-node；书籍容器格式不变。

## 四批实现

1. 精简稳定基础前缀，按需加载记忆、编辑、画布规则；删除空来源、空冲突和没有执行检索时的空报告。确实检索但没有证据仍说明边界。同修订、原文重叠一致的范围合并；相同正文只发送一次，但独立来源编号、修订和适用范围仍保留，不合并正式记忆状态。
2. 当前会话使用原生角色消息，选择近期六条、相关原文和用户明确限制，最多十六条；完整本地分块原文不变。相关旧事实继续回原文检索。canvasControl.taskState@1 提供至多两份相关计划的目标、必要操作、真实执行/失败/放弃/过期状态；公开对象能力比对修订后识别撤销、重做和后来修改。概览标明省略项，不充当完整正文。
3. canvasControl.localPlan@1 保守解析明确六位色值、方向距离和单节点绝对坐标；有歧义、配色设计、多意图仍走模型。既有对象修改仍走范围、审查、原子事务和撤销。context@2 按操作提供字段。续写只读尾部；数字段落改写通过分块定位完整段落和必要完整邻段，返回 UTF-16 目标范围与修订；超出范围/预算则拒绝，不猜测。v2 edit 只提交变化字段，v1 拒绝新字段，nodesPlan@1/@2 并存。普通正文提案保留生成依据修订，不更新为后来修订，从而拒绝覆盖生成中用户修改。
4. Gemini 原生连接按公开能力发送 responseMimeType/responseJsonSchema；其他兼容接口保持文本协议，不猜测其 Schema 支持。Schema 不代替对象、权限、范围、修订及事务业务校验。BOM、围栏及空白先本地处理，不补猜缺少字段。最多一次模型纠正及一次自动续写；预算参考明确篇幅和对象数量。归一化平台推理及缓存用量，子集不重复加总。

## 累计口径

默认直接生成也覆盖可写空白节点的正文填充。只有新建对象或仅写入空白正文的整批计划可自动提交。计划捕获后如果节点修订变化，已有提交校验会拒绝。其他修改、删除和主动选择的预览模式仍需确认。创作要求可生成原创正文，缺少旧正文不构成拒绝理由。

- ai-provider.taskUsage@1 记录每次真实 HTTP 尝试，包括 HTTP/兼容重试、工具往返、格式纠正、续写和记忆提炼。流式用量采用最后累计快照，不累加重复 usage 块。
- ai-assistant 通过 ai.task.usage@1/ai.task.new@1 管理明确任务边界：连续追问、重试、额外调用继承任务，用户点“新任务”另起统计；可选看较早任务。无需分类模型。
- 平台输入/输出、成功缺失方向的估算补充、失败或取消缺失方向的未知次数分别显示。未知不是零；平台已知合计不冒充完整账单。输入分类始终是本地估算；输出分最终内容、操作计划、记忆提炼，逐调用仍显示目的。推理和缓存为平台总量子集。
- 每个任务保存至多 128 条明细，省略旧明细不会减少总数。统计和请求全文仅当前打开期间保留，不进入书籍、恢复日志或全局历史；刷新、切书或插件重启会重建临时统计。
- 记忆提炼按原文修订与范围去重，失败可重试；普通对话和画布程序状态不自动提炼。已有证据充分且无省略时不再提供无关补查工具。工具仍有只读、范围、次数限制。

## 测量与验证

固定九类原文场景：tests/fixtures/ai-efficiency-scenarios.ts。before 在源码 0c28ec6 的构造器上采集，scripts/measure-ai-efficiency.ts 可重算 after。数字仅为相同固定输入的本地 Token 估算，不包含模型输出，不是完整任务节省或实际账单证明。

新账本才是完整任务的实际观察入口。自动测试使用模拟平台用量检查实际/估算/未知分离、重试与额外调用累计、缓存/推理子集、原文及限制保留。未使用用户 KEY 或付费调用来宣称账单节省。验收覆盖连续追问、历史原文和冲突既有评估、创作续写、改色、分组连线、局部范围、生成中编辑、撤销与保存重开，以及 v1/v2 和三浏览器托管/单 HTML。

官方依据：[Gemini 结构化输出](https://ai.google.dev/gemini-api/docs/structured-output)、[DeepSeek 缓存](https://api-docs.deepseek.com/zh-cn/guides/kv_cache/)、[OpenAI 流式用量](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。缓存子集不会使实际发送的上下文变短，不为命中率保留无用内容。
