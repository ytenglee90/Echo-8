# ADR-0101：箭头重接、连线标签与群组复制预览

## 状态

已采纳，2026-11-03；补充 0089、0091、0097、0099，部分替代旧标签独立底色规则。

## 决定

公开 typed connection.reconnect v1 请求包含 id、from、to、expectedRevision。连接拥有者复用创建时的端点、类型、循环及重复校验，排除被重接记录；同一事务保留 ID、文字、尺寸和颜色，仅更新语义端点及修订。旧版本文档及不透明字段保持兼容，没有新增持久字段、文件格式或权限。拖动使用 connecting 独占 session token、临时 draft、完成一次指令；取消、丢失捕获及卸载释放交互。

标签缩放由连接插件持有 session token，稳定 SVG 根持有指针捕获；手柄取得键盘焦点，Esc、取消、丢失捕获、正常完成及卸载均释放同一 session。正式缩放前结束交互，避免下一次节点操作仍遇到 resizing。预览不写文档，正式大小仍通过现有 revision checked resizeLabel 指令提交。

标签底色固定画布色；旧 labelBackgroundColor 原样保留和往返，但不影响呈现。保留旧 appearance 请求枚举用于协议兼容，背景更新计划返回零修改；背景选中映射为连线颜色。SVG 圆角框与曲线共用世界缩放、宽度和 6/4 虚线参数，避免浏览器 CSS dashed 自行分段。所有自定义颜色的连线仍采用统一 canvas-selection 提示色。

已用色目录只由实际节点/文本框、群组、注释、连线的拥有者汇总；不再加入界面偏好、画布底色、没有对象使用的默认色或旧标签底色。现有 appearance.colors@1 返回形态不变。

整组 Alt 复制用同一临时成员位置生成复制框；原框忽略 duplicate origins 的位移。复制框不可命中、不加入文档，只有直接选择整组且全体成员参与复制时出现。普通成员复制不产生群组复制框。

## 验证

端点重接覆盖 stale revision、重复、类型错误、身份与文字保持、全局单步撤销及停用后历史。浏览器覆盖真实箭头拖动、群组复制提交前预览、实虚线标签连续缩放/Esc/继续拖动节点，以及统一描边、底色和提示色。旧群组/中转图文件、复制粘贴继续往返。
