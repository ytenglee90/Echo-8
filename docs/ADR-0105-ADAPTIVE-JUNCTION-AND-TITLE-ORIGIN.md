# ADR-0105：按相对位置选择中转点端口与保留标题起始侧

## 状态

已采纳，2026-11-04。替代 0102 的中转点固定左入右出；扩展 0103 的文本框目标区域规则。

## 决定

中转点每条边独立选择朝向另一端的左右端口，切线保持水平。拖拽指针在左边则向左出线，在右边则向右出线；连接节点、文本框、群组及另一中转点时，两端根据几何中心相向接入，不依赖落点命中的物理输出口。移动对象后的预览和最终几何使用同一投影。中转点加号置于上方，保留可悬停的连接区域、缩放下固定屏幕大小与原有低缩放可见性。

从文字节点的标题左右端口拖出时，所选起始侧保持到连接完成。持久记录可选 titleOrigin：side 表示所选物理侧，sourceIsLeft 表示创建时两个对象的水平中心次序。相对次序反转后投影翻转 side，不改写记录。只有实际文字节点标题启用该字段；标题与标题仍同侧，其他端点维持相向规则。旧记录无字段时仍按旧自动选边。箭头重接、撤销、复制、保存和恢复保留元数据。

群组或中转点连接到文本框时，与文本框互连一致：目标中线以上为标题虚线，中线及以下为正文实线，锚点始终在边缘中点。中转组件的虚实线隔离校验继续生效，不自动修改原组件的线型。

公共 create/reconnect/draft 协议增加可选标题起始侧信息。连接 dataVersion 由 8 升至 9，8→9 恒等迁移保留旧记录和未知字段；连接剪贴板 payload schema 由 3 升至 4，接受旧的无版本、2、3 格式。外层文件容器、能力版本、权限和部署边界不变，无数据库迁移。

## 验证

契约覆盖双向中转几何、次序反转、水平控制点、旧数据往返、标题左右起始侧及翻转、元数据的撤销和文件/剪贴板往返、8→9 迁移，以及群组/中转点目标文本框上下区判定。浏览器覆盖加号位置、左右拖出、远侧端口接入、移动和撤销、标题起始侧在预览与提交的一致性、上下区草稿和最终线型。保留全量基础与跨浏览器验证和单 HTML 检查。
