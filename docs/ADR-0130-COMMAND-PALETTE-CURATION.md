# ADR-0130：命令面板分组与云端另存入口

2026-11-06，有效。补充 ADR-0007、0081；替代 ADR-0072 的书籍分组排序规定，保留其工具栏与打开文件边界。

命令面板按“书籍与同步、编辑、画布与节点、群组与排列、连线与中转点、AI 助手、设置”固定分组。插件继续声明自己的分类、关键词和组内优先级；面板只消费公开动作目录，不导入功能插件，也不根据功能 ID 操作它们。未知插件类别仍保留并稳定排序。搜索同时匹配插件原分类和用户看到的分组名，底部显示当前匹配的命令数。

书籍区顺序为返回书库、打开、保存、另存本地副本、另存到云端。恢复、云同步、快捷键、外观、参考线/吸附、文字辅助、AI 连接和插件管理归入设置。编辑按撤销/重做、剪贴板、选择/删除、查找、注释和选中项颜色排列；AI 以打开、新开、保存存档排列。

从动作目录移除选择/手抓工具切换、取消选择、重复的单独建组/解组、与常用连线重复的端点连接入口和开发诊断入口。其已有命令、工具栏控件与快捷键保持不变；诊断仍可通过原快捷键及快捷键中心进入。各动作仍由功能拥有者注册与清理，不把精简规则写成面板中的功能黑名单。

“立即保存当前云端书籍”与普通保存重复，替换为“另存到云端”。新增无载荷的版本化公开指令 `cloudSync.requestSaveAs@1`：只为本地书籍打开 cloud-sync 拥有的登录/命名表单，通过正式指令的 inline invoke 路径复用 `cloudSync.open`，不直接创建、覆盖或上传书籍。已有云端书籍拒绝此请求并提示使用普通保存，避免误创建副本。确认书名后仍调用已有 `cloudSync.saveCurrentAsProject`；现有同步指令和快捷键保持兼容。

新入口同时登记默认不绑定按键的可配置快捷键，避免占用用户现有组合键。此次新增协议是兼容扩展，不改变文件格式、数据库、权限边界或持久数据，无需迁移。验证覆盖新指令的载荷校验、串行队列不自锁、无意外保存、旧同步指令兼容和停用清理；浏览器覆盖完整分组顺序、重复入口消失、分组搜索与计数、菜单到云端另存的完整流程，以及诊断快捷键入口。
