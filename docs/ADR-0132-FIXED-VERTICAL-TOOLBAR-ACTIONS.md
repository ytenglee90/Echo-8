# ADR-0132：固定竖排连接菜单与批量中转点

2026-11-06，有效。替代 ADR-0131 的菜单排列、群组下拉和自动排列主按钮约定，补充其中的中转点操作。

连接菜单固定按正文连接、标题连接、创建中转点竖排三个图标。当前选择存在对应连接时，原位置切换为断开正文连接、断开标题连接；纯中转点选择时第三项切换为删除中转点（保持已有旁路重连语义）。不可用项保留位置并禁用，避免选区变化时图标跳位或消失。统一菜单支持 max-content 自适应宽度，不按最大图标数预留空白；AI 会话列表继续使用其固定文本宽度。菜单状态只存在于视图，不进入文档或历史。

群组使用单个直接点击的上下文图标，不再提供重复下拉入口；既有有序加入、成员踢出、创建和解组语义不变。自动排列主按钮恢复已有 node.arrangeSelectedCycle 的宫格、横排、竖排轮转及原超时复位规则；竖排下拉保留三个固定排列指令。

中转点操作从选择中筛选连线，混入的节点或其他对象不参与修改。同类型且有共同输出或输入端点的整批连线仍共用一个中转点；不能共用时，每条连线分别在自身实际曲线中点添加一个中转点。因此相同端点的正文/标题混选也保留创建入口，分别建点，避免混合线型；不将无共同端点的关系合并成全互连网络。

新增兼容扩展指令 connection.addJunctionBatch@1，载荷为 junctions: ConnectionAddJunctionRequest[]，返回新点 ids；总连线引用及分组数上限均为 10000。拥有者在一次提交前验证所有修订、重复引用、端点及线型，组合标准点/边补丁，一次操作对应一次持久事务。connection.toolbarToggle@1 通过 inline invoke 复用批量指令，然后通过 selection.set 选中新点，兼容保留结果中的首个 id，并扩展可选 ids。删除选中新点仍复用原批量旁路命令，单步撤销。

旧 addJunction、指针/右键中转点指令继续保持原共同端点约束，已有数据版本和迁移不变。无书籍、剪贴板、数据库或部署边界变化，无需迁移。测试覆盖同端点同类型及不同线型、独立连线、混合选区、原始关系/未选对象保持、整批修订失败不写入、一次撤销、文件往返、菜单固定顺序与竖排、群组直接点击、排列轮转，以及完整托管和单 HTML 回归。
