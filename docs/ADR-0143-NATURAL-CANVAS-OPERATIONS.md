# ADR 0143 · 全画布自然语言操作

状态：有效。补充 ADR 0138、0141、0142。由 ai-assistant 识别会话入口，canvas-control 解析与审查操作，正文、群组、连线和外观继续由各自插件提交。书籍容器不变。

## 本地识别与定位

识别明确的查找、关系查询、连线、线型、色名与色值、背景、主题、节点展示、群组、正文替换与追加、筛选、移动和排列。询问人物动机等问题继续走问答。支持的本地操作可以在没有模型连接时发送，仍显示每轮 0 Token。

按本轮需要从公开目录建立标准化标题查找表，不依赖视口。重名、或自动编号的同名系列，展示群组与实际节点标题；选定后重新解析原请求和剩余对象。通过 `@` 绑定的 ID 优先。只把相关对象纳入操作快照；需要修改的现有对象在提交前重新验证修订。自动查找遵循来源的检索权限。

新指令的查找和定位立即执行，涉及书籍内容和外观的写入进入可审查计划。明确的应用主题切换委托 palette。背景可临时预览并按画布外观修订提交。批量操作复用已有事务，一次撤销。原有 `@画布操作` 的纯创作继续使用直接生成设置。

最近查找结果、连线预览、已应用连线和群组按当前会话保留。待应用连线更新原预览，已应用连线通过 ID 校验，不再创建重复连线。撤销后检查真实对象是否存在。关书清理这些临时数据。

连线连续对话接受「用虚线」「改回实线」和「刚才那条用实线」。未指定线型时保留已有唯一同向连线的线型，新线缺省实线。「把 A 和 B 连起来」先点选箭头方向，再沿用已经确定的对象、线型和原请求。引号内的标题保留「和」「与」及动作词。「A 和 B 连着吗」只查询真实关系，显示方向与线型。假设、否定和不确定的问句不生成本地修改计划。

省略目标与「刚才那条」沿用当前会话处理的连线，「这条线」读取当前选中的真实连线。待应用计划的后续线型修改绑定准备时的计划 ID，并核对有效期和待应用状态。期间应用、放弃或换成另一份计划后，迟到的准备结果被拒绝。应用时沿用原快照校验，正文、端点或连线已变化时拒绝过期修改。明确重新连接到已有线后更新会话目标，避免继续修改更早的预览。

## 正文与批量整理

明确替换在本地分块定位唯一旧值，优先核对字段标签。唯一匹配才生成 v2 范围修改。追加只返回新增文本。编辑选区、匹配描述的段落和连续缩写绑定正文范围与修订，仅发送匹配原文和两侧必要片段。待应用提案可被更新版本替代，已应用提案记录结果修订。范围提案只能应用到原目标。

按群组、空白正文和是否连线筛选。用户后续使用「它们」时复用结果 ID。批量改色、移动或排版显示影响数量和变更。超过 80 个修改目标分批；查询显示命中数量和前 80 项。复杂线索查询只向模型提供用户要求，由模型提取搜索词和筛选条件，`canvasControl.searchPlan@1` 在本地检索并核对候选。模型不会接收全量目录或正文。

新增测试包括 2,000 个节点、屏幕外的主角与武器、同一连线虚实切换、重名点选恢复、无模型配置的聊天入口、群组追问、局部正文与连续改写、背景预览，以及筛选后沿用目标移动。

## 2026-11-13 连线连续对话交付与验收

本批完成首个验收场景。2,000 个节点中两个目标位于屏幕外，通过「把武器连到主角」→「用虚线」更新同一预览，应用后「改回实线」修改同一连线 ID，保留武器指向主角的方向。同名目标点选后继续原请求。撤销创建后的追问明确返回对象已撤销，迟到的准备结果无法修改另一份新计划。浏览器输入框测试在断网、未配置模型时运行，每轮输入与输出均为 0 Token。

实现属于 ai-assistant 共用的本地路由及 canvas-control 会话解析，沿用现有版本化指令、拥有者能力、修订检查和事务。新增的关系查询、引号标题、方向点选和指代区分均在本地完成。五阶段方案中更广的自然语言指令、复杂筛选、长期任务约束及检索设置、云端授权和模型升级仍属于后续工作。

验收结果如下。

- TypeScript、ESLint、610 项单元测试通过，其中画布控制 19 项包含上述 2,000 节点及竞态回归。托管构建和正式单 HTML 构建成功。
- Chromium 全量 229 项中 228 项通过，一项中转点到文本框的鼠标重连场景失败。该文件的虚实线两项独立复核均通过。
- Firefox/WebKit 全量 456 项中 439 项通过、17 项失败。失败项单独复核后 5 项通过，12 项仍失败，具体清单见下方。首次并行执行曾共用测试输出目录并导致报告文件相互清理，后续运行使用独立目录保存报告。
- 本批涉及的画布 AI 控制场景在 Chromium、Firefox、WebKit 共 54 项通过。最终单 HTML 在 file:// 三浏览器共 69 项通过，包含无外部资源启动、编辑、导入、保存重开、撤销及本次两项离线新场景。
- WebKit 启动测试曾在样式应用前读到空图标遮罩。旧版及当前版在样式就绪后均返回有效遮罩，现有断言改为轮询等待同一计算样式成立，最终三浏览器全套便携版通过。
- 极限画布浏览器性能场景通过。测试模型请求使用模拟接口，本次线上两项新场景在三浏览器共 6 项通过，未使用个人 API Key。

单独复核仍失败的 12 项均处于本批未修改的鼠标交互路径。

- Firefox 共 6 项。中转点独立端口连接的数量断言失败，群组端口 40% 缩放出现 0.4000000059604645 与 0.4 的精确比较差异，中转点移出视口后的拖动断言失败，100%、40%、240% 下端口间隔的几何断言失败。
- WebKit 共 6 项。移出群组成员后连线跟随，拆分删除重连，自由中转点拖动方向，选中后拖动中转点，文本框边缘平移，以及 601 条重合曲线的点击轮换。

忽略的本地诊断保留在 local-data/natural-followup-*。完整运行日志为 natural-followup-cross.log，独立复核日志为 natural-followup-firefox-recheck.log、natural-followup-webkit-recheck.log 和 natural-followup-webkit-extra-recheck.log。测试失败与复核通过分别记录。
