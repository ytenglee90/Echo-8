# ADR-0100：仅标题互连使用同侧端口与小地图群组填充

## 状态

已采纳，2026-11-03；用户确认按原相对位置自动选边，且同侧规则仅用于标题与标题。部分替代 ADR-0093、0096。

## 决定

当两端均为真实文字节点标题时，按原水平中心规则确定源端左右侧，并使目标标题使用同一侧；节点换位后两端同步切换。曲线向共同侧外部延伸，保留水平接入。文本框、正文、群组及中转点不采用此同侧特例，继续使用各自既有锚点和方向。转换与拖动预览仍使用统一的形态投影，因此变成文本框后恢复普通相向规则，转换回文字节点标题后再次使用同侧规则。

小地图群组去掉描边，使用继承群组颜色、透明度 16% 的底色；缺省为自动明暗适配的灰色。底色不拦截空白平移或节点命中，保留键盘聚焦能力。文字节点色块与文本框轮廓横杆不变。

以上均为派生渲染规则，不新增存储字段或文档版本，无需迁移。既有文件直接采用新投影。

## 验证

契约覆盖标题互连同侧及自动翻边，文本框、正文和群组保持原规则。浏览器覆盖真实端口、预览、移动、撤销，以及群组底色、透明度、无描边、键盘聚焦和小地图空白导航。
