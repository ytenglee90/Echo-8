# ADR 0160 · 助手指令目录、个人用语与分批新建

有效。补充 ADR 0157、0158、0159。

## 产品入口与所有权

书库只提供新建、打开和书籍管理。书库所有者移除 AI 入口与命令依赖。助手通过公开 `bookLibrary.state@1` 与 `bookLibrary.updated` 隐藏自己的窗口，保留会话、草稿及正在运行的任务，返回画布后继续显示。助手显示当前书籍及默认控制范围，范围修改仍由 `canvasControl.scope@1` 处理。

工作区固定计划、注册统计和 JSON 编辑器保留为命令面板中的开发者工具，退出普通设置导航。普通设置新增“指令与偏好”，包含全部指令、我的用语、默认偏好。目录无需账户，个人数据仍按账户保存。

AI 所有者通过 `workspace.actions@1` 投影实时动作，不导入工作区插件。新增只读 `ai.instructions@1` 返回版本 1 目录，含类别、示例、条件、当前可用性及是否能设置别名。只有经过本地路由核对的示例和明确允许的无参数本地命令可设置个人用语；其余动作标为功能界面操作，不把注册成功当成自然语言支持。插件停用后目录刷新，发送别名前重新读取目录以拒绝失效动作。

## 个人配置 v2 与兼容

个人偏好 v1 继续读取。v2 沿用账户资源，新增动作标识、别名可选排列间距，以及横排、竖排、网格各自的默认间距。v1 的横排间距没有 `layout` 时仍解释为 horizontal。迁移复制已有条目，不删除旧条目。内置指令和本次明确参数优先于个人别名与默认值。别名只是展开为已有本地指令，不能带脚本或绕过目标、修订、确认、事务和撤销校验。

新增 `account.assistantPreferences@2` 使用 Data Worker 9 的 `/v3/assistant-preferences`，v1 能力与 `/v2/assistant-preferences` 保留。v3 GET 将旧内容投影为 schemaVersion 2；第一次成功的 v3 PUT 在原有修订条件下保存升级，不需要数据库表迁移。旧客户端 GET 返回兼容的 v1 子集；存储已升级为 v2 后，旧端 PUT 返回 409，防止旧端静默删除新条目。Worker 8 的账户继续使用原三种用语和横排默认间距，并提示显式升级服务以使用扩展。此工作不部署 Worker、不修改线上账户、不自动升级服务。

## 数量解析与执行

“生成60张空白，三张人物，两张角色，一张势力，一张地图，地图连接势力实线。60张空白打一个组”此前把“打一个组”误识别为第二次新建 60 张。现在本地语法直接生成 69 项：67 个节点、一条有方向的实线、一个含 60 个成员的群组。整个计划仍是一次原子事务，撤销和重做覆盖全部对象。

独立新建支持完整解析后最多 400 张，每批最多 80 张。各批复用 `canvasControl.localPlan@2`、offer、generate、receipt 和原有所有者事务。没有扩宽画布控制公开协议的 80 对象范围。含连线、分组或已有对象修改的组合超限时在提交前拒绝，避免跨批依赖和半份组合。

批次标识从原任务标识稳定派生。重试先读取原批回执，已提交或待确认批次不重复。取消停止后续批次，不回滚已提交的成果；界面明确逐批撤销边界。预览模式的每批仍需用户确认。进度、失败与完成只反映实际回执。任务属于助手的原有可取消任务，切书、停用与生命周期清理沿用现有机制。

## 验证

定向单元覆盖截图原句的实际节点、群组与连线、原子撤销重做、120 张分批中断续接与无重复、按批撤销、超限混合任务不写入、示例实际路由、不可用动作、默认参数与账户 v1/v2 兼容和旧端防覆盖。

浏览器覆盖匿名目录搜索分类、键盘切页、停用插件后更新目录、首页隐藏助手及草稿恢复、v2 用语预览保存和跨设备恢复、默认间距，以及真实大批量新建。相同目录及数量用例在托管和真实 file:// 成品运行。完整检查结果见[本次验证记录](VERIFICATION-2026-11-18-INSTRUCTIONS.md)。
