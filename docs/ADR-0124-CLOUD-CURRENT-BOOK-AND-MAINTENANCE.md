# ADR-0124：只保留当前书籍的云端增量保存与自动维护

## 状态、范围和所有者

2026-11-05，已采纳。替代 ADR-0067/0068 中长期追加操作日志与多版本检查点的存储策略；保留用户自有 Cloudflare 账户、短期授权、单设备编辑租约、浏览器恢复和 .echo8 导出边界。补充 ADR-0075、0085。

cloud-sync 拥有上传、重试、状态及个人快捷键同步；用户数据 Worker 拥有云端版本、数据校验、原子提交、迁移及回收。内核持久服务只增加通用的目录查询、备份确认、本地存储统计与安全清理协议。文件、快捷键插件继续通过类型消息协作，不读取彼此私有数据。

## 存储与协议版本

- 数据 Worker release 5、D1 schema migration 3；既有 v1 路由可读取尚未迁移的书籍。新 `/v2` 协议使用 book formatVersion 2，与外层 .echo8 formatVersion 2 独立。
- 书籍只保留当前有效的 document 命名空间及插件目录；位置、内容、文字格式、注释、节点/文本框/群组/连线/中转点颜色、背景和全局实际配色均随书保存。工作区主题预设、收藏颜色、布局、撤销历史、缓存和秘密不进入书籍。
- 当前书籍由头记录、记录目录页和 SHA-256 内容块组成。目录按记录名的稳定桶分组，正文按 UTF-8 边界切为不超过 64 KiB 的块。块在有收益时 gzip，哈希对应解压后的原始字节。每块解压有严格大小上限并校验哈希；书籍当前最大 256 MiB、20,000 个唯一分块。
- 首次保存编码全部有效记录。之后使用已提交事件的文档修订和最终标准补丁，只编码变化值；同一字段的连续编辑合并，逆向补丁仍由本机历史保留。目录无需读取正文。待上传内存超过界限时退为“完整本机源待保存”标记，而不是保留无限操作历史。
- `/uploads` 建立 15 分钟上传会话，比较当前引用，仅记录引用的增删差异；不为每次实时保存重新写入整本书的所有引用。已有同哈希块复用。`PUT blocks` 只接收会话清单中的块，受租约和大小约束。
- `/commit` 验证目录、引用完整性、原始长度、上传会话和编辑权；头、当前引用和项目版本在同一 D1 batch 事务内切换，使用版本 CAS 与唯一 saveId 守卫。失败回滚到原书籍。仅保留一个头，没有永久保存日志或完整历史快照。
- 上传成功但响应丢失时，浏览器先对照云端头，按相同 saveId/原始提交集合恢复确认；期间新编辑仍待下一批上传。重试不会误确认新编辑或重复推进版本。
- 正在下载的书籍通过限时 reader 引用保护，完成后释放；清理不与正在读取或上传的块竞争。旧数据只为这些短期会话保留，不作为历史版本长期累积。
- 已迁移书籍的 v1 bootstrap/changes/chunks/sync 返回 426 与 `client_upgrade_required`，防止旧客户端误写；刷新前本地草稿仍保留。v1 兼容逻辑隔离在 legacy-transport 中，不混入新协议。

## 实时保存与故障

继续使用现有自动保存间隔，包括 1 秒实时、手动关闭。相同时间只准一个书籍上传；重复触发合并，持续编辑由既有周期上限触发下一批。无文档修改不上传正文；租约更新独立于内容保存。首次或重新连接需要完整建立本机引用基线，后续少量修改不再次编码大正文。

网络服务增加经过现有来源、请求体、鉴权头、限流、并发、超时与停用取消校验的 PUT；没有绕过统一出口。对冲突、租约转移、授权、升级、容量、限流、服务错误和断网分类；临时错误按指数延长间隔并遵守 Retry-After，空间/授权/升级错误降低重试频率。云端空间使用超过 80%/95% 时提示；写入前为新数据和数据库元信息预留空间，禁止破坏唯一旧头来腾空间。

界面区分本机恢复保护、等待上传、同步中、云端已保存和失败重试，展示新增传输大小与最近维护摘要。并发手动保存不能通过排队写入个人设置自锁：正式指令拥有的收尾走 invoke，后台收尾不等待后来占用串行队列的写入。

## 自动回收和旧数据迁移

数据 Worker 每 5 分钟由 Cron 启动维护，成功请求后也可通过 waitUntil 补充，至少间隔 1 分钟。带到期锁，每轮选择至多两本、每张表至多 200 条，按最后检查时间轮转，失败可重试。只保留一份维护摘要和每本最后状态，不保存正文、令牌或无限诊断日志。

- 永久删除仍先设置 tombstone，使列表和读取立即停止，再后台清理正文、目录、操作日志、旧快照、上传/读取会话及租约，最后删除目录记录。旧版本遗留的 tombstone 同样处理。
- 有当前头时分批删除旧 v1 日志/检查点/正文块，回收不被当前头、有效 reader 或有效上传引用的过期块。
- 即使首次上传尚未产生头，过期会话及其无人引用分块也能回收，避免半途关闭造成永久残留。
- 没有新头的旧书籍只能在无有效编辑租约时迁移。取得短期维护租约，完整读取旧检查点及必要的后续操作、恢复内容，编码新书籍并执行实际解码往返校验，然后走普通上传/提交协议。只在新头成立后回收旧数据。损坏、未知内容或中断不触发源数据删除。
- 主站为已有安装提供 release 5 自动原地升级；升级失败保留原版本和数据，仍可使用明确的升级入口。部署迁移先创建新表，完全兼容既有数据；未知插件记录原样携带。

## 个人快捷键

账号只保存一份最新自定义快捷键，账号/安装隔离并带修订前提；不上传主题预设、收藏色、布局、个人 AI 设置或密钥。登录加载书库时恢复，修改后合并同步。跨设备都修改时保留本机并提示选择“使用本机”或“使用账号”，不静默覆盖。快捷键所有者验证并通过标准 workspace 事务应用；共享书籍本身不能改变个人快捷键。

## 本地维护

通用 `system.storage.usage` 返回 IndexedDB 各类逻辑数据大小和条数，以及浏览器可提供的 origin usage/quota；逻辑字节不是精确物理文件大小。文件与恢复面板提供占用明细、清理无引用数据及清理已备份重复恢复副本。

`system.persistence.confirmBackup` 只在当前文档修订与成功保存修订一致时确认，且不会为每秒云保存额外强制完整本地快照。手动本地文件写入完成也提供备份确认。自动恢复整理不再按数量删除独有恢复点，只处理已有备份的完全相同文档副本。垃圾回收同时保留最新快照、全部保留恢复点及待合并日志的正逆补丁引用，保护未上传/未保存内容、唯一副本和撤销所需正文。个人设置及授权句柄不属于日常清理目标。

## 验证和运维

- 使用真实 SQLite 约束/事务适配器验证新表、旧表兼容、Unicode、未知插件和外观往返、增量传输、丢失确认、陈旧版本/接管拒绝、错误块、部分上传、事务中断回滚、迁移校验、reader/上传保护、过期回收和 tombstone 完整删除。
- Chromium 使用实际数据 Worker/SQLite 后端验证实时与手动保存交接、重新打开大正文、本地清理保护恢复副本、账号快捷键下载/更新/重开，复测原有云书籍命名/删除、只读保存和恢复入口。
- 主站和个人数据 Worker 都需发布；仅更新主站不足以启用新存储。升级/迁移前记录 D1 恢复书签元信息，禁止为诊断导出整库或泄露密钥。迁移结果以有效书籍数量、头/块和旧表清理计数核对。
- D1 页面文件的物理占用与存活数据量分别观察；删除后可复用页面不是残留正文，不通过误报“零占用”隐藏空间开销。
- Cloudflare 主体历史发布版本不清理；.echo8 文件格式不变，便携 HTML 由源码构建。
