# ADR-0113：舒展中转曲线与左右拖线预览

> 几何实现已由 [ADR-0116](ADR-0116-physical-junction-network-splines.md) 替代；本文保留为历史记录。

## 状态与问题

已采纳，2026-11-04，细化 ADR-0112。公共有向切线已消除点处反向尖角，但强制零端点曲率、分段过渡和额外直线引导段把弯曲集中到中间，形成生硬的 S 形。共享轴的局部分量也可能引出不必要的鼓包。向左拖动仍以中转点为输出、自由指针未纳入候选拓扑，会产生绕回的预览。

## 决定

连接拥有者保留每点公共前向切线与 15° 旋转偏移。输入均值到点、点到输出均值在某个坐标分量相反时，优先把该轴分量归零；若两分量均退化，则保留原自动轴与退化回退。这样低位中转点可采用水平切线，避免向下鼓包再转向上。

每条中转分段采用一条三次 Bézier，用跨度 40%、上限 420 世界单位的手柄均匀展开弯曲；前向横向手柄各限于横向间距的一半，陡峭分支保持横向单调。移除零端点曲率和独立直线引导段的硬约束，保留点处 G1 几何切向连续，分支曲率可自然分开。普通节点端仍水平接入，箭头沿真实末端导数对齐；窄横距缩短箭头并同比缩放起始控制向量，避免破坏公共切线。绘制、标签、命中、框选和批量路径继续共用同一几何。

中转点的新建拖线通过纯协议辅助函数按实际另一端锚点判定：向左形成“另一端→中转点”的输入段，向右形成“中转点→另一端”的输出段。节点、文本框、群组和其他点均适用。共享输入适配器在派发现有 connection.create 前完成此转换；指令拥有者仍做原有类型继承、重复/环路校验和单事务写入。程序式显式指令、原有记录和箭头重接不被全局反转。

自由拖动时用零尺寸临时指针目标投影候选图；悬停真实目标后使用其真实锚点。预览和提交共用左右规则，候选公共切线同时驱动已有分支。候选若匹配已有同类型有向边，则替换该边参与投影，避免重复计权和绕回源节点的假分支。虚拟目标仅在渲染缓存，不进入文档、选择或历史。

未新增消息或持久字段，connections dataVersion 11、剪贴板 schema 6、旧角度和位置保持不变，无文件或数据库迁移。
