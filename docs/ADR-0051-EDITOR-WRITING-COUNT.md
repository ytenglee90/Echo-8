# ADR-0051：编辑器写作字数与字符数分离

## 状态

已采纳；其中“编辑器主显示采用独立写作字数”的决定已由 ADR-0059 取代，写作单位字段仅保留兼容用途。

## 问题

编辑器曾把“不含空白的 Unicode 可见字符数”显示成“全文”。这个指标会计入标点、Emoji，英文也逐个字母计数，因此与 Word、WPS 等中文写作软件通常展示的“字数”明显不同。

## 决定

- 编辑器状态栏展示独立的“写作字数”：汉字、日文假名和韩文字符逐字计数；连续的其他语言字母或数字算一个词；标点、空白和 Emoji 不计数。
- 编辑器悬停提示同时展示原有“字符数”，便于用户核对两个口径。
- 顶部工具栏既有的选中文字节点“字符数”保持不变，不把两个概念混在一起。
- 码字速度继续按实际输入的可见字符计算，并明确标为“字符/分”。
- 文本所有者通过版本化能力 `content.metrics@3` 提供精确写作字数；`content.metrics@2` 保持兼容。
- 超长正文仍按分块扫描并可取消。连续输入只重算发生变化的词语边界，不在每次按键时扫描全文。

## 示例

正文 `你好，world 2026！👨‍👩‍👧‍👦` 的写作字数是 4：`你`、`好`、`world`、`2026`。标点和 Emoji 不计入。

不同软件仍可能对连字符、数字和日韩文字采用不同口径，因此产品必须通过提示公开自己的精确定义，而不能声称与所有第三方软件的统计完全相同。
