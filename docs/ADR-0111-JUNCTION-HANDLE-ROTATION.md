# ADR-0111：双击中转点按 15° 循环旋转曲线手柄

## 状态

已采纳，2026-11-04。用户提出 15° 循环或依次匹配相连曲线两种方案，本次采用每次双击顺时针旋转 15°，完整 360° 循环。

## 决定

连接拥有者通过 connection.rotateJunctionHandle 对当前点相对递增角度；每次操作读取当前拥有者记录并提交一次标准补丁。点位置、节点锚点和箭头规则不变。handleAngle 为可选的 0–345°、15° 整数倍，未设置表示原来的自动水平手柄；转回 0° 时移除此字段。

每条分段保留根据实际另一端锚点选择的左右侧，再按点角度旋转其水平导数。输入/输出角色使用同一旋转轴的相应方向。绘制、命中、框选、重接和新建预览共用几何；节点一端的导数及锚点保持原有规则。最终导数已进入选择几何修订，旋转会更新命中缓存。

拖动仍在稳定 SVG 图层捕获鼠标，因此原生双击同样由该层处理，核对两次按下属于同一个中转点；加号双击不旋转。角度与点一起保存、复制并可撤销，停用拥有者后仍可回放历史。

## 版本与验证

连线 dataVersion 10→11，恒等迁移保留旧点和未知字段；旧点继续使用水平手柄。剪贴板 schema 5→6，继续接收无版本及 2–5。容器和命名空间不变，无数据库迁移。验证 24 步完整循环、位置不变、输入/输出几何、无效角度、一次撤销/重做、热停用回放、文件/复制往返及旧版本迁移。Chromium 验证双击、关联曲线变化、无关线不变和新建预览。
