# ADR-0099：群组透明连接口与成员变更时的锚点预览

## 状态

已采纳，2026-11-03；补充 ADR-0091、0095、0097。

## 决定

群组左右中点的连接按钮保留受治理命中区域和键盘名称，去掉常态圆点、边框及底色。拉线目标在点目标之后优先识别真实节点的标题端口，避免被包裹群组的大范围命中或其他正文几何抢走。

`connections.targets@1` 请求增加可选成员变更预览。群组拥有者按既有批量成员规则计算临时剩余/新增成员，再投影外框；连接视图、群组端口和包裹框使用一致的成员集合，连接不再跟着已移出的对象扩张。即将解散的群组在预览中不再提供锚点。预览延续到正式复合事务结束后清除，失败或取消时恢复原几何。

扩展字段仅存在于已有版本化能力的临时请求，不改变文档、连接记录、容器版本或历史格式，无需迁移。正式成员变更、位置及群组连线清理继续一次提交和撤销。

## 验证

浏览器验证连接按钮透明但可拉线、连接另一群组左上成员的标题、移出成员时线端始终位于剩余群组边中点、提交后与预览一致及一次撤销。批量移出、Alt 复制固定外框、群组边中点与形态转换回归继续保留。
