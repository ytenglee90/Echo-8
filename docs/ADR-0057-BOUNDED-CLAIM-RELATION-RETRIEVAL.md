# ADR-0057：受限、可解释的确认事实关系检索

## 背景

关键词、BM25 和语义检索能找出直接相关的原文，但用户常会询问一个明确设定所处的同一版本、角色或流程中的相邻设定。完整 GraphRAG 数据库会引入新的持久化状态、同步与过度关联风险；本应用的 AI 记忆仍必须以用户原文为唯一证据。

## 决策

- 在每次 AI 记忆检索时，从已启用的索引中临时重建轻量关系图；不写入画布、文件、恢复记录或网络请求。
- 只有 `authority: user-explicit` 且仍有效的 `@确认`、`@修改`、`@分支` 声明可以入图。候选、废弃声明以及模型推断全部排除。
- 问题必须先直接命中一条确认事实，才能沿一跳关系补充候选：相同适用范围、相同主题，或相同当前值。双方都有明确但不同范围时，主题和值都不能跨范围关联。
- 每次最多分析 240 份索引、600 条声明、12 个种子、24 条关联证据；关联只提供原文锚点。上下文准备器仍通过现有版本检查与完整结构块读取原文，模型不会收到关系推导作为事实。
- 检索报告显示关系补充的候选数量和原文定位数量，供用户核对。

## 后果

- 跨记忆的版本、范围与相邻流程更容易一起被取证，且不需要本地向量模型或额外服务。
- 图是即时派生数据，因此不需要迁移、恢复或权限；代价是超出固定上限的老旧或大规模记忆不会参与本次关系补充。
- 这不是自动知识抽取或自治 Agent；不支持实体猜测、跨范围推理或无证据写回。更复杂的关系只能由用户用明确指令写入原文后参与检索。
