# ADR 0156 · 编号连线与共用中转点的本地操作

状态为有效。补充 0153、0154 和 0155。

本地创建组合共用分组子句语法，识别「空白卡群组」及动词变体。创建时保留通用节点的原称呼，让同一轮后续分组和连线绑定本轮创建的对象。明确命名与引号中的标题按字面保留。

定向连线识别动词前的线型，以及「空白 1、2、3、4」这样的连续编号省略。程序展开真实标题并逐一核对对象，保留从编号节点到指定目标的方向。冲突线型、重名或缺少对象继续经过已有本地计划的澄清与校验。组合任务及连线沿用既有 v2 计划和事务。

新增连接线所有者命令 `connection.addJunctionForEdges@1`。输入是已有连线 ID、修订和可选的共用要求。所有者复用现有几何计算及批量中转点事务，要求共用时核对同一方向的公共端点和相同线型。工具栏 v1 继续按当前选区执行，内部委托新命令并保留既有自动共用或逐线添加行为。

「所有虚线，添加一个中转点」在画布控制中按当前可操作的直接连线范围捕获 ID 和修订。自动检索停用的内容默认排除，明确引用继续沿用已有授权范围。应用前重新核对整个命中集合与修订，新增、删除、改线或范围变化使旧操作失效。最终写入由连接线所有者完成，可一次撤销。模型没有新命令入口。没有同向公共端点时返回本地说明。已包含中转点的路由继续使用明确选线入口。

这次是新增版本化命令，旧命令和书籍格式保持兼容，无持久化迁移。回归覆盖报告原句的四种创建开头、编号虚线的入向端点、四线共用一个中转点、零云端调用、受限来源排除、过期提交原子失败、撤销重做及保存内容。托管与便携浏览器共用原始场景。
