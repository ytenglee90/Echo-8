# ADR 0145 实时操作日志

现有诊断概览只展示活跃的调度任务。AI 回答、用户确认和画布写入分别由不同拥有者处理，原先的任务计数无法说明计划是否真正生效。

内核提供只读的 system.operationLog@1，记录调度任务、正式命令失败、有文档提交的命令和已选择的本地操作。异步任务使用调度器实际的创建、开始、进度报告、重试和结束时点。等待模型的耗时从请求能力发起到内容事件或非流式结果返回，包含提供器处理及重试的等待。文本生成进度是已有估计，UI 标注为约数。默认每条记录展示操作状态及适用的排队、执行、预计等待与超时字段。

AI 助手和画布控制经 system.operationLog.stage@1 提交受限的枚举状态。逐条接收，避免合并时丢掉快速完成的转换，再通过 system.operationLog.changed@1 按帧刷新观察者。已应用的画布与正文状态来自成功提交。更换书籍或停用模块时，正在等待的旧阶段失效或取消。失败和超时保留为可筛选的结束结果。日志记录撤销和重做本身，作为独立发生的操作。

诊断中心拥有界面，入口为内核与诊断、命令面板与 AI 助手。页内可按 AI、失败与超时或同轮状态筛选。内存保存最近 240 条完成结果和有界的待处理阶段，页面重载后清空。仅记录固定操作编号、受限关联 ID、状态、耗时和计数。提示词、节点标题和正文、模型请求、错误原文、密钥及补丁值不进入日志。日志不参与历史、恢复、书籍文件或同步。

新查询、通知、打开命令均采用版本 1。现有任务、设置和书籍格式兼容，无需迁移。合同测试验证任务超时、取消、重试、保留上限、私有数据排除和撤销。浏览器测试通过模拟模型延迟验证 AI 从等待到确认、应用和撤销的链路。
