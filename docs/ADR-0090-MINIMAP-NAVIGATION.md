# ADR-0090：独立小地图插件与保持缩放的视图导航

## 状态

已采纳，2026-11-03。补充 ADR-0007、0011、0084、0087。

## 决定

`minimap` 拥有左下角小地图、百分比旁的开关以及快捷键中心操作。新增受治理的 `canvas.navigation` 插槽，由 shell 管理层级、指针穿透和定位容器；插件不建立全局 DOM 或监听器。插件可独立停用、重新启用，所有贡献与订阅由内核生命周期清理。

地图通过 `content.catalog@2` 增量目录读取节点和文本框的矩形与颜色，以无正文的 SVG 色块绘制全部空间分布；不绘制连线、标签、群组或中转点。辅助视口框表示当前可见区域。`visualOnly` 目录订阅比较几何、颜色、形态和可访问名称，正文/修订变化与内容相同的全量目录重置不会重绘色块。色块子树记忆化，相机移动只更新视口框。

色块单击依次发送既有 `selection.set` 与 `canvas.focusEntity`。空白点击和任意位置拖动使用新增的第一版 `CanvasPanRequest` 临时信号 `canvas.pan.requested`，由画布所有者将目标世界点移到视口中心，保留实时缩放。拖拽过程为可合并预览，仅结束时保存一次工作区相机，不进入文档历史。超过 3px 才判为拖动，起点是色块也不会误触聚焦。坐标投影由内容范围决定，并在整个手势固定；不因视图移动重新缩放地图。空画布使用有限默认范围，负坐标和远距离节点正常纳入概览。

手势使用独立 `panning` 会话令牌、指针捕获和按顺序入队的结束指令。Escape、指针取消或插件卸载释放会话，撤回未提交预览。地图提供方向键平移、色块 Enter/Space 聚焦、按钮按下状态和可访问名称。点击提示使用组件内 CSS 动画，不建立计时器；减少动态效果设置改为短暂静态淡出。

半透明底、边框、视口框和点击提示根据画布实际背景亮度适配，包括颜色预览、提交与撤销；原始节点色彩不反转。

## 兼容与状态

`minimap.state@1` 公开只读开关；`minimap.open/close/toggle` 是有类型的工作区命令。首次默认关闭，开关状态保存到独立工作区命名空间 `minimap`，不是书籍内容或撤销历史。公开信号和插槽是向后兼容扩展。`.echo8` 容器、现有插件数据版本与文档格式不变，无需文档迁移。

## 验证

契约测试覆盖开关历史隔离、资源清理、重启恢复、两千节点及远负坐标投影和正文/外观目录失效区分。浏览器测试覆盖仅色块显示、离屏对象聚焦、空白点击、从色块起步的实时拖拽、缩放保持、Escape 恢复、快捷键绑定、热停用/启用和真实背景颜色预览。完整测试、画布压力、便携构建与 file:// 入口继续运行。
