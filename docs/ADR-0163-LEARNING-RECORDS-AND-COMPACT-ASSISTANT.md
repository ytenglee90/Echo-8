# ADR 0163 · 学习记录与紧凑助手控制

有效，补充 ADR 0160、0162。按用户要求统一学习结果入口、移除独立默认偏好及开发者入口，并调整助手输入区和群组名称显示。书籍格式、账户配置 v1/v2、数据库及所有持久指令格式保持不变，无迁移。

## 学习记录

AI 所有者的“指令与偏好”只保留“全部指令”和“我的用语”两个页签，键盘左右键与 Home/End 按两项循环。我的用语提供固定可见的“学习记录”区域，显示待确认/已确认数量、筛选、内容、适用范围、来源及生效/停用状态。没有账户、尚无记录、反馈学习未开启或筛选无匹配均有明确说明。

反馈生成的用语与间距候选进入同一区域；确认、忽略、编辑、启停和删除复用带账户修订条件的 `ai.personal.update@1`。候选仍不自动生效。已确认反馈用语保留反馈来源，手动用语单独显示。移除默认偏好页签不会删除原有间距：旧的手动/对话间距在该区域明确注明来源，可继续编辑、停用、删除、导入/导出及跨设备恢复，不假装它们都是新学到的内容。旧间距候选确认时沿用原配置的 explicit 来源，界面显示“对话设置或确认保存”；现有协议不保存逐条确认时间或完整学习审计历史，不能虚构这些记录。

## 输入区和检索入口

模型名称、联网、Prompt 与记忆选择放在输入框内部的底部左侧，发送/停止在右侧。只有模型显示文字，其余为有可访问名称、鼠标说明与状态反馈的图标；原有选择、发送、输入法、引用、调整高度和取消命令不变。图标使用统一 UI 图标和主题，不新增全局监听或浮层栈。

模型下拉宽度按当前选中名称的实际排版自适应，不随最长选项或工具栏剩余空间拉伸。隐藏的同字体文字仅参与布局，原生 select 保留键盘及可访问语义；左右内边距、箭头位置、主题边框和焦点提示一致，窄窗口可收缩并省略长名称，完整名称由 title 提供。无需全局测量监听或新增持久状态。

模型连接页检索入口使用带搜索图标、用途说明和箭头的按钮，提供 pointer、边框、悬停、键盘焦点和 title 提示，仍通过 `retrieval.open@1` 进入设置。2026-11-18 后续用户明确要求保留在配置页最底部：入口位于模型连接表单之后，和表单共用一个滚动区；空余高度足够时靠页面底部，内容较长时滚动到末尾可见，保留完整按钮样式。

## 群组

群组完整名称不再常驻画布。群组悬停或键盘聚焦时，在边框外显示小型数字编号，鼠标说明展示名称与成员数。编号是当前群组列表的展示序号，不是持久 ID；不新增文件字段，不能当作跨书籍身份。语义解析的有界群组目录同时提供当前编号。

点击编号可直接编辑名称，Enter/保存通过既有 `group.rename@1`，携带编辑开始时的修订。过期拒绝并显示错误，Escape/取消不写入，成功的一次改名可全局撤销/重做。输入和按钮阻止冒泡到群组拖拽；编号放在边框外，避免遮挡原拖拽命中区域。悬停编号使用屏幕尺寸补偿，不改变群组文档几何。管理面板继续提供名称管理。

## 可执行动作覆盖

移除工作区动作所有者的开发者命令面板入口及可分配快捷键贡献，收回对应注册权限。保留 `workspace.plan.run@1`、校验、回执、续接和内部调试视图协议，普通用户不再看见 JSON 计划入口；助手仍使用同一所有者执行底座。

实时动作目录新增 12 项有参数结构及真实所有者的动作：群组详情、改名、管理开/关与状态；连线详情、外观和标签尺寸；编辑器状态、组合布局、长正文显示起点；指定选区包含对象查询。新增目录动作不等于增加 12 条内核命令，也不代表所有自然语言都已支持。已存在的命令仅在拥有者活跃且协议可用时开放。

群组改名检查修订并回读名称；连线外观仍进入原画布预览，和群组改名组合时编译为一次原子事务。编辑器布局和长文本窗口返回实际 owner state，连线标签尺寸返回实际记录。已停用功能与无效参数在预检/所有者处拒绝，不以模型文字代替执行。新增目录兼容扩展原 `workspace.actions@1`，不改模型写入或确认边界。

## 验证

协议检查覆盖新动作的实际读回、失效参数及修订拒绝、组合撤销与编辑器/标签状态。浏览器覆盖旧配置保留、候选来源/确认/启停/筛选、跨设备恢复、无候选状态、两页签键盘导航、图标选择/实际模型请求、检索按钮与导航、群组悬停编号/直接改名/撤销及开发者入口移除。过时的原始 JSON 面板浏览器用例退役，工作区计划的原子、回执、续接、冲突及生命周期协议测试继续保留。完整发布结果另行记录。
