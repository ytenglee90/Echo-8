# ADR-0106：标题同侧与对齐区、中转点相向端口及输入箭头

## 状态

已采纳，2026-11-04。部分替代 0100、0102、0105 的形态限制、标题起始侧投影和正文箭头方向。

## 决定

两个普通内容端点均为标题语义时，统一左接左、右接右，包括文字节点、文本框及混合形态。沿用 titleOrigin 保存实际拉线侧，正文端口开始而最终接入标题时也记录该操作侧。标题两端水平中心的差值位于较窄对象宽度 20% 内（最少 24、最多 80 画布单位）时，保留原始拉线侧；超出该范围后再使用原有相对次序翻边规则。对齐区与缩放无关，可避免很小的宽度/吸附差异导致换侧。未记录操作侧的旧连接保留既有自动选边。形态转换保留标题语义和已有操作侧，文本框锚点始终位于边中点。

任一端是群组或中转点时不应用标题互连的同侧/原始侧特例，各段独立按当前几何中心相向接入，切线水平。三条标题连线添加共享中转点后，即使分支保留旧 titleOrigin，也不会再被原始出线侧拉向错误方向。

正文实线的三角箭头属于实际左侧输入口；实际右侧输出口没有箭头，中转点没有箭头。该规则独立于持久图中的 from/to 顺序，移动对象或中转点后同步投影，不改写逻辑连接方向。渲染按需要反向生成描边并反转中转点切线，使箭头始终与原曲线平滑衔接。标题虚线仍只向其逻辑目标显示箭头，目标为中转点则隐藏。

输入箭头可能对应记录的 from 端。重接适配器按箭头实际端点锁定另一端，预览使用同一连接 ID；结束时通过既有 revision-checked connection.reconnect 一次原子替换所拖端，取消恢复原图。节点透明端口限制在框内，保证框外两侧箭头均可接收指针事件。空白拖动中的临时箭头仍跟随指针，命中实体后按真实端口投影。

## 协议与兼容

复用现有 titleOrigin 字段，允许文本框标题记录操作方向。重接端选择仅属于适配器临时会话；预览与持久 create/reconnect 指令复用现有端点和字段，不增加消息形态。连线 dataVersion 9、剪贴板 schema 4、容器和权限不变，不需要迁移，不批量改写旧数据。选择几何、预览、描边、标签和箭头重接共享连接拥有者的投影。测试服务器忽略生成的 artifacts/test-results 目录，避免 Windows 锁定临时 trace 文件导致开发监听器退出；生产部署边界不变。

## 验证

契约覆盖四种内容形态组合、上下排布、对齐区边界、微小中心次序反转与明显错开、记录不被改写、文本框操作方向的创建与撤销、共享输入/输出中转点在左右位置的水平曲线，以及箭头与实际输入口匹配。浏览器真实选择三条线并右击合并，移动中转点到两侧、检查虚线/实线及箭头、拖动 from 侧输入箭头重接并撤销；覆盖标题预览/提交、对齐内外移动、文本框与文字节点转换、标签缩放、旧文件与 file:// 便携入口。
