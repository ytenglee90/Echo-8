# ADR-0102：中转点固定水平端口与标题互连选边修正

## 状态

已采纳，2026-11-03；替代 ADR-0091 的分支方向平均切线，修正 ADR-0100 标题互连的自动选边方向。

## 决定

中转点固定左侧接入、右侧输出，切线恒为正 X 方向；移动到节点另一侧、增加或删除分支、旧 branchSide 字段均不旋转端口。既有节点、群组、文本框端点保留原有投影。正式路径、临时拉线、命中、标签及框选共用同一水平端口投影。连接指令继续走原所有者的校验和单事务路径，新生成端点规范为 junction from:right / to:left。

对沿水平方向前进的中转路径，控制柄各自不超过水平间距一半，防止垂直落差放大控制柄后造成 X 方向折返。开放线身在箭头截断后也限制控制柄，水平空间不足时缩短箭头，保留水平接入及单向描边。目标处于输出口背面时仍保持右出、左入的端口方向，允许连接绕回目标。

仅真实文字节点标题互连按修正后的同侧规则选边：源节点水平中心在目标左侧时两端左侧，在右侧时两端右侧，移动时自动切换。正文、文本框、群组及中转点不使用标题同侧特例。

这些是派生几何规则的修正，没有新增消息字段、权限或持久字段，连线 dataVersion 8 与文件容器版本均不变。读取旧的反向 side 或 branchSide 记录时投影到固定端口，不进行批量文档改写，旧标签与外观、保存往返及撤销继续保留。

## 验证

契约覆盖各高度差、狭窄水平距离、缩放及线身截断的水平端口与控制点单调顺序，反向布局和点对点的固定方向，以及旧文件无损往返。浏览器重现底部/中部中转点四路分叉、拖动预览/提交/撤销、向左拖动时仍右出、接入草稿左入无箭头，以及标题对标题左右换位时的自动同侧切换；实际截图检查后执行完整回归、性能及离线构建。

## 箭头重接预览

ConnectionDraft 增加可选 reconnectId / reconnectRevision，仍是原临时协议的兼容扩展。拖动既有箭头时，连接层以单个实时几何替换该 ID 的线身、箭头、命中和标签，密集模式将它从静态批次中移出并单独绘制，避免原位残影。成功提交后等待连接图读到替换修订，将新几何与清除预览在同一次渲染交接；取消或失败立即恢复原连接。原记录在拖动中不写入，正式重接仍一次事务与一次撤销。预览带所有者 token，旧手势失败不会清除新手势。浏览器覆盖原路径在松开前消失、标签跟随、提交无跳回及 Esc 恢复。
