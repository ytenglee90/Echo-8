# ADR-0137 · 书籍扩展名与关联连线悬停

本地书籍统一使用 `.e8`。文件插件在打开命令入口检查文件名，选择器、画布拖入、另存和生成规则共用这一扩展名。应用不接收旧扩展名。旧书可以改名后打开，文件内容无需迁移。原生书籍继续写入 Gzip 和 CRC32 的项目 v2，AI 直出继续读取文本 v1。

连线层使用既有 `canvas.entity.hover.preview` 临时信号及连线端点索引。在普通和批量渲染中高亮悬停文本节点直接连接的线，低倍总览也可临时显示这些线。批量模式按实线和虚线合并高亮路径，避免为每条关联连线增加独立的交互元素。提示以实线或虚线、标签、方向和对端为一行，最多查询四个对端的标题并显示剩余数量。连接中转点时提示直接端点。提示允许鼠标穿透，移出节点后撤下。悬停状态只存在于当前视图。

## 验证

类型检查、静态检查、生产依赖审计、568 项单测、210 项 Chromium 托管回归和极限画布压力测试均通过。定向覆盖旧扩展名拒绝、AI 文本改名打开、原生 `.e8` 保存和重开、实虚线悬停、40% 总览和 601 条线的批量高亮。Firefox 和 WebKit 的托管定向测试各通过 2 项。重建后的便携版在 Chromium、Firefox 和 WebKit 通过真实 `file://` 回归，各 5 项。
