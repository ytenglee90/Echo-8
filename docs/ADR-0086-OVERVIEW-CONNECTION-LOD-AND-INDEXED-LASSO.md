# ADR-0086：低缩放连线 LOD、框选仲裁与增量选择索引

## 状态

已采纳 — 2026-10-30。补充 ADR-0011、ADR-0017、ADR-0021、ADR-0022、ADR-0045、ADR-0065 与 ADR-0074。

## 问题

一份约 1,500 个节点、1,500 条带文字连线的真实书籍在 40% 缩放下会同时挂载上千个连线文字框。连线图层还会在 pointer-down 阶段抢先选择对象，使从曲线或文字框起步的拖动无法进入框选。与此同时，选择插件在普通单击和每次框选时都会重新请求并合并完整选择目录；连线提供者还会为所有连线重新计算端点和包围盒。空间裁剪虽然已存在于画布与连线视图，但没有成为选择命令的长期派生索引。

40% 概览中的节点选择层仍按 4 个世界单位绘制，屏幕上只剩约 1.6 px；紧凑卡片的 `overflow` 还会裁掉外侧选中框，导致节点与文本框缺少明显的非颜色提示。

## 决定

1. 选择插件拥有一个可重建的内存目录和 `SpatialHashIndex`。目录启动后预热；普通 `selection.set` 通过缓存 ID 解析，不因单击重新请求全目录。`selection.box` 等待当前几何失效处理完成，只查询与框选矩形相交的空间候选，再执行容器完整包含、精确区域和连接优先级规则。
2. `SelectableEntity.geometryRevision` 是可选、向后兼容的几何修订提示。文本节点由形态与矩形生成修订；连线由端点语义和两端节点矩形生成修订；群组由成员矩形生成修订。目录刷新可以更新元数据，但只有新增、删除或几何修订/包围盒变化才调用空间索引的 `set/delete`。正文编辑发出的 `geometry: false` 失效不会刷新选择几何。
3. 低于节点详细视图阈值 `0.5` 时，连线视图进入 `overview-focus`。默认不创建普通曲线、命中路径或文字标签；只渲染与已选、悬停或正在编辑的文本节点/文本框相连的连线，以及直接选中、悬停或正在编辑的连线。编辑节点通过公开的 `editor.openPanes` 查询获得，节点悬停通过 `canvas.entity.hover.preview` 临时信号传播，均不进入工作区、历史或文件。
4. 指针在连线曲线或文字标签上按下时，连线选择延迟到未越过 3 px 拖动阈值的 pointer-up。越过阈值后，连线层通过 `canvas.lasso.external.requested/preview/finished` 临时信号把手势交给画布所有者；画布取得指针、绘制框选并在结束时只提交一次 `selection.box`。框选预览存在期间，连线、标签、编辑器和调整手柄全部关闭命中测试。
5. 40% 概览中的已选节点和文本框使用约 4 px 屏幕宽度的补偿选择框，不叠加额外角标，避免角标被误认作节点内容或连接控制。紧凑节点允许该选择层溢出显示。100% 及普通详细视图仍保留既有 4 世界单位选择层。

## 兼容与迁移

`.echo8` 项目格式、插件数据版本和历史补丁均不改变。`geometryRevision` 与新增临时信号是公开协议的向后兼容扩展；旧选择提供者没有修订时仍通过包围盒比较正确更新。所有目录、索引、悬停、框选和 LOD 状态都是可丢弃派生或临时状态，插件停止后不保留。

## 结果

- 40% 无关注对象时，带文字的密集连线集合不会创建 SVG 曲线或 `foreignObject` 标签，概览 DOM 与命中面积由节点数量主导。
- 单击延迟不再包含完整选择目录合并；框选精确判断由全目录线性扫描缩小为空间候选集合。
- 从连线或文字标签起步也能稳定进入框选，单击、双击编辑、键盘选择和标签调整仍保持原语义。
- 选择所有节点会按明确规则显示所有相关连线；这是用户主动关注整个集合时的可解释成本，不是默认概览成本。

## 验证

契约测试覆盖 40% 阈值、关注实体过滤、2,000 实体目录的零变化刷新和单实体几何增量更新。Chromium 工作流从真实连线标签起步框选，验证框选期间命中关闭、40% 补偿选择框存在且没有额外角标。专用性能门禁导入 2,000 个节点和 1,600 条带标签连线，要求 40% 无关注状态的曲线/标签 DOM 为零，并在既有五秒预算内完成真实框选和全选。完整类型、Lint、契约、托管浏览器、便携构建及 `file://` 门禁继续作为发布要求。
