# ADR 0157 · 画布控制只在本地执行

有效。取代 0138、0147、0148、0151、0153、0154 中由云端补充画布意图、定位对象或规划操作的助手路径；原有公开能力、审查、事务与记忆证据规则继续有效。

## 边界

画布控制包括节点、文本框、群组、连接线、中转点、注释、主题、背景及其他外观、视图、选区和相关本地界面命令。助手先在浏览器内解析当前用户指令，完整语法优先于可选的设备内语言模型。分类、绑定对象、读取当前状态、构造计划与提交均不调用云端生成模型。配置了付费模型也不能改变这条边界。历史相关的控制上下文只允许本地检索，不走云端嵌入回退。

不明确、缺少对象、插件不可用、语法不支持或无法安全编译的要求在本地澄清或报错，不能以模型兜底，更不能先执行能识别的部分。零调用保证不代表任意自然语言都能成功识别。明确的讨论与普通问答仍可使用模型。

用户明确允许正文创作消耗 Token。仅当本地已经确定新卡标题或现有卡的写入范围及修订后，才发送正文任务。模型只能返回严格的 `text` 或 `texts` 数据；对象 ID、坐标、动作、范围和连线由本地确定。模型附加动作字段、字段不符、截断或资料修订变化均终止写入，不发起云端计划修正。目标不明确时先本地定位或选择。拆合后重接到多个新目标的含糊关系仍须澄清。

## 实现与所有权

- AI 助手拥有分流、设备内编译、正文请求装配和发送前检查。发送边界再次拒绝未绑定的画布任务以及携带画布操作工具的正文请求。
- 画布控制拥有对象绑定、原生本地指令、计划校验、回执和应用编排。按已有公开指令委托各功能所有者，不写其他插件的私有状态。
- 主题和全局颜色、注释、缩放、全选及清空选择都有本地入口。`执行本地命令：命令面板中的名称` 只允许唯一匹配且当前可用的画布、编辑、外观等本地功能命令；排除 AI 与云服务命令。由现有 `system.actions` 查询及 `system.action.execute` 提交，沿用所有者校验、确认与生命周期。回执只声称已提交排队命令。
- 成批创建后可引用本轮新群组连接其他对象，仍构成一个原子画布计划。引号内的正文、内容、操作词和分隔符保留为字面标题。

## 兼容性

复用 `canvasControl.native@1`、`localPlan@1/@2` 和画布计划 v1/v2，不修改消息形状、书籍格式、数据库或部署边界，无需数据迁移。补齐已有缩放与全选命令的静态类型。画布控制声明新增的既有命令消费、`system.actions` 只读查询和 `ui.action.execute` 权限；路由器继续执行权限及插件存活校验。

## 验证

定向回归检查配置了模型时主题、背景、注释、缺失目标及未支持操作的零次模型调用和实际零用量；完整本地组合、审查、原子撤销重做和保存重开；正文创作只发送文字协议，并拒绝模型注入动作或修改本地标题和范围。既有云端画布规划浏览器用例改为验证本地拒绝、定位和正文契约；普通问答、模型连接重试与用量统计继续保留。模型响应使用测试数据，不使用个人密钥。完整验证结果以本次交付说明为准。
