# ADR-0140 · 每轮 Token 用量与临时请求查看

每条助手回复底部展示本轮输入与输出 Token，适用于所有已接入模型。平台返回值优先；缺失方向按实际请求消息、工具定义与回复估算，并分别标记“估算”。历史缺失数据按可见问答估算。输入包含提示词、历史与引用内容，输出包含平台另行返回的思考 Token。估算不是账单数字。

OpenAI 兼容流式请求启用 `stream_options.include_usage`，读取 choices 为空的流尾用量块。仅在 400/422 明确拒绝该参数时最多移除参数重试一次，不改模型或消息。解析兼容 prompt/completion 与 input/output 两组字段；Gemini 的 prompt/tool-use 计入输入、candidates/thoughts 计入输出，不重复增加缓存 Token。依据 [OpenAI 流式用量说明](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create) 与 [Google 用量字段说明](https://firebase.google.com/docs/reference/js/ai.usagemetadata)。

工具后续请求、自动续写和画布格式纠正的成功请求分别记录一次并累加，不重复累加流式累计块。混合实际与估算时保留分方向标记。可选 usage 元数据与回复详情一起通过标准事务保存、撤销，不写入对话正文或记忆文本。旧记录无需迁移，书籍容器版本不变。

每轮用户气泡下有“查看发送内容”，通过 AI 助手拥有的模态界面展示实际 JSON 正文、地址、参数与脱敏请求头。provider 在每次真正 fetch 前记录，包括兼容重试后的实际正文。本地 session/turn 关联字段不发给模型。AI 助手只通过版本化 `ai.provider.requestTrace@1` 获取数据，不读取 provider 私有状态。

用户选择仅当前打开期间保留。请求缓存不进入书籍、恢复副本、个人配置或诊断导出，刷新、切换书籍及插件重启后不可用。最多保留 128 次请求、两千万正文字符，单条最多一百万字符；超过单条上限明确显示未缓存，不以截断片段冒充完整正文。已清理或刷新前记录显示不可用。密钥类请求头、URL 凭据和已配置 API Key 在缓存前脱敏。

弹窗通过现有模态插槽与表面管理注册，点击空白、关闭按钮或 Esc 关闭，不增加全局监听或自定义层级。正文仅作为 React 文本显示，不解释 HTML 或脚本。查看是临时界面行为。
