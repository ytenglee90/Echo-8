# ADR 0168 · 本地规则与模型解析的执行衔接

有效，补充 ADR 0159、0162、0165、0167。用户要求扩大本地表达，并解决误匹配后提前结束、界面操作进入普通聊天、模型已规划但未实际执行的问题。此处不承诺自然语言规则或模型永远正确。

## 分流与本地扩展

共享服务仅把当前应用对象的明确操作请求送入工作区解析，疑问解释、假设和故事创作保留聊天路径。礼貌请求可去除完整前缀。完整本地语法优先；含操作谓词、界面或选区语义的弱节点名匹配不冒充完整解析。若该名字与当前节点标题精确一致，仍按真实标题本地处理；引号和显式引用始终保持字面语义。

本地语义模型的“不完整识别”使用内部 `needsModel` 标记，替代从中文错误提示猜测是否兜底。明确缺参、真实目标缺失、停用功能、权限拒绝和实际执行失败不因此升级为收费模型重试。未覆盖的完整应用操作使用当前选中的、已配置的连接，保留最多两次的动作筛选/参数规划预算。

扩大本地表达：调出/唤出/呼出/叫出、后置打开关闭、礼貌说法、开关设为开启/停用、按成/倍缩放、调整至、沉浸与正文的对象前置句式、变成/转换为文本框、连线两端/两头/首尾、撤回和重做。数值仍由真实所有者校验，名称引号不作命令处理。

## 模型输入与执行

界面规划只提供界面动作结构，不读取节点、群组、连线、上下文目录或画布选区，也不将这些信息发给模型。模型目录中的 `assistantId`、`sessionId` 由应用绑定发送窗口和会话，不交给模型猜测；模型显式提供不同窗口 ID 时拒绝。连接资源只提供已配置的模型 ID、名称和模型名，不含 KEY。

模型返回的完整 JSON 经动作目录、参数、对象引用及所有者预检。普通请求的查询和工作区动作直接由原所有者执行并返回真实回执；文档修改及明确预览继续审查。模型文字不能代替执行回执，未知动作和对象、无效参数、取消和不完整输出不执行。连线详情和群组详情以本地真实名称、端点和成员回读答复，不另花一次模型回答费用。

模型自动执行前记录内部计划 ID 和步骤。重试读取原执行回执，必要时通过既有 resume 协议核对待完成状态，不重发模型或重复切换开关；原回执已失效时要求先核对再重新发送。刷新准备对象仍保留该引用。此状态只属于 AI 所有者的临时准备对象，不新增持久格式。

## 修订与选择

模型解析期间只重查实际引用对象：节点公开修订/标题/几何、群组名称/成员/修订、连线端点/修订。无关节点和对话记录推进文档版本不再错误使计划过期。提交仍使用最新文档版本和原所有者的原子校验；目标真的变化仍拒绝。

仅成员调整沿用 ADR 0165 的边界：正文同时更新不影响成员意图；标题、几何、成员、对象存在性仍核对，既有确认和一次撤销不变，不覆盖并发正文。涉及发送时选区的语句绑定捕获 ID，选区变化则拒绝；显式具名对象不被无关选区变化改指向。

## 兼容与验证

无新公共命令或协议版本，无书籍、账户、连接备份、数据库或部署边界变更，无迁移，不升级个人数据 Worker。仍使用现有工作区计划、查询、预览、回执和节点/群组/连线所有者。单 HTML 只能从源码构建。

验收包含本地变体、未知界面实际打开、弱节点误判恢复为端点查询、真实命令式标题与缺失目标保持零调用、发送窗口与选区绑定、无关/真实目标变更、并发正文保留、取消、无效模型动作拒绝、重试不重复开关。发布记录单列完整与定向浏览器结果及未解决的既有兼容问题。
