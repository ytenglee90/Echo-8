# ADR-0092：查找的未命中选区自动导航

## 状态

已采纳，2026-11-03。补充 ADR-0083，替代其未命中选区阻止导航的行为。

## 决定

上一处/下一处仍优先使用本轮首次选中的节点或文本框。只有该范围没有任何命中、但本次全画布结果存在时，导航才退回全画布，并通过已有受治理任务依次广播 `selection.clear`、`selection.set`。导航拥有者预先登记这两次预期选择变化，避免自己的清选事件清除导航状态。后续上一处/下一处保持全画布范围，不会被刚自动选中的命中节点重新限制。

随后执行已有正文选区或标题高亮定位，并通过可选的 `canvas.focusEntity` 使目标出现在画布视图。所有指令仍在导航任务中排队，正式导航指令本身不等待新排队指令，也不改变文档历史。选区本身有命中时保留原范围；真正全局无结果时不虚构目标。

若直接执行替换指令时选区没有命中，也先导航到真实命中、返回替换数零，不静默扩大为全画布批量写入。用户下一次明确替换遵循既有高亮/节点/全画布优先级。持久模型、文档格式和公开消息形状均不改变。

## 验证

契约测试验证前进/后退自动退回、后续全画布范围稳定、有命中选区保持限制，以及替换不扩大写入范围且不增加历史。浏览器分别从原有节点和文本框的未命中选择开始，验证旧选中取消、真实命中选中与正文范围揭示、无错误提示和全画布导航状态。
