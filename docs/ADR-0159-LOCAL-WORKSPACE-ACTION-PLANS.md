# ADR 0159 · 本地工作区动作目录与固定计划

状态：已接入；全工作区覆盖验收持续登记，不代表全部能力通过。

## 目标与责任

先验证动作底座，再接本地生成式模型。`workspace-actions` 插件拥有目录适配、固定计划、依赖、作用域、回执和续接。各功能所有者继续负责对象、参数、权限、修订、事务、历史及文件授权。新路径不请求云端规划、生成或嵌入，不提供远端同步执行动作。

助手将明确的视口、面板、查找、选区及布局等请求编译为本地计划。输入适配按动作、对象、参数和顺序拆分语句。引号内的名称作为字面值，名称先按当前书籍核对原样，再尝试去除称呼。选区代词绑定发送时的 ID。多步骤按照句中的顺序执行，最后读取实际倍率等结果。单独建卡与改名将核对后的字面参数交给现有画布控制，由它处理预览与提交。助手记录本地工作区指令时，不把对话写入放进用户的画布撤销序列。

现有 BGE 继续提供本地向量分类。自由拆解和润色等生成能力仍需本地生成式模型。自然语言适配与验收语料相互独立。

## 工作区动作补充分流

上一轮的 233 条识别或路由失败中，208 条进入了模型连接提示，25 条停在已有画布分类器。新增的输入识别复用动作词、界面对象和参数类型。打开、关闭与查看可以使用同一组界面对象。具名卡片的读取、导出、排版、路径查询复用对象绑定。结果使用当前注册动作的 ID，由助手核对目录、绑定参数，再交给计划执行器和功能所有者校验。功能停用或对象不明确时给出本地反馈。超出这层支持范围的请求继续走原有流程。

选区在发送时捕获。具名复制先验证发送时所选卡片，计划执行时再核对。定位文字范围会先激活同一个所属窗格。正文读取可以附带来源修订号，修改保留已有格式修订和正文修订的校验。首段替换使用已有文档预览。工具开关接受明确目标状态，在指令事务中读取、按需切换并回读。此路径只处理本地动作，保留原有正文创作流程和普通对话入口。

## 选区指代和结构操作

复制、排列和分组共用选区指代解析。数量和对象类型是作用范围约束。「这些卡」使用发送时捕获的 ID。具名选择表达先核对所提到的卡确实属于发送时选区。剪贴板所有者通过 `clipboard.copySelection@1` 解析这些 ID，仍由原有序列化提供者生成内部剪贴板。发送后改变选区不会改变复制目标。捕获的对象失效或有无法复制的对象时，保留原剪贴板。支持直接复制群组及其内部连线的规则沿用既有所有者协议。

坐标区间、原点与大小、节点坐标和尺寸使用一组有类型的数值参数。分组预览绑定具名成员或发送时的选区。正文摘录和布局先计算有界的原文或几何范围，再交给既有文档预览。标注更新及删除核对唯一对象和修订。画布控制、动作目录和模型连接设置的面板所有者明确开放无参数动作，由动作索引验证后开启。模型连接设置面板只是本地界面入口。

修改既有群组成员时分别解析成员卡片和接收群组的名称，两者均需匹配唯一的公开对象。已有具名建组流程继续维护后续消息使用的群组引用。

剪切的新增表达使用相同的捕获 ID。剪贴板写入通过所有者的工作区事务完成，文档删除由各实体所有者的删除计划合为一份可撤销事务。原来的剪切审查和选区变化校验继续由原入口负责。具名粘贴先核对剪贴板的来源 ID，再绑定该份剪贴板的递增时间标记。发送后更换剪贴板会停止该次粘贴。

快捷键从核心注册目录按唯一名称绑定所有者和 ID，组合键参数单独归一化。提示模板从本机目录按唯一名称绑定。缺少模板时返回本机配置状态。操作回执使用实际日志查询。资料模式设置与只读取材要求共同解析。明确提供的导入正文按标题、内容和视口中心坐标交给文件所有者。

书库和画布共用当前已打开的助手窗口。进入书库保留窗口、会话及未发送草稿，书库页通过公开的 `ai.open` 命令打开或聚焦助手。助手停用时书库入口显示为不可用。工作区导航的目的地支持当前画布、当前书籍画布及刚才那本书，统一执行 `bookLibrary.enterCanvas`。具名打开另一部书仍由书库的独立打开流程负责。书籍格式和插件数据版本兼容原有数据。

窗格比例把整数比和分数转为权重，按 `editor.openPanes` 的公开顺序绑定实际窗格 ID；数量不符时先反馈前置条件。最小窗格宽度仍由编辑器所有者控制。带卡名的选区聚焦与剪贴板共用选区称呼解析，核对卡名和发送时捕获的单一 ID 后再聚焦。`file.copy` 识别本地副本及保留原书的限定，继续由文件所有者选择新目标并执行副本任务。

## 公开协议

- `system.actionCatalog@1`：当前注册命令、查询和能力及其所有者、可用状态；不泄露实现、提交内容或凭据。
- `workspace.actions@1`：带参数结构、效果类型及可用状态的执行适配和原始注册目录。`manual` 只表示存在界面入口，不能交给计划执行。
- `workspace.coverage@1`：66 类动作、27 项跨类别能力、11 个组合场景与原始清单、运行时来源和执行适配的映射。目录不缓存或冒充测试结果。
- `workspace.plan.run@1`、`resume@1`、`cancel@1`：有界 v1 固定计划及逐步回执。
- `workspace.plan.receipt@1`、`latest@1`：仅返回同一调用者的任务，防止不同助手或窗口串用回执。
- `ActionContribution.localTool`：功能所有者明确选择开放的版本化参数动作。`system.action.validate@1` 使用真实指令校验器预检，`system.action.invoke@1` 在原指令返回后才返回；不把入队成功当成完成。
- `canvas.viewport.set@1`：原子设置视口中心、绝对倍率及屏幕像素平移，独立于文档历史；支持公开节点、群组、连线和中转点的几何。
- `layout.arrangeNodes@1` 从明确的卡片 ID 和排列方式准备并提交一份布局事务。原有的选区排列指令继续读取调用时选区；自然语言入口使用发送时的选区 ID，节点失效时停止提交。
- `layout.settings@1` 读取参考线和吸附状态。四个开关动作的计划参数可选 `enabled`，未提供时继续切换。工作区读取正文范围可选 `expectedRevision`，复制选区可选 `expectedIds`。已有固定计划继续兼容。
- `clipboard.copySelection@1` 复制捕获的对象 ID，使用当前所有者解析核对存活对象及可选类型。计划中的 `clipboard.copy` 可传 `sourceIds` 绑定这一行为。旧的 `expectedIds` 继续核对调用时选区。
- `clipboard.cutSelection@1` 使用同样的 ID 输入复制并剪切。文档删除作为一份历史记录，撤销恢复原对象。原来的 `clipboard.cut` 和审查流程继续兼容。
- `clipboard.sources@1` 只读取来源 ID 和时间标记，`clipboard.pasteCaptured@1` 校验两者后才实例化副本。旧的无参数粘贴仍可调用。
- 注册工具的 `inputSchema.type: "null"` 声明无参数动作。动作计划省略参数再交给所有者验证。查找状态可带已完成的关键字和命中数，标注删除可附带修订约束。项目和内部剪贴板数据格式保持兼容。
- `canvasControl.workspacePreview@1` 与 `reviewReceipt@1`：复用既有审查、所有者规划、一次提交、撤销及结果核验。来源节点即使只被复制，也纳入修订校验。
- `content.canvasSummariesById@1` 只返回公开画布节点，避免通过已知内部 ID 读写会话载体。`content.statistics@2` 真正限定节点集合，保留旧版全画布统计语义。
- `file.saveLocalCopy@1`、`file.operationResult@1` 与 `file.cancelOperation@1`：本地副本强制选择新目标或生成下载文件，保留原保存目标；任务结果区分运行、完成、失败和取消。计划取消会按原任务 ID 请求文件所有者中止，不撤销已经完成的写入。

以上是追加的版本化 API，没有修改书籍格式、文档数据版本或既有协议含义，因此无需书籍迁移。复制文件修复了旧实现复用当前句柄的错误；原书句柄保持绑定。

## 计划与跨类别组合

### 2026-11-18 本地入口和完整子句编排

`ActionContribution.localTool` 追加 v2，可声明同一功能所有者的独立 `command`。注册时核对清单声明，调用和预检时再次核对实际命令所有者及可用性；不得借别名调用其他插件的命令。v1 继续使用原界面动作命令，普通界面执行也继续使用原命令。

保存动作通过 v2 使用无参数 `file.saveLocal@1`，只复用文件所有者的本机句柄、首次选择位置或下载流程。普通界面保存仍保留原有云书籍行为。`palette.selectionColor.openFor@1` 接受明确的实体 ID，使用公开选区解析能力确认对象；打开局部调色不改当前选区，发送后的改选不会改变目标。原无参数界面入口继续使用当时选区。两个新增命令均有协议及兼容回归。

规则 TXT 选择和云端另存设置由各自所有者明确开放原有入口。后者只打开本机命名与授权界面，不代表上传成功。当前工作不发起远端写入。

组合编译先隔离引号内的字面值，再按动作子句调用已有解析器。所有子句必须完整识别、绑定并通过目录可用性检查；任何一步不能核对时，不启动这份组合。此新增编排目前限于查询和工作区效果，文档、文件效果组合在执行前明确停止，已有独立文档预览机制继续适用。拒绝的组合不能回退到单动作目录执行其中一部分。每个子句重编号并保留结果引用和前置依赖，嵌套选区引用统一捕获发送时 ID。

当前会话存档由 AI 所有者在现有生成任务中准备原文与索引，再通过原有正式 `ai.session.memory.commit` 提交，避免另排子任务造成调度依赖。提交成功并核对存档索引后才回复成功；取消清理待提交准备，修订冲突继续由原所有者拒绝。该路径不调用生成、嵌入或云端服务。浏览器验收打开真实存档原文核对输入，不能只凭回复判断成功。

书籍文件格式、存储版本、原有动作 ID 和旧调用语义保持兼容，无需数据迁移。

每个计划最多 24 步、256 KiB；已有画布计划仍沿用自己的 80 对象、100 动作和文字上限。计划先检查所有动作、字面参数、可用性、唯一编号、前置依赖、条件和作用范围，再开始执行。只读与工作区限制不能被文档或文件步骤突破。

`{from: "前置步骤"}` 传递唯一对象；同名对象产生候选并等待，不能按列表第一项猜测。`{$step: "前置步骤", path: ["ids"]}` 显式传递有界结果字段，支持查询集合进入选择、统计和布局。后续执行前再次验证实际值，不读取界面后来变化的选区。引用只访问自己的字段，不能执行脚本或读取原型。

`when` 对前置 `content.find` 是否存在进行分支。前置等待或失败只阻止依赖它的步骤；独立查询和工作区操作可继续。回执分别记录完成、等待、失败及跳过。`verify` 使用只读动作再次读取最终字段，失败不会报告整轮完成。

候选绑定到具体参数角色与成员下标，不能将“起点”的候选用作“终点”。同一步有多个歧义时逐一确认，并保存已经选定的绑定，下一次澄清不会丢失前一次选择。长正文统计进入内核拥有的后台任务，正式指令队列可继续响应；取消、切书和停用会释放任务，结果返回前再核对来源修订。

连续且支持编译的多个文档步骤合为一份画布预览，包括建卡、局部正文、名称、坐标、尺寸、形态、标题色、明确成员分组和连线。新建对象使用本轮别名，提交后才向下游交付真实 ID；同一卡的兼容属性合并。其他批量操作可使用显式的 `canvas.batch.preview`。无法原子合并的多次文档提交会在执行前拒绝，不能悄悄拆成多条历史。

预览应用可从原画布控制界面或计划续接进入。续接先查询预览实际状态；已应用则读取原结果，不重复提交。应用共享预览中的任一步都只提交一次。关闭面板后仍可回到上次固定计划。取消只放弃剩余工作，不撤销已提交成果。

同一调用者与计划 ID 是重试键，已执行的相同计划返回原回执；同 ID 不同内容拒绝。内存最多保留 64 份回执。替换书籍后全部旧回执失效。插件资源由内核清理，不把视口、目录、候选或回执写入书籍。

## 使用与验收

### 明确对象的复制与运行时来源索引

`clipboard.duplicateCaptured@1` 由剪贴板所有者处理捕获的对象 ID 和一组放置参数：明确偏移，或方向及可选间距。两个模式互斥；方向模式按公开选择实体的整体边界计算偏移，默认间距为 80 个画布单位，不依赖视口倍率。对象解析不会改动调用时选区。复制继续使用各所有者的序列化与实例化能力，内部关系按两端都在复制集合内的原有规则复制，外部关系保留在原对象上。

新动作 `clipboard.duplicate` 使用文档效果声明。一次复制的全部标准补丁合为一份事务，一次撤销与重做覆盖全部副本。该路径保留原内部剪贴板和粘贴序号。明确要求内部关系时检查关系能力可用性；新路径还验证每个序列化实体都有实例化补丁，缺提供者时整份复制不提交。既有复制、粘贴和 Alt 拖拽协议保持原语义。

自然语言将对象集合、内部关系要求和放置方向分别绑定。名称集合必须逐项唯一解析；选区集合采用发送时捕获的 ID 和数量约束，不能以当前只有一张选中的卡代替“这两张”。缺对象或不满足数量时停止，不猜测补足。

运行时动作描述新增可选 `sourceKeys`，公开真实命令、查询与能力的标识。动态 v2 动作显示其实际本地命令，索引与预检共同核对命令可用性和真实所有者。跨类别条目新增可选动作映射；目前登记 X04、X08、X13、X18、X22、X26 的代表动作，其他条目继续明确留待映射。映射与注册不等于验收通过。两个结构均是既有带版本查询的兼容附加字段，旧消费方可忽略，无书籍迁移。

新动作的三条同义句放在独立扩展语料中。默认继续运行原始 528 条，`ECHO8_LANGUAGE_SUITE=extended` 单独测试扩展动作。原始和扩展报告分别保存，并分别列出不属于本套的运行时动作，不能把新增动作并入旧通过率。运行时索引由 `scripts/probe-workspace-language.mjs` 在本机页面读取，交付 `Echo-8-运行时动作索引.md` 及 JSON，包含实际参数、来源和当前状态。

命令面板搜索“查看本地工作区动作与固定计划”，或设置中心进入“工作区动作”。这里可以查看实时目录和清单，运行固定计划、选择候选、核对文档预览、回读文件任务及取消剩余步骤。

原始清单位于项目上一级 `deliveries/`。`scripts/generate-workspace-action-catalog.mjs` 从已确认的 JSON 清单生成运行时的精简目录；不包含源码全文和提示词规则。`scripts/verify-workspace-actions.mjs` 独立运行固定计划回归并生成逐项证据表。

验证要求包含正式指令路径、参数拒绝、候选续接、动态注册及热拔插、冻结 ID 集合、统计范围、原子撤销、来源过期、重复提交、文件真实内容、另存目标、取消和故障，以及托管和真实 `file://` 离线入口。浏览器测试拦截外部请求；`ECHO8_OFFLINE_TESTS=1` 禁止测试资产脚本在缺少缓存时下载模型。

覆盖表中的代表用例及同类变体未全部关闭前，不得宣称 66 类已全量通过。原创、润色、事实整理及语义质量的固定稿件只验证执行流程；只有本地生成式模型可用并完成原句和变体测试后，才登记语言理解结果。远端同步、真实授权和远端效果不能用本机模拟结果冒充。
