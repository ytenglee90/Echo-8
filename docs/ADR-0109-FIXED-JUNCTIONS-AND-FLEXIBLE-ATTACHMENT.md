# ADR-0109：固定中转点、独立线型及群组/文本框自适应接入

## 状态

已采纳，2026-11-04。按最新用户要求取代 0098 的平均位移跟随；保留中转点多选移动、吸附和一手势一次撤销。补充 0104、0105、0107。

## 决定

中转点保持保存的绝对位置。节点、文本框和群组移动或调整尺寸时，连接拥有者不再提供 content.moveAttachmentsPlan@1，也不再投影跟随位移。旧能力契约保留给其他拥有者，既有标准补丁历史和旧文件可继续读取。仅直接移动中转点的指令修改点的位置和修订。

复制内容不会自动遍历并收集相邻中转点网络。只有显式选中的中转点可进入剪贴板；连线仅在两个端点都被复制时保留。群组复制继续排除中转图，普通内部连线规则保持一致。快捷键、导航按钮和 Alt 拖动共用拥有者的序列化路径。

普通节点及文本框的同一端点对可以同时有标题虚线和正文实线。创建/重接按语义线型去重；标题及正文快捷操作只操作对应线型，不再自动把现有正文线转换成标题线。中转点删除旁路同样按线型去重。

群组或文本框接入一个已有中转点时，从该点现有分段继承线型，两个方向及箭头重接相同；只剩当前一条群组连线时，重接仍从该原连线继承点的线型。此规则优先于文本框上下区域分类；中转点内仍禁止混合两种线型，普通文字节点的显式标题/正文端口不自动转换。连接拥有者在事务前重新判定；输入适配器使用同一公开纯函数作预览。画布适配器新增对已有 connections.graph@1 的可选只读依赖，不读取连线私有命名空间。无连线的空中转点仍使用现有目标区域规则。

中转点每条分段的左右端口以实际另一端锚点位置判定，接入/输出导数均水平，预览、绘制、命中和框选共用几何。手势捕获及键盘焦点放在稳定中转点图层，避免点被视口裁剪或重绘卸载导致 lostpointercapture 取消和回跳；最终坐标采样、唯一令牌、串行提交和投影交接规则保留。群组透明端口不显示焦点矩形。Ctrl/Meta 双击文本框通过现有 editor.open 打开侧边正文编辑区，普通双击仍内联改名。

## 版本与验证

本决定不增加持久字段、消息形态或数据库迁移；与 0108 一起使用连线 dataVersion 10、剪贴板 schema 5，旧版本迁移链不变。验证节点/文本框双线型及独立撤销、群组/文本框双向继承两种线型和重接、三种复制入口、固定点预览与提交、快速连续移动、移出裁剪视口再返回、撤销和 Ctrl 双击编辑。原平均位移测试改为固定位置测试，旧历史热停用撤销仍覆盖。
