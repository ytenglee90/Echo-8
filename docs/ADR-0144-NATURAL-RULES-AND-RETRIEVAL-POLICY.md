# ADR 0144 自然语言规则扩展与独立检索设置

状态为有效，补充 0012、0056、0142 和 0143。本批由 ai-assistant、canvas-control、local-semantic-provider、semantic-provider 和新增 retrieval-settings 分别拥有各自实现。

## 本批行为

自然语言内容任务复用 AI_OPERATION_DEFINITIONS，同一目录负责 @ 入口和常见自然说法。显式 @ 优先。标题和引用中的动作词在内容任务路由中视为数据。确定性画布操作继续在模型调用前尝试本地规划。

本地规则新增选区操作、节点改名、明确命名的新建与相对摆放、批量一对多和链式连线、入线和出线查询、连线标签和颜色、反转、断线、删除及六种对齐。群组范围、空白正文、无连线、未分组、卡片和文本框、标题包含短语、排除对象可以组成有确定含义的筛选。筛选和批量修改均沿用真实 ID，修改继续复用已有拥有者计划、快照修订检查及原子事务。80 对象的现有修改上限继续由控制协议校验。

明确命名的新建要求“叫”或“名为”等参数标记。“新建两个测试节点”“新建一个人物节点”等创作请求沿用模型路径，避免把数量或用途误当成字面标题。已有未命名创作入口和直接生成行为继续兼容。

“新建角色节点”等未指定字面标题的命令自动进入画布计划。画布控制的文字节点计划能力是启动依赖，模型收到由应用确认的启用状态。目录中 available 仍只描述群组与连线两项可选能力。明确创建节点时，空计划或没有创建节点的计划进入既有的一次修正；再次缺少创建动作则返回本地校验错误。

本地规则接受常见口语前缀、连线动词、简写配色和主题表达。“类别｜名称”的各标题段可用于定位，命中多个节点时使用原有候选选择。显式选中节点可在本机操作。明确的画布动作在无本地规则时进入画布计划，保留文本处理命令的识别优先级。

“创建一张角色卡”“来一张人物卡”等明确创建单张角色资料的短句走本地画布计划。默认写入空白资料字段，明确说“空白”则保留空正文，也可带上指定标题。创建遵循用户的直接生成或先审查设置并可撤销。包含原创人物设定的请求继续使用模型计划。画布状态栏显示真实操作结果或等待确认的说明。

“把 A 和 B 连起来”“在 A 和 B 之间画一条虚线”等命中两个节点后按提及顺序创建箭头。两端已有任一方向的连线时复用真实连线；“把 A 连到 B”明确指定方向。“连线”使用当前选中的两个节点。只有同名端点需要点选，点选后继续原指令。新增连线遵循直接生成或先审查设置，改变现有线型仍先审查，整个操作可以一次撤销。此规则更新 ADR 0143 中未指定方向时的交互。

本地操作也接受“建个文本框，就叫线索”“往右挪一点”“排成一行”“刷成墨绿”“换成文字框”“归到人物组里”和“打开夜间模式”。“一点”表示 40 个画布像素。省略对象时沿用会话里的真实节点，或使用选中的节点。单数指代遇到多个对象时列出候选。只说连线起点时，临时保留起点和已指定的线型，下一句“连到……”只需补终点。过期或已删除的起点必须重新指定。短标题只命中部分名称时展示候选，点选后沿用原操作。

超出本地解析的明确画布请求使用现有模型计划。只提供相关节点的有界目录，同名无法唯一确认时要求补充目标。标题别名支持类别分隔符，目录仍按本轮动作选择必要字段。修改现有对象沿用预览。书籍格式和已有公开协议无需迁移。

正文支持按节点标题绑定全文改写和“把某节点里写某事的那段……”绑定局部范围。同一正文提案的追问携带用户明确约束原句，经审查记录到提案的可选 taskInstructions。近期角色历史继续默认选最近六条消息。长正文和历史仍保持范围读取、去重和完整原文保留。原话约束与上一版草稿纳入本轮上下文预算和用量估算。

## 检索设置和公共协议

新增 retrieval-settings 拥有 workspace 命名空间 retrievalSettings。mode 属于功能偏好，默认 local。open 属于仅当前页面的 UI 状态，通过 sessionOnlyWorkspace 过滤。页面通过统一 right.primary 设置导航贡献，打开时发出既有 system.ui.surface.revealed，由内核协调冲突表面和 Escape。

新增 retrieval.open@1、retrieval.close@1、retrieval.configure@1 和 retrieval.state@1。新增 context.localSemanticSearch@1、context.remoteSemanticSearch@1 区分本地和远程提供器。旧 context.semanticSearch@1 保留原合同以兼容既有消费者。

新增 context.semanticSearch@2 负责本轮语义检索策略，输入沿用有界 AIContextSearchRequest 并可附加 lexicalHits。结果包含 contributions、mode、attempted、matched 和 warnings。keyword 跳过语义，local 只请求本地。cloud-fallback 先请求本地，关键词候选和本地语义候选各不足三个独立来源时补查云端。这是公开可见的覆盖启发式，不能作为语义置信度保证。三个候选的初始阈值来自本批实现判断，后续按真实问题评测调整。

云端仍由独立连接的 allowRemoteContent 授权检查。受限 sourceIds 在建立远程索引前过滤目录，防止只过滤返回结果却发送范围外正文。不同范围索引并行时拒绝复用正在构建的其他范围任务。空 sourceIds 不发起补查。设置模式在本地阶段结束后变化时，跳过之后的云端阶段。策略插件不可用时，助手降级为本地提供器。

助手连接页通过按钮打开设置中的检索页。原本本地、远程插件拥有的设置贡献由检索页承载，连接和密钥仍由对应插件拥有。回答可选 metadata 保存检索路径、命中方式和失败提示，来源正文、查询内容和请求体不复制进这份 metadata。

## 版本与升级展示

页面披露当前压缩倒排索引格式、两款量化 ONNX 模型、ONNX WASM 1.29.0 及各自缓存标识。Small 固定为 75c43b069aac4d136ba6bc1122f995fedcfd2781，Base 固定为 71e50dc531959f9e04ebf190ea25b00261a0a186。保留 Small 为默认。新增 localSemanticProvider.model.set@1，原配置缺少 modelId 时读作 Small，沿用 Small 的旧缓存。Base 使用独立设备缓存。切换不会混用不同型号的向量。切换或下载失败时关键词检索仍可用，切回原型号时可重新装载其缓存。

本地模型设置补上关闭和取消入口。云端设置说明独立授权、查询及片段发送、费用和更换模型的重建影响。

## 兼容和验证

书籍容器和节点、群组、连线持久格式沿用现有版本。旧提案和回复缺少新增 metadata 时按空字段读取。新偏好有默认值，新增协议采用独立版本，旧能力继续提供。没有数据库迁移。

定向合同覆盖自然说法路由、引号标题、复合筛选、排除、批量修改和撤销、入出线、反转冲突、范围修订、十二轮约束保留、模式切换、空范围、独立云端授权及实际 Embedding 请求的 sourceIds 发送范围。浏览器覆盖统一设置导航、关闭与重新打开、真实版本披露、自然语言段落定位及约束追问，并复用 file:// 和跨浏览器场景。

## 组合操作、全文汇总与续接

明确连接词串联的本地对象操作最多八步，并用同一预览与一次事务应用。组合可引用该计划内的新节点。主题和背景预览使用原有入口，需单独提交。已识别的目标、连线方向、颜色、主题可以通过候选按钮补齐。相对颜色可调整待应用的单一配色计划。全量或第 N 处正文替换按每个节点计算，有独立命中预览并按原文修订一次应用，最多 80 个节点、500 处命中、2 MiB 正文。

正文处理可通过完整标题或带引号的标题直接绑定来源。自然对比明确提到两个来源却只命中一个时会提示补齐。结果可预览后另存新节点。已有绑定的草稿可说“替换进去”，沿用修订和范围校验。最近三轮（六条消息）优先保留，较早消息优先保留用户原话约束，再按任务词匹配补入，额外最多十条和 1,800 字符。原始对话、正式记忆索引和画布正文依旧独立保留。

明确要求总结群组或全文时，先显示将发送的正文范围。确认后按修订分批读取并让当前模型提炼、合并。最多 80 个来源和 64 个正文批次。任何正文变化、超出批次数或模型返回不完整提要都显式报错。正式记忆的确认、修改、废弃和分支措辞可转换成原有指令，确认后以零模型调用写入原始对话并触发已有的记忆索引。

## 本地模型对照

同一台 Windows 设备在 Chromium 中运行产品使用的 ONNX WASM 1.29.0 单线程推理代码，语料为 24 段合成中文正文、12 道题，每题一个标注来源。Small 和 Base 分别为 512 和 768 维，下载总量约 38.5 和 117.3 MB，两款首位命中均为 10/12、前五均为 12/12。Small 单次测得装载 217 ms、24 段嵌入 344 ms、查询嵌入中位 9 ms。Base 对应 272 ms、1,634 ms、42 ms。运行结束的浏览器 backing storage 增量约为 38.9 MB 和 117.9 MB，完整应用峰值内存未测。样本较小，个别题目排序不同，结果只反映本次样本。脚本为 scripts/compare-local-semantic.mjs。
