# ADR-0058：稳定 AI 协议前缀与动态请求分离

## 背景

每轮 AI 请求都携带不变的安全、证据和记忆协议，同时也携带会随用户、模板、联网开关和检索结果变化的内容。把它们拼成同一段 system 文本会降低支持前缀缓存的平台的缓存复用机会。

## 决策

- 将永远不变的 Echo-8 系统规则和记忆协议作为首条独立 system 消息。
- 原生联网说明、用户选定的模板和 Prompt 策略随后以独立 system 消息附加；用户要求、检索报告及原文证据继续保持在最后的 user 消息。
- 对于只接受单个系统指令的 Gemini 形状请求，提供器按原顺序合并所有 system 消息，因此行为和安全边界不变。

## 后果

- 能够命中前缀缓存的平台可以复用最长且最稳定的提示词部分，从而减少高频追问的输入成本和首 token 延迟。
- 缓存是否可用、缓存折扣和最终延迟仍由用户所选模型平台决定；本应用不把缓存命中作为正确性的前提。
