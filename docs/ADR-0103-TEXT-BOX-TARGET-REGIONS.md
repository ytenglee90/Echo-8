# ADR-0103：文本框互连按目标落点区域选择线型

## 状态

已采纳，2026-11-03；用户明确确认：只依据最后接入的目标上/下半区，连接位置继续保持左右边中点。

## 决定

只有两端均为文本框时，目标落点严格高于水平中线表示标题虚线，中线及以下表示正文实线。源端拖动起点所在半区不影响线型。左右边端口始终位于垂直中点，不把上/下判定区变成额外锚点或移动连接位置。拉线与箭头重接草稿在跨越目标中线时立即切换；正式创建和重接由连接拥有者依照目标语义规范两端为 title 或普通自动朝向。

其他节点、标题、群组和中转点的语义保持现有规则。文本框转换、标签、颜色、ID、全局撤销仍按既有协议。connectionTargetSide 的可选源几何元数据用于识别文本框配对；公开消息形态和持久字段不变，连线 dataVersion 8 与容器版本不变，无需迁移。旧标题记录继续按原语义读取。

## 验证

契约与真实浏览器覆盖源/目标上下半区四种组合、中心边界、草稿实时切换、所有锚点保持中点、箭头重接切换、单次事务和撤销，以及普通节点到文本框仍为原规则。
