# ADR 0166 · 设置页归位与本地指令扩展

有效，补充 ADR 0159、0162、0163。由 AI 模型连接所有者提供设置中心页面，顺序 15，位于云同步（10）之后。新增 `aiProvider.open@1`、`aiProvider.close@1`；页面开关为会话工作区状态，不进入书籍、配置备份和文档撤销。连接、KEY、导入导出沿用原所有者和存储。2026-11-18 用户后续要求移除模型页底部检索按钮；检索统一从设置中心分类导航进入，原检索命令及功能保留。无数据库、书籍或连接配置格式迁移。

助手标题栏移除记忆、Prompt 和模型配置图标；记忆与 Prompt 保留输入区入口，旧配置命令及快捷键转发到设置中心，不新建对话。恢复的旧 provider 视图投影为聊天，保留会话、草稿与选择。模型占位项只在无有效选择时显示且不出现在可选菜单；无连接仍明确提示未配置。输入聚焦只调整边框，不添加输入框阴影。导航栏移除画布控制贡献，保留命令、快捷键、审查和执行功能。窄屏设置中心显示时暂时隐藏浮动层，防止助手挡住设置关闭按钮，关闭设置后恢复窗口与草稿。

## 本地动作

实时目录新增 13 项所有者命令适配：指令与偏好、插件、检索、模型连接、云同步的打开/关闭，以及快捷键、文件恢复和诊断关闭。全部指令与个人用语目录使用已验证的相同示例。完整本地语法优先，明确界面操作不发模型请求。插件停用仍由动作可用性与所有者校验拒绝。

“打开节点，沉浸写作模式”和“打开/进入/切到/切换到某节点的沉浸写作模式”均在本地编译为编辑器已具备的打开后沉浸动作；“切换节点为文本框”使用已有显示形态计划；“删除所有/全部”明确为当前画布所有节点，保留删除审查和一次撤销。“删除所有内容”仍要求澄清正文清空与对象删除；引号内的“所有”仍是字面标题。

“给节点里的文字添加注释”将节点名称和匹配文字分开，在所属节点内通过可取消的本地搜索绑定唯一正文偏移，重复命中要求明确位置，提交前核对正文修订。注释仍由原所有者创建和撤销，不将正文发给模型。

“改写节点内容，用新节点插入内容，标题为……”及“用新节点插入内容，标题为……，内容为改写后的某节点内容”按创建、标题、改写来源三个完整字段绑定，允许六种排列及句末逗号，引号内的逗号保留为标题数据；缺字段、重复字段或附带未知操作不部分执行。该流程复用现有正文拆合绑定，只读取指定来源，由模型生成严格正文 JSON；新卡标题及写入计划由本地构建，按已有直接生成或审查模式提交，保留原卡并支持一次撤销。生成需要 Token，确定目标和建卡不增加模型规划请求。

## 模型输入与反馈

界面请求兜底只发送界面动作与参数，不发送选区、节点标题、坐标、群组和连线目录。筛选后的动作不需要对象参数时同样省略对象目录。明确界面计划通过所有者直接执行并读取回执，不要求画布审查；对象修改仍保留原审查规则。

原生 DeepSeek 的结构化规划请求沿用已验证的 `thinking.type=disabled`，避免小 JSON 规划预算被思考占满；普通回答的思考行为不变。界面尚无通用思考强度设置，错误提示改为可实际执行的重试或切换模型，不再指向不存在的设置。协议依据：[DeepSeek Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/)。

本地计划是客户端执行路径，并不表示只能编辑本机文件。移除对当前云端书籍的一刀切拒绝；修改仍是当前文档标准事务，所有者校验、全局撤销和既有同步路径不变。不增加远端账户写入或上传动作，不绕过文件授权。

## 验证

覆盖真实设置中心顺序与导航、旧入口兼容和无额外会话、生命周期清理、空模型与实际模型切换、底部记忆/Prompt、聚焦无阴影、窄屏与暗调；补充零模型请求的设置操作、删除全部审查/撤销、正文注释偏移与过期/重复拒绝、云书籍显示形态事务，以及改写生成新卡实际读回/撤销。完整发布检查另附记录。
