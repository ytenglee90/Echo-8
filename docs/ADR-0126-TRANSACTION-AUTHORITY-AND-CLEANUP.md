# ADR-0126：事务授权、原子提交与项目清理

日期：2026-11-05。状态：有效；补充 ADR-0001、0035、0060、0074、0080。

## 事务与身份

`schemaOwner` 是可持久化的归属标签，不是授权凭据。能力注册表只为提供者自己的补丁，或已经由原所有者签发的嵌套计划登记内存授权。事务入口校验原始补丁对象和签发时内容，并一次性消耗授权；复制、篡改、自报所有者和重放均不产生授权。校验发生在标准化/克隆前。普通插件的 ID 不能占用 `core` 前缀。该约束是内置插件的架构边界，不声称提供同一 JavaScript realm 内的恶意代码沙箱。

状态写入预先克隆所有变化值，只保留涉及记录和修订的回退引用。历史合并使用不可变条目，提交与撤销/重做在同步持久化接纳失败时一起回退；订阅者仅在接纳完成后收到通知，其异常单独记入诊断，不中断其他订阅者或已提交操作。无需复制整份文档或正文历史。

## 导入和生命周期

任意命名空间/记录名按自有键读取和定义，包括 `__proto__`、`constructor` 和 `toString`；文件解析、状态写入和异步快照均不能触发原型 setter 或把继承成员误当成数据。已有 v1/v2 文件继续接受，未知插件数据原样往返。

停用、暂停、启动失败和卸载使用一个静默化流程：停止能力准入/发出取消，取消所有者任务与 Worker，再等待已经准入的能力调用结束。检索等待遵守调用者取消，但不会取消其他调用者共享的索引任务。

## 重复实现与目录

内联重命名状态由公共 UI hook 管理，调用方继续发送各自声明的公开命令；HTML/SVG 图层复用非被动滚轮 hook；节点/群组复用吸附预览；背景延时采用同一取消与监听清理实现。相近功能只在职责相同时合并，插件继续保有独立数据和生命周期。

连线层显式订阅框选临时状态，框选期间关闭自身命中区；该修复恢复 ADR-0086 已声明的行为。浏览器夹具按稳定实体 ID 定位中转点，使用真实端点/终端切线检查多段曲线，并按物理像素预算验证显示对齐；自由指针与曲线方向不依赖旧的单 cubic 数组下标。过时的旋转断言改为验证双击保留自动路由，视图截图按 ADR-0123 的实际段落排版逐个平台核对更新。

便携构建同时生成 HTML 和纠错规则的 SHA-256 清单，避免清单与重新构建的交付物脱节。

群组边框统一由 `inset: 0`、继承圆角的伪元素绘制，选中后只改变这一层边框；不叠加 focus-visible 外框或阴影。真实容器不再因 1px/3px border 改变内部坐标，连接端口中心和选中提示均精确对齐群组几何外边界；未选中的键盘焦点仍有可见提示。文字卡片最小显示高度与既有 120px 几何下限一致，防止旧文件中的 120–157px 节点被 CSS 强行撑高，造成可见矩形与连线/群组边界不一致。此处仅修复显示与交互投影，不重写用户尺寸。

开发交接合并为 `docs/DEVELOPMENT.md`，项目规则的唯一维护位置是 `.agents/skills/infinite-canvas-architecture/`。用户书籍、个人连接和数据库备份只在被 Git 忽略的本机资料目录保存。清理仅移除可再生成缓存、旧诊断产物和无引用副本；保留许可证、迁移、兼容层、用户数据和当前依赖。

## 兼容与验证

没有新增网络/文件字段，没有改变 `.echo8` 版本、插件 dataVersion 或 IndexedDB 结构，不需要数据迁移；授权凭据仅在内存中存在，既有序列化补丁不能携带它。补充测试覆盖特殊键往返、冒认所有者、保留身份、修改/重放计划、状态通知异常、持久化失败时修订和撤销/重做回退，以及重建中的索引停用。

## 本机清理记录

- 合并两份开发交接文档，移除活动工作区中的过时技能镜像；仓库技能继续作为唯一维护源。
- 删除经依赖元数据确认未使用的 `Canvas-App/.pnpm-store`：30,838 个缓存文件，1,419,290,083 字节；保留当前 node_modules 使用的工作区缓存。
- 21 个旧发布备份/CI 文件、9 个技能副本、2,624 个历史调试文件完整归档至 `local-data/archive/`，没有删除数据库恢复书签。
- 用户书籍与个人连接文件分别归档至 `local-data/projects/`、`local-data/personal/`；Git、Lint 和 TypeScript 均排除本机归档。
- `artifacts/` 只保留正式 HTML、纠错规则与自动生成的 SHA-256 清单。

群组显示修复已在真实 Chromium 的 40%/100%/240% 缩放下检查选中、键盘焦点、单层边框和边界重合；普通群组、混合选区、复制预览共享同一绘制规则。

群组选择的异步准入尚未完成时，正常 pointerup 已将请求标记为 released，随后浏览器自动释放捕获不能再将它当作取消；异常丢失捕获仍取消未释放的请求。该规则与节点图层一致，避免 WebKit 快速点击丢失群组选中状态。
