# ADR-0093：标题连线的左右端口

## 状态

已采纳，2026-11-03；替代 ADR-0064 和 ADR-0091 中标题统一从左侧绕出的几何规则。

## 决定

标题栏提供左右两个端口。标题连线继续保存已有 `side: title` 语义，几何投影按两端对象的水平中心决定相向的左右边，与普通节点连线采用同一规则；移动、缩放节点或中转点时重新投影。垂直锚点仍为标题栏中线，线型、标签框仍为虚线。

`connectionEndpointPoint` 增加可选的横向投影参数，不增加持久字段。连接绘制、命中、标签、框选使用同一投影，拖拽预览也使用相同的左右判定。群组端口可接入节点左右标题端口，中转点保持共享切线和无输入箭头。旧文件中的标题连线自动采用新投影，无需更改文件版本或写入迁移。

## 验证

单元测试覆盖标题语义保留、两边投影及普通曲线控制柄。浏览器覆盖右标题端口拉出、左标题端口接入、拖拽预览、节点移到另一侧后的端口翻转及撤销恢复，并继续执行标题虚线、中转点和群组回归。
