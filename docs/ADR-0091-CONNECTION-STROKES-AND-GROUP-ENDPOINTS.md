# ADR-0091：独立箭头、平顺中转点、群组端点与焦点提示

## 状态

已采纳，2026-11-03。补充 ADR-0002、0064、0086、0089、0090；替代 0017 中的整合箭头绘制策略。

## 问题与绘制决定

原路径在线身末端折返并闭合，虚线正反两次描边的相位不同，叠加后间隙变成实线；同一路径中的箭头还会被虚线切割。现在每条可见连接分别绘制一条单向开放线身和一个无描边的实心三角箭头。箭头前的线身使用 de Casteljau 分割在原贝塞尔曲线上截断，保持几何方向；箭头尺寸继续按缩放补偿。密集模式按颜色和线型分别批量合并线身与箭头，不生成逐箭头 DOM。标题虚线使用平端帽，选中加粗后仍保留清晰间隙。

中转点没有输入箭头，只有真实节点或群组目标端绘制箭头。点的所有入边与出边共享沿主干方向计算的前向切线，长度随线段距离限制，避免标题端点的左侧回绕规则误用于中转点。线身、标签、命中、框选和空间边界共用连接所有者的纯几何投影；邻近主干移动导致的切线变化也会使相关分支预览失效。标签继续位于对应曲线的弧长中点。

40% 概览下，中转点采用与连接相同的关注规则：无关注对象时不挂载；所属可见连线或被直接选中时才显示。中心圆点仍负责移动，旁边的加号端口负责拉线；节点可以拖线到点，点可以连接节点、群组或其他点。自连接、失效端点及纯中转点循环在创建事务前拒绝。按选择顺序连接两个端点的命令也注册到快捷键中心。

## 群组所有权与公开协议

连接端点 schema v3 的 `kind: group` 标识群组，现有 node 缺省和 `kind: junction` 保持不变。群组拥有者通过新的 `connections.targets@1` 提供只含 ID、类型和外框的几何投影；传入临时节点几何时同步生成预览，不修改文档，也不把群组实现导入其他插件。端口在外框左右边的垂直中点，成员移动、缩放、加入、移出时实时跟随。群组外框仍由群组拥有者推导。

群组—群组、节点正文—群组为实线；涉及真实节点标题的线为虚线。群组端点不转换成标题端点。连接、文字框、颜色、中转点、删除、快捷键、剪贴板和历史沿用连接原有规则。可选提供者停用时保留已有数据、撤销和历史；几何暂不可用时隐藏相应线条。

解组、移除成员导致群组解散时，通过 `connections.detachPlan@1` 取得连接拥有者的标准删除补丁，与群组补丁一次提交。选择删除成员时，连接计划请求删除前后群组几何，原子清理因此消失的群组端点。不存在提交后再补删连线的第二次历史记录。

直接声明的选择项若尚未进入派生目录，解析器先刷新新对象再展开其成员；已有缓存对象仍使用原来的快速路径。这保证新建群组后立即复制也能包含全部成员与内部连线。

连接文档数据版本升至 8，`7 -> 8` 为保持全部旧字段的无损迁移；旧应用通过版本门禁拒绝新端点，避免误读。剪贴板连接片段的内部 schema 升至 3，继续接受旧 schema 2 和无版本旧数据；外层 bundle 和 `.echo8` 容器版本不变。直接选择群组复制时同时复制必要的群组端点和中转点并统一重映射身份；仅复制成员不携带未选群组的外部连线。

## 焦点与小地图

连线、中转点和加号端口使用局部高优先级焦点样式，覆盖全局 `[tabindex]:focus-visible` 矩形框，以线条加粗和圆环保留键盘反馈。小地图去掉整块 SVG 的外部焦点框，保留视口小框、色块键盘反馈与半透明外观；导航开关位于聚焦按钮右侧、缩放百分比左侧。

## 验证

契约测试验证切线一致性、开放线身、独立箭头、中转点输入输出、循环拒绝、群组边中点和预览、7→8 迁移、文件/剪贴板恢复，以及多种解散删除路径的一次撤销。浏览器用实际像素验证虚线间隙，检查点击/Shift/键盘焦点无大框，验证中转点拉入拉出、概览隐藏、群组端口拖拽和成员改尺寸后的锚点、普通与标题线型、小地图焦点与工具栏顺序。完整回归、密集连线压力及真实 file:// 单 HTML 检查继续执行。
