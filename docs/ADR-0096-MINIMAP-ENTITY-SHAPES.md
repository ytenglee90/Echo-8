# ADR-0096：小地图的群组与文本框形状

## 状态

已采纳，2026-11-03；替代 ADR-0090 中省略群组和将文本框画为实心块的决定。

## 决定

文字节点仍显示原色实心块；文本框使用继承自身颜色的矩形边框和中间横杆，并用透明命中区域保留整框点击、拖拽和键盘导航。群组显示其颜色的轮廓，绘制在节点后方；未指定颜色时使用随明暗适配的概览色。群组内部保持空白导航区域，边框及键盘操作可聚焦群组。连线、连接标签、中转点和正文仍不显示。

新增几何型 `canvas.overview@1`：内容消费者只提供节点 ID 和几何，群组拥有者投影自己的外框与颜色，视图不读取群组私有存储或导入群组实现。提供者通过 `canvas.overview.invalidated` 宣布创建、成员、颜色、历史或文档变化；能力生命周期使停用后的轮廓立即消失并支持重新启用。`canvas.focusEntity` 在内容节点外查询可选概览提供者，继续由画布拥有者执行相机聚焦。

地图范围同时包含群组边框，手势期间投影继续冻结；节点和群组子树记忆化，相机平移不重新读取投影。没有新增持久记录、文档版本或迁移；原小地图开关与导航协议继续兼容。

## 验证

契约覆盖几何与颜色所有权、无查询写入、尺寸投影、群组聚焦和提供者热停用/重启。浏览器验证三种形状、横杆居中、继承颜色、文本框点击聚焦、空白/拖动保留缩放、群组焦点和热停用、自动明暗适配及无正文绘制；继续执行带小地图的压力和文件版门禁。
