# ADR-0098：中转点批量移动及平均位移跟随

## 状态

已采纳，2026-11-03。2026-11-04 用户改为固定中转点，平均位移跟随部分由 ADR-0109 取代；批量移动继续有效。

## 决定

中转点支持 Shift/Ctrl 多选，拖动已选点保留整个中转点选择及相对间距。临时预览支持可选批量 `positions`，兼容原单点和清除形状；`connection.moveJunctions` 在一个事务内验证每个目标的修订并提交全部位置。方向键移动所选点集合，Shift 提供原有较大步长，Escape 取消预览。吸附以所选集合的边界计算一个公共偏移。

中转点相连网络按唯一真实端点集合计算平均位移，静止端点计零；同一端点重复分支不重复加权。每个连通中转组件平移该平均量，保留手工布置的内部形状。节点、文本框与群组端点均使用公开几何投影。所有端点一起等量移动时中转点同步等量移动，移动一端时根据端点总数分摊。

新增 `content.moveAttachmentsPlan@1`：内容拥有者提供移动前的几何与正式目标位置，连接拥有者规划自己的中转补丁。节点单移、多移及既有移动计划将这些拥有者标记的补丁与节点位置合并为一次事务；没有提交后补写或第二条历史。连接视图使用同一纯函数投影节点拖动预览；Alt 复制保留原对象几何，因此不会误移动原中转点。

所有新能力、指令和预览均为类型化协议。中转点仍保存原有绝对位置和修订，没有新增持久字段或文档版本，旧文件直接兼容，无需迁移。连接插件停用后，已有标准补丁历史仍可撤销。

## 验证

契约验证批量修订的全有或全无、键盘整批移动、一端/所有端点的平均位移、同一事务撤销及连接拥有者停用后的历史。浏览器验证多选拖动、间距、键盘步长、撤销重做与 Escape，并分别从节点、文本框验证平均位移预览及一次撤销。
