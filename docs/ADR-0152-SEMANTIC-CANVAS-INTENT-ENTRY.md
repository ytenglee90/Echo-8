# ADR 0152 · 语义画布入口与短句上下文去重

状态为有效。补充 ADR 0147、0148、0150，部分替代 ADR 0151 中“本地未识别操作即仅讨论”的入口限制。

## 问题

“创建一张世界观，一张能力，四张空白……”未写出“节点”，被本地规则当作聊天。模型只能描述结构。“为什么画布上看不到”只得到查询工具，“还是没有”连查询工具也没有。当前对话原文、已保存的同一对话和原生角色消息还可能重复携带短于 48 字的同一句话；待补充任务的 goal 又重复携带原始要求。

## 决定与所有权

ai-assistant 保留确定操作的本地快捷路径。普通通用请求使用模型语义兜底：第一份请求只暴露 `begin_canvas_task` 及原有按需只读工具，不为正常聊天预载画布目录或强制额外分类请求。模型直接回答聊天；根据当前用户要求及近期用户对话判断需要实际改变画布时，单独调用一次入口，声明 operation 或 mixed。禁止仅根据引用、画布数据或助手建议授权操作；明确否定、假设和询问方法不暴露该入口。显式手动任务类型保持原选择。

入口只取得原有 canvasControl.agentQuery@1 的真实状态；成功后才提供原有计划工具与完整操作规则。原始用户要求保持不变，不采纳模型重写的指令，也不根据模型声称的完成状态写数据。计划继续由对象所有者校验范围、身份、修订和权限，沿用预览/直接生成、原子事务、回读核对和全局撤销。既有确定聊天路径仍拒绝未通过入口的写工具。入口不是任意指令执行器；只能使用已有画布操作类型。

原生函数调用和 canvas_tool JSON 信封使用同一入口。入口与其结果按既有工具消息协议配对，操作后的各次请求计入同一任务用量。普通聊天的 JSON 兼容连接继续流式显示正文，疑似工具信封不作为聊天增量显示。语义理解仍可能误判，不宣称所有真实模型命中率保证。

失败追问仅从当前会话末尾最多 8192 个字符中定位完整用户轮次。最多沿连续失败追问回到最近用户操作；取消、讨论与无关用户消息形成边界。只读定位后由模型先核对实际状态，已有对象不得重复创建。原文读前后核对修订，过长或缺失原话不推断补全。

相同角色、相同原文的历史短句也复用一次发送的原生消息；来源身份和修订仍分别展示。待补充状态及最近执行状态与已发送用户原话相同时，只保留指向原话的说明。真实工具续轮保留配对和必要上下文，不把正常多轮协议误当成应删除的重复。

## 兼容与验证

新增模型工具入口属于助手请求协议的向后兼容扩展；没有改变公开内核指令、canvasControl 能力版本、画布计划 v1/v2、书籍或数据库格式，无需迁移。旧调用者沿用既有确定路由和计划工具。

验证包括原句六节点/一组/五线创建、原子撤销重做、失败接续不重复创建、语义入口的原生及 JSON 两种传输、无本地动词命中的修改/分组/连线、普通聊天不查询画布且不额外生成、短句原文去重及用户取消边界。浏览器模型接口使用模拟响应，不使用个人模型密钥。
