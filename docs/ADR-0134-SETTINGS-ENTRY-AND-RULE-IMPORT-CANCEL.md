# ADR-0134：设置入口、规则取消与本机恢复面板精简

2026-11-06，有效；替代 ADR-0133 的工具栏设置入口，补充 ADR-0130 的分组顺序及 ADR-0048 的 Esc 退出链。

导航栏不再注册设置按钮，也移除插件管理不再需要的 ui.top.contribute 权限。拥有者复用原 action ID 和 pluginCenter.open 指令，以“设置中心”在命令面板的首组“快捷入口”置顶，保留旧名称搜索词、打开/关闭指令及快捷键。命令面板仍只消费公开目录；首项的鼠标、方向键和 Enter 使用同一排序。设置页从短暂命令浮层打开时，关闭后可回到触发该浮层的工具栏入口。

设置分类按用户编号从上到下固定为：1 云同步、2 书籍与恢复、3 命令与快捷键、4 外观、5 插件、6 内核与诊断。各拥有者只修改自身导航贡献的 order；不另建按功能 ID 排序的外壳逻辑。

同日默认页跟进：设置中心入口改走新增的 system.ui.openSettings@1（无载荷，返回 { opened: boolean }）。UI 服务每次读取已注册设置页的公开排序，使用内联 invoke 调用首个可用页面的拥有者指令，默认进入云同步，重新打开也不保留上一次分类。云同步停用时自然降级到下一可用页面；无页面返回 opened: false。保留直接打开各分类的旧指令与快捷键，并为设置入口登记可配置的独立快捷键。无文档历史、持久格式或数据库变更；覆盖重复打开、停用降级、无页面及无历史副作用。

书籍与恢复页面将本地占用/安全清理和历史恢复副本合并为一个“本机数据与恢复”模块，自动保存配置独立呈现。移除“选择已加载副本”按钮，保留逐条勾选、删除选中、清空、单条删除、手动恢复点、预览恢复和保留数量设置。两个区域继续使用 import-export 拥有的公开查询和维护指令，删除确认、分页及数据保护语义保持不变。

文本辅助新增无载荷公开指令 textAssist.cancelRulesFileSelection@1，返回 { cancelled: true }，通过 text.assist.rules-file.cancelled@1 临时信号通知其拥有者视图。显式请求选择规则时，把既有 canvas.selection 贡献登记为受治理的可关闭表面。Esc 继续经 system.ui.escape 路由，不添加全局按键监听；更新请求比底下设置页面先关闭，输入法和局部控件仍优先。默认缺少规则的被动提示不抢占书库等表面的 Esc，用户可以用新增关闭按钮隐藏它；再次发起规则更新会重新显示。

关闭按钮、原生文件选择器取消和 Esc 共用取消指令。取消只隐藏当前提示、清空临时错误并失效尚在读取的文件结果，不改已有规则、个人资源、正文或历史；已经正式提交的导入不由该取消指令撤销。成功导入和插件停用均释放关闭表面。文件读取携带本地请求代次，取消后到达的结果不能再发起导入。

新增协议为兼容扩展，没有文件格式、数据库、插件数据版本或权限存储迁移。验证覆盖首项入口与键盘执行、导航栏按钮移除、Esc 分层取消、可见关闭按钮、原生选择器取消、取消后的重新请求、迟到文件读取隔离、无文档/历史变化及停用清理。
