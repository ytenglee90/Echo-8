# ADR-0110：中转点与内容、群组的混合选区移动

## 状态

已采纳，2026-11-04。补充 0109：未选中的中转点继续固定；显式选中的中转点参与整组选区移动。

## 决定

选择插件拥有 selection.moveEntities 指令，组合已有 content.movePlan@1 和新增 entity.movePlan@1 版本化拥有者计划。移动请求携带显式位置，中转点位置另含 expectedRevision；连接拥有者只返回自己认领的点及标准补丁。协调方先验证完整、唯一认领及所有修订，再在一个事务中提交内容和中转点补丁。缺失拥有者、已删除实体或过期点修订均拒绝整个移动；停用连接插件后历史仍可通过标准补丁撤销。

节点、文本框、群组与中转点拖动入口保留整个混合选择，展开选中群组成员并按 ID 去重，只追加显式选中的中转点，不沿连线收集相邻点。所有移动对象使用同一位移和吸附偏移。群组边框仍仅由自己的内容成员决定。内容及点的预览复用 canvas.drag.preview 和 connection.junction.preview；可选 owner 为运行期预览清理提供所属标识。中转点适配器在连续提交中仅叠加自身已确认的内容/点位移，不越过其他来源的修订。

混合移动先结束当前交互再提交，避免下一次拖动越过上一次结束。拖动节点/群组时交接键盘焦点，Esc 取消整组预览；点的方向键移动同样展开混合选区并只产生一次历史。Alt 复制继续走原有复制协议，未选中的中转点不跟随移动。

## 兼容与验证

新增指令与 entity.movePlan@1 能力均为有类型的公开消息；画布、群组及连接适配器声明对应权限依赖。没有新增持久字段、数据库或文件格式变更。验证整组原子提交、过期/缺失拥有者拒绝、成员去重、一次撤销重做、拥有者停用后撤销、Esc、最终松手采样、连续移动，以及四种对象作为拖动起点。按用户要求仅运行相关测试和 Chromium。
