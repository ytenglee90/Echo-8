# ADR 0154 · 对话草稿回查与本地画布指令

状态为有效。实现依据为 [助手对话与画布操作设计](DESIGN-AI-ASSISTANT-CONVERSATION-AND-CANVAS.md)。补充 [任务用量与按需上下文](ADR-0142-AI-TASK-USAGE-AND-DEMAND-CONTEXT.md)、[回合分流](ADR-0151-AI-TURN-ROUTING-AND-CANVAS-WORKFLOWS.md) 和 [本地语言理解](ADR-0153-LOCAL-CANVAS-INSTRUCTION-UNDERSTANDING.md)。

## 对话与请求

- 可判定为独立寒暄或定义问题的通用对话，在没有明确资料或选定记忆时直接准备空来源请求。模板和模型配置随请求保留。涉及具体项目数据的查询继续走检索，例如「某项目当前状态是什么」。
- 对话目录补充草稿版本、话题和用户选用的记录。改写追问从同会话的指定草稿原文范围取证，歧义先澄清。显式要求保留首句时，程序原样拼接并核对字数。字数超限最多做一次定向纠正，纠正调用仍进入本任务用量统计。目录按源修订缓存，重建与读取遵守原有分块和预算。
- 明确礼貌执行请求可进入本地解析。否定或假设语句使用聊天或相应的分析路径。普通定义问答、明确草稿引用和已能直接编译的动作可跳过本地语义模型准备。其他口语继续复用现有本地分类和模型兜底。

## 操作所有权与协议

- 新命令 `canvasControl.native@1` 只接收 AI 助手发送的本轮原话、会话及准备标识，还有需要时捕获的选择和引用。画布控制重新解析有限指令并委托所属功能的正式命令。模型没有该命令的工具入口。既有 v1/v2 画布计划、读写能力和书籍文档格式继续兼容。
- 已接入内部剪贴板的复制、粘贴、确认剪切，标注添加、正文替换、改色和删除，连接线中转点、个人导航栏与相关外观颜色，以及全局撤销重做。选区型指令核对当前选区。待确认的剪切、标注编辑及粘贴核对目标修订或剪贴板状态。定向修改由拥有者验证和提交。标注与剪切的审查复用画布控制面板。
- 本地原生操作的发送记录和回执照常持久化，作为任务记录不占用新的画布撤销步骤。显式撤销重做通过现有全局历史命令。如果下一项是此前可撤销的助手对话记录，回执指出该项，用户仍可用全局历史控制处理。旧历史记录保持原样。
- 支持明确正文原样填写、选中连线的标签和改色，以及指定列数、间距和保留对象的本地排列。调整列数时复用待应用计划的对象与间距。已应用方案的接续以最近提交后的实际状态为依据。显式选择范围为空时需要用户指定对象。

## 验证证据与限制

用现有测试覆盖全局历史、权限、事务、内容保存及读写分流。新增测试覆盖独立定义问题、隔 100 轮取回已选草稿、布局计划保留目标和间距、离线原生操作与选区竞争、一次模型调用完成草稿改写。浏览器中的模型响应使用固定测试输出，输入内容和调用次数由测试记录。

交付回归包括类型检查、ESLint、667 项单测、252 项 Chromium 托管回归、46 项 Chromium 便携回归、Firefox 和 WebKit 的 4 项定向便携验证及大画布浏览器压力测试。最后的回执和草稿范围调整通过了助手单测、托管定向复测和便携版回归。单 HTML 由正式构建脚本生成，校验值写入 `artifacts/SHA256SUMS.txt`。

本次验证为固定样本回归。真实使用中的整体自然语言命中率、付费 Token 和耗时分布需要按设计文档收集独立样本后测量。
